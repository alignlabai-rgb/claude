Claw Stack 系

Claw Stack

PicoClaw / NanoClaw

軽量エージェント基盤の実験名。PicoClaw は最小構成、NanoClaw は中規模実験用。Claude Code や OpenClaw との組み合わせで使う。

OpenClaw

→ OpenClaw 詳細 / 使い方

Hermes Agent

もう一つのサードパーティ CLI ハーネス。hermes.md を読むだけで課金される問題が Hacker News で拡散し、OpenClaw とともに5/24に利用解禁された経緯がある。

Claude / Anthropic 製品

Claude Code

Anthropic 純正の CLI エージェント。実装支援＋レビュー＋長時間運転＋権限制御を含むエージェント基盤。2026年6月時点では Opus 4.8 の Effort Control / dynamic workflows と組み合わせる長時間作業レーンが中心。

→ Claude Code 詳細 / 操作ガイド

Effort Control （旧 Adaptive Thinking）

Claude が「どれくらい深く考えるか（思考量）」をタスク難易度に応じて調整する機能。Opus 4.8 で Adaptive Thinking の進化形として明示的な制御性が強化された。深い推論・コーディング精度の強みの源泉。

→ Claude モデル詳細

Cowork

Claude Desktop 上で動く知識ワーク自動化エージェント。2026/04/09 に GA。「試す機能」から「組織で運用を考える機能」へ。Analytics API・OpenTelemetry・Enterprise role-based permissions 対応。

Managed Agents

Claude のクラウドホスト型エージェント基盤。dreaming / multiagent orchestration / Memory / Self-hosted sandboxes / MCP tunnels / outcomes / webhooks 等の機能を持つ。

Mythos / Mythos Preview

Opus より上位の Claude モデルクラス。Mythos Preview は Project Glasswing 向けに始まり、2026/06/09 に Claude Fable 5 / Claude Mythos 5 が追加された。ただし 2026/06/12 の米政府指示により Fable 5 / Mythos 5 は全ユーザーアクセス一時停止中。

Project Glasswing

Mythos 公開と同時に発表された協調的脆弱性修正プログラム。Apple・Google・Microsoft・Linux Foundation・AWS・NVIDIA など約48組織に優先アクセスを付与。

Claude Design

2026/04/17 に Research Preview で公開された Anthropic Labs プロダクト。デザイン・プロトタイプ・スライド・ワンペーパー作成。PDF / PPTX / HTML / Canva 出力対応。

Memory（Claude Managed Agents）

2026/05/19 Code with Claude London で public beta 公開。セッションをまたいだファイルベース記憶。dreaming（過去セッション振り返り）と組み合わせてエージェントの自己改善を実現。

Self-hosted Sandboxes / MCP tunnels

機密ファイル・社内サービスを自社インフラ内に置きつつ、エージェントのオーケストレーションは Anthropic 側で実行するハイブリッド構成（self-hosted sandboxes）と、外部 MCP サーバーへのセキュアトンネル（MCP tunnels）。5/19 公開。

Claude Routines

Claude 周辺の定型作業を自動化する仕組み。`_routines/` ディレクトリ配下に置く運用パターン。

→ Routines Deep Dive

Codex

Workspace Agents （旧 Custom GPT）

ChatGPT Sites

Frontier プラットフォーム

2026/02 発表。共有ビジネスコンテキスト・実行環境・評価・パーミッションを企業が一元管理できるエンタープライズ AI コワーカー基盤。Workspace Agents（4月）と Codex Cloud Agents の前提となる戦略的プラットフォーム。

プロトコル・標準

MCP （Model Context Protocol）

Anthropic が策定し業界標準化が進むエージェント・外部サービス連携プロトコル。2026/05 時点でレジストリのサーバー登録 9,000+、月間ダウンロード 9,700万超。Claude / ChatGPT / Gemini ほぼ全てがネイティブ対応。一方で MCP RCE 脆弱性も実証開示（5/18, OX Security）。

MCP Connector

MCP 経由で Claude / Gemini / その他クライアントから外部 SaaS にアクセスするためのアダプタ群。コンシューマーアプリ向け（Uber・Spotify・Instacart・Booking.com 等 200+）と業務向け（Salesforce・Box・Docusign・Thomson Reuters 等）に分かれる。

MCP Tunnel

外部 MCP サーバーへのセキュアトンネル接続。パブリックインターネットを介さず社内システムへ到達。Claude Managed Agents で 2026/05/19 から research preview。

ADR （Architecture Decision Record）

「なぜそう決めたか」を残す決定記録のフォーマット。本ハブでは decisions.html で軽量 ADR を採用している。

オープンウェイト・ローカルLLM

MoE / A3B （Mixture-of-Experts / アクティブパラメータ）

MoE（Mixture-of-Experts）は、推論時にモデル全体ではなく一部の「専門家」だけを起動するアーキテクチャ。A3B の「A」は Active（アクティブパラメータ）の意で、例えば「Qwen 3.6 35B-A3B」は総パラメータ35B・推論時にアクティブなのは約3Bを表す。「35B級の賢さを3B級の負荷で回せる」ため、一枚 GPU でのローカル運用に向く。

→ Qwen 深掘り / SLM ガイド

Qwen3.7 Max / Plus

Alibaba / Qwen の商用プレビュー系列。Max は agent frontier、Plus は multimodal agent intelligence として位置づけられる。open-weight / local 運用の Qwen 3.6 系とは別系列として扱う。

→ Qwen 最新アップデート

GLM-5.1

Z.AI の現行 flagship。公式スペックは 200K context / 128K max output。8時間級の long-horizon task、thinking mode、function calling、MCP、context caching、structured output に対応する。

→ GLM 深掘り / GLM 最新アップデート

量子化 / GGUF / AWQ

モデルの重みを低ビット（例 INT4）に圧縮し、必要 VRAM を 1/2〜1/4 に減らしてローカル運用を可能にする手法が量子化。GGUF は Ollama / LM Studio / llama.cpp 向けの定番フォーマット、AWQ（や GPTQ）は vLLM 向け。INT4 でも品質劣化は小さく、省 VRAM 化の中心技術。

→ SLM ガイド / Llama 深掘り

エージェント頭脳 （agent brain）

エージェント（OpenClaw / Claude Code 等のハーネス）を実際に動かす中身の LLM をどれにするかという選定概念。同じハーネスでも頭脳を Claude にするか、ローカルの Llama/Qwen にするかで品質・コスト・プライバシーが変わる。「ハーネス（外枠）」と「頭脳（中身の LLM）」を分けて考えるのが選定の出発点。

→ SLM ガイド（頭脳の選び方）
