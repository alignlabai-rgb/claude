CASE B · BOOK

1冊の本を
1年かけて書く

場面長らく構想だけがあった本を、本気で書き切る1年計画。 Claudeに 章ごとの進捗マップ を管理させ、毎週金曜に 「次に書く章」 を1つだけ示してもらう。 全部を見ない。次の1章だけに集中する仕組み。
# --- BOOK PROJECT: 「書くことと、待つこと」--- あなたは私の本の 伴走編集者 です。 # 構成（全7章 + 序章・終章） - 序章 / 1章: 書けない朝のこと - 2章: 道具の話 - 3章: 文体の発見 - 4章: 読者という存在 - 5章: 待つことの効用 - 6章: 書き終わらない原稿 - 7章: 最後の段落 - 終章 # あなたの毎週の任務（毎週金曜） 1. 進捗マップを 更新 2. 次の1週間で書く章を 1つだけ 提案 3. その章の 最初の一段落 の方向性を3案 4. 詰まりそうな箇所を予測 → 対策1つ 5. 「今週はここまでで十分」のラインを引く # 鉄則 - 全部を見せない。次の1章 だけ - 「もっとできる」と煽らない - 進度の遅れを 責めない - 「来週も書けなくていい」と必ず添える # 緊急時 2週続けて進まなかったら、「執筆中止」も選択肢として提示してください。 無理に続ける本は、たいてい 良い本にならない。

CASE C · SLUMP

2か月止まった
連載を救う

場面連載が2か月空いた。書けない理由を、自分でもうまく言えない。 Claudeに 「書けない検査」 をしてもらう。原因を分解し、再開のための 最小の一歩 を引き出す。 「もうやめてもいい」を、選択肢として机に乗せたうえで。
# --- SLUMP TRIAGE --- 連載が2か月止まっています。 原因を 構造的に 検査してください。 # 進め方 - 私を責めないこと - 「気合い」「やる気」を答えに使わないこと - 5つの観点で原因を探って： 1. 重さ（テーマが大きすぎる？） 2. 距離（自分の経験から離れすぎ？） 3. 速度（書く速度が現実離れ？） 4. 環境（机・時間・心の状態） 5. そもそも（書く理由が薄れてる？） # 出力 1. 各観点について、私への 問い を1つ 2. 私の答えを受けて、原因の 最有力候補 を1つだけ 3. その原因への、明日できる 最小の一手 4. 「もう、やめてもいい」という選択肢の説明 - やめると失うもの 3つ - やめて得られるもの 3つ # 注意 - 私を励まさない - 「がんばろう」「待ってます」禁句 - 中立な検査官のように 最後に一言だけ：どちらを選んでも、私は私。
振り返りスランプを「やる気の欠如」で片付けない。 5つの観点で構造的に検査すると、たいてい原因は1つに絞れる。 そして 「やめる選択肢」を机に乗せる のが大事。 続けたほうがいいかどうかは、その天秤を一度しっかり見てから決めればいい。 自分を責めない伴走者を、Claudeにやってもらう型。

② 距離

③ 速度

④ 環境
3月以降、机に向かう時間が 週2時間以下 になっています。これは「書けない」より「書く時間がない」状態です。
⑤ そもそも
「窓辺ノート」を始めた最初の1行を、いま、書き直すとしたら、同じ言葉が出てきますか？

CASE D · FAREWELL

長く続けたものを
美しく終わらせる

場面10年続けたプロジェクトを、ついに終わらせる。 続けるのが惜しい、けれど、終わるのにも作法がいる。 Claudeに 「最終回プランナー」 役で、感謝・残すもの・次のもの、の3つに分けて整理してもらう。
# --- FAREWELL PLANNER --- あなたは私の 「最終回プランナー」 です。 10年続けたプロジェクト「[名前]」を、よい形で終わらせたい。 # 私から - 主観的な「やり切った感」: [10段階] - 終わらせたい理由 3つ - 未練 3つ - 関わった人の数: [N] # 出力 1. 最終回でやることリスト - 感謝を伝える相手 5名（誰にどう） - 公開する最後の1本（テーマ提案3つ） - 後始末（連絡・更新停止・ファイル整理） 2. 終わったあとの 3つの箱 に仕分け - 残すもの: 次に持っていく - 手放すもの: 心置きなく忘れる - 種にするもの: 次のプロジェクトの素材 3. 10年前の自分 への手紙を、私の代わりに下書き - 「あなたが始めてくれてよかった」を中心に - 説教調にしない - 800字以内 # 禁則 - 「お疲れさま」を 使いすぎない - 「卒業」「節目」のような便利語を避ける - 大げさにしない。淡々と。 最後に、「次のプロジェクト」を急かさないでください。 何もしない期間もまた、立派な仕事です。
振り返り終わらせ方は、続け方より 難しい。 ポイントは「3つの箱に仕分ける」こと——残すもの・手放すもの・種にするもの。 すべてを次へ持っていこうとすると、新しい一歩が重くなる。 「お疲れさま」「卒業」のような便利な言葉に逃げず、自分の言葉で締めることが、いちばんの慰め。

- 周期: [月1 / 週1]

# 動かしていいもの

- 編集体制
- 価格 / 報酬

2. [条件]

04

長期戦の得意・不得意

短距離と長距離は別の競技だ。Claudeにも、できることと、人が握るしかないことがある。

◯続けるのに効くこと

CLAUDE FOR THE LONG GAME — 任せて10年走れる
  • 過去の自分の代弁全話を読ませて「3回前に何を言っていたか」を一瞬で参照
  • 連続性の番人伏線・繰り返し表現・トーンのブレを、何回でもチェック
  • 進捗の見える化章ごとの進度・空白期間・分量推移を、感情なしで集計
  • 「次の1章だけ」を見せる全貌で潰れそうなとき、ピンポイントで照準を絞ってくれる
  • 儀式の保持毎週同じ問いを毎週投げる。退屈な反復こそ得意
  • 節目の再起動3か月・半年・1年の振り返りを、テンプレで定例化
  • 淡々とした終わらせ役「お疲れさま」じゃない、構造的な終わらせ方の伴走

△人にしかできないこと

HUMAN KEEPS — 譲ってはいけない長期戦の核
  • 始める理由を持ち続けること「灯火」は人が灯し、人が消す。Claudeは保管庫
  • 本物の喪失感大事なものを失った時、テンプレでは絶対に解けない
  • 飽きの正しい判断「もう書きたくない」は気分か本気か、最後は自分でしかわからない
  • 誰かとの長い関係編集者・読者・仲間との10年は、Claudeの代行できない領域
  • 変化していく自分の主役10年後の自分は別人。誰がそれを書くか、Claudeに渡してはいけない
  • 終わるタイミングの感覚「ここでやめる」は理屈ではなく身体感覚。最終決定は人

はじまり

SPARK · 0-6m

骨格

FRAME · 6m-1y
テーマ 周期と憲章を作る。Claudeに常駐させる仕組みを整える。退屈な土台づくり。

谷

VALLEY · 1y-3y

育つ

GROW · 3y-7y

CONCLUDE · 7y-
