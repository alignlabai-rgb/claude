🔴 Claude / Anthropic

新研究Anthropic、ライフサイエンス研究ラボを新設——Claudeが自律的にCRISPR類似の新規酵素システムを発見

Anthropicはライフサイエンス研究グループを新設し、第一号の成果を発表。Claudeが自律エージェントとして21.5時間・949セッション・2.156億トークンを投じたキャンペーンの中で、バクテリオファージ由来の未知の酵素システム「ART」（逆転写酵素＋CRISPR様のDNA反復配列）を発見した。機能自体はまだ未解明だが、CRISPR開発に関わったMITのFeng Zhang氏も「本物に興味深い」と評価。

Source: Anthropic公式発表 / TechCrunch

アップデートClaude Code v2.1.281公開——デスクトップ向けゲートウェイ制御・Bedrockクロスアカウント対応を強化

Claude Code v2.1.281がリリース。Claude Desktop向けゲートウェイに`blockReadsOutsideWorkingDirectories`等のポリシーブロックを追加、Bedrockアップストリームでは`assume_role`によるSTS経由の別AWSアカウントアクセスと`guardrail`指定に対応。`settings.json`で`"attribution": false`によりcommit/PRの署名表示を無効化できるようになった。

Source: Claude Code Changelog

🟠 Grok / xAI

新モデルxAI、コーディング特化の最新モデル「Grok 4.7」を公開——パラメータ数はGrok 4.6比40%増の2.1兆

xAIは9月21日、より大きなベースモデルと長時間タスクに偏重した強化学習で訓練した「Grok 4.7」を公開。CursorBench 4.0で46.3%（Grok 4.6比+5.9pt）、DeepSWE v1.1で71.0%を記録。新しい安全対策スタックも導入し、価格はGrok 4.6と同じ$2/$6（100万トークンあたり）。Cursor・Grok Build・Grok APIなどで利用可能。

Source: xAI公式発表 / Android Headlines

🟠 動画生成

サービス終了OpenAI「Sora」API、9月24日で提供終了へ——Web/アプリ版は4月に終了済み

OpenAIはSora APIを9月24日付で完全に提供終了すると案内。Web・アプリ版のサービスは4月26日にすでに終了しており、今回でSoraの段階的シャットダウンが完了する。ユーザーには終了前のコンテンツ書き出しが求められており、猶予期間経過後はSora関連データが完全削除される。

Source: OpenAI Help Center / NewsBytes

🟡 Gemini / Google AI

開発状況Google DeepMind、次世代モデル「Gemini 4」がポストトレーニング初期段階に入ったと明言

Google DeepMindのSVP Koray Kavukcuoglu氏が「The Information AI Agenda Live Summit」でGemini 4が早期ポストトレーニング段階に入ったことを公表。「すでに有望な結果が出ており、できるだけ早く展開したい」とし、年内より前倒しの投入を示唆した（具体的リリース日は未定）。同時期にGrok 4.7・Opus 5.5・GPT-6 Sol/Lunaが相次いで発表され、フロンティアモデル競争が激化している。

Source: The Information AI Agenda Live Summit / Yahoo Finance
