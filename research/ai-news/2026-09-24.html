🔴 Claude / Anthropic

アップデートClaude Code v2.1.282公開——maxProseWidthとmanaged Chrome MCP対応を追加

Claude Code v2.1.282がリリース。ワイド端末でのプローズ幅を制限する`maxProseWidth`設定、プロジェクト設定でテレメトリが無効化・無視されている場合に起動時通知や`/status`・`claude doctor`で表示する機能、`allowClaudeInChromeWithManagedMcp`管理設定（排他的な managed-mcp.json と`claude --chrome`の併用を許可）を追加した。

Source: Claude Code Changelog

新機能Claude Tagがチャンネル内で個人コネクタの利用に対応

Slack向け「Claude Tag」（ベータ）が、チャンネル内でユーザー個人のコネクタ（カレンダー・ドライブ・CRM・ステージング環境など）を利用できるように更新。従来は管理者がチャンネルに付与したコネクタしか使えなかったが、個々のリクエストに応じて自分のコネクタを使わせられる。応答を都度レビューする方式と、機微情報がない限り自動投稿するAuto Modeを選択可能。まずTeamプランに展開、Enterprise対応は追って提供予定。

Source: Anthropic公式ブログ

🟠 クリエイティブMCP

連携拡大Adobe、Claude向けプラグインにAcrobatツールとDocument Reviewスキルを追加

Adobeは「Adobe for Claude」プラグインを拡張し、PDFの削除・結合・分割、機密情報の墨消し、他形式への変換・書き出しなど主要なAcrobat機能をClaude会話内から利用可能にした。新設のインタラクティブPDFエディタでページ並び替え・テキスト編集・コメント/ハイライト付与ができ、Claudeの新スキル「Document Review」が文書を分析してエディタ上に直接推奨事項・注釈を追加する。これでAdobeのツールは80種類超がClaude内で利用可能に。同日、Google GeminiにもPhotoshop/Lightroom/Express/Fireflyのツールが展開された。

Source: Adobe公式ブログ

🟠 動画生成

サービス終了OpenAI「Sora」API、本日9月24日付で正式に提供終了

3月24日の予告から半年の猶予期間を経て、OpenAIはSora APIの提供を9月24日付で完全終了した。Web/アプリ版は4月26日にすでに終了しており、これで2段階に分けたSoraのシャットダウンが完了。後継モデルや代替APIの提供はなく、API上に構築したプロダクトは他ベンダーへの移行を迫られる形となった。

Source: OpenAI Help Center

🟡 Gemini / Google AI

新機能Google、Geminiが企業に電話をかける「Call for Me」機能をテスト開始

GoogleはGeminiがユーザーに代わって企業へ電話をかける新機能「Call for Me」を発表。米国のPixel 11・Geminiサブスクリプション利用者向けにベータ版Phoneアプリ経由でまず展開する。ユーザーが許可した個人情報を通話中に共有できるなど、Geminiがより広い範囲のアクションを代行できるようになった。MetaのMuse／Instinctなど他社エージェントの同種機能に追随する動き。

Source: TechCrunch
