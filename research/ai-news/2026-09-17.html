🔴 Claude / Anthropic

新機能Anthropic、常時稼働の並列開発エージェント「Claude Code Projects」を発表

Anthropicは9月17日、Claude Codeに長期プロジェクト向けの新機能「Claude Code Projects」を導入した。目標とリポジトリを指定すると調整役（コーディネーター）が複数のワーカースレッドに作業を分割して並列実行し、リリース日の変更や承認者情報などの文脈を共有メモリとして数日〜数週間にわたり保持する。モデルや思考量の指定、プロジェクト単位の使用量トラッキングにも対応する。

Source: VentureBeat / Unite.AI / Anthropic

アップデートClaude、CoworkとチャットをひとつのアプリにUI統合——Docs・Slides・Designをベータ公開

Anthropicは9月16日、Claude CoworkとチャットUIを単一の製品に統合すると発表した。タスクがどちらに属するかをユーザーが判断する必要をなくし、Claudeが会話・プロジェクトの文脈を横断して対応する設計に変更した。あわせてClaude Docs・Claude Slidesをベータで追加し、これまで独立面だった「Claude Design」も会話内で直接使えるようになった。展開はPro・Maxプランから開始し、数週間かけてTeam・Freeへ拡大、エンタープライズ管理者には30日前通知を行う。

Source: Anthropic (claude.com) / SiliconANGLE

🟠 Grok / xAI

アップデートxAI、Grok Buildの長期記憶機能を一般提供開始（v1.0.34）

xAIは9月16日、開発ツール「Grok Build」の長期記憶機能を全ての新規セッションで一般提供（GA）にしたと発表した。プロジェクトの重要な決定事項や事実をセッションをまたいで自動的に保存し、一時的・機微な情報は除外する設計で、開発者は`/memory`・`/dream`コマンドで保存内容を管理できる。同日リリースのv1.0.34では、Markdown見出しのテーマカラー適用の不具合修正も行われた。

Source: KuCoin / x.ai Build Changelog

🟠 動画・画像生成ツール

業界動向OpenAI「Sora」API、9月24日に提供終了へ——Kling・Veoへの移行が加速

OpenAIが3月に予告したSora APIの提供終了が9月24日に迫っている（Web・アプリ版はすでに4月に終了済み）。移行先として、快手（Kuaishou）の「Kling 3.0」がマルチショット・ストーリーボードとFP対応の映像生成アリーナで首位を維持しており、GoogleのVeo 3.1もプロンプト忠実度とネイティブ音声対応で受け皿の一つとなっている。制作パイプラインでSora APIを利用している場合は移行対応が必要。

Source: OpenAI / Bloomberg

🟡 Gemini / Google AI

新製品Google、「話しながら考える」音声AI「Gemini 3.8 Live」を発表

Googleは9月15日、推論しながら発話できる新モデル「Gemini 3.8 Live」と、より複雑なタスク向けの「Gemini 3.8 Live Extended Thinking」を発表した。Extended Thinkingはツール実行を含む多段推論の最中でも音声で応答を続けられるのが特徴で、Artificial Analysisの音声対音声指標で82.6を記録したとしている。Gemini API・AI Studio・Gemini Enterprise・Search Live・Gemini Live・Google Workspaceへ順次展開する。

Source: 9to5Google / MarkTechPost / Google Blog
