🔴 Claude Code

GAClaude Code 2.1.198：Claude in Chrome 正式GA・バックグラウンドエージェント自動PR化

7月1日リリースのv2.1.198で、ブラウザ操作エージェント「Claude in Chrome」が正式GAに。あわせてバックグラウンドエージェントが完了時に自動でcommit・push・ドラフトPR作成まで行う機能、`Notification`フックによるバックグラウンドエージェント通知、チャート・ダッシュボード作成を支援する`/dataviz`スキルが追加された。サブエージェントもextended thinking設定を継承するようになった。

Source: Anthropic, GitHub Releases (anthropics/claude-code)

🟠 OpenClaw

ベータOpenClaw v2026.7.1-beta.1：GPT-5.6対応・外部ハーネスアタッチ・iOS刷新

7月2日公開のベータ版でOpenAI GPT-5.6モデルのカタログ・実行時選択対応を追加。既存Gatewayセッションに外部ハーネスを接続する`openclaw attach`、Telegram経由でCodexのペアリング開始・実行中セッションの操作・API障害時の返信復旧を行うワークフロー、コマンド終了を監視して起動する`on-exit`型のイベント駆動cronも新規実装。iOS版はiOS 26デザインに刷新され、iMessageでのネイティブ投票作成にも対応した。

Source: GitHub Releases (openclaw/openclaw), OpenClaw Docs

🟡 Gemini / Google AI

新モデルGoogle、画像生成モデル「Gemini 3.1 Flash Image」「Gemini 3 Pro Image」を公開

6月30日、Googleが新しい画像生成モデル2種をGemini APIおよびGoogle AI Studioで即日提供開始。Gemini 3.1 Flash Imageは入力$0.50・出力$3.00（100万トークンあたり）の低価格帯、Gemini 3 Pro Imageは入力$2.00・出力$12.00のハイエンド帯として、用途に応じた使い分けが可能になった。

Source: Google AI, Gemini API Docs

🟡 動画生成・クリエイティブAI

資金調達Kling AI、20億ドルの資金調達を発表・動画AI事業を拡大へ

7月2日、快手技術（Kuaishou）傘下のKling AIが少なくとも20億ドルの資金調達を発表。最大30億ドル規模まで拡大する可能性もあり、快手の持株比率は約68%まで希薄化する見通し。Sora終了発表以降ユーザー数が伸びている動画生成AI市場での投資拡大の動き。

Source: Bloomberg

追加Runway、API に Gemini Omni Flash と Seed Audio 1.0 を追加

6月30日、Runwayがプロンプト・画像・動画からの生成編集に対応する「Gemini Omni Flash」を有料プランに追加。同時にRunway APIでは、最大30秒の音声参照から音声・効果音を生成できる「Seed Audio 1.0」（テキスト読み上げ・効果音生成）も利用可能になった。

Source: Runway

🟡 エンタープライズAI

新機能Anthropic「Claude apps gateway」：Bedrock・Google Cloud・Azure Foundry横断の統合管理基盤

6月29日発表の「Claude apps gateway」は、Claude Codeの利用を一元管理するセルフホスト型ゲートウェイ。企業SSOログイン・ロールベースアクセス・ユーザー単位のコスト可視化に対応し、Claude API・Amazon Bedrock・Google Cloudへのルーティングとプロバイダー間フェイルオーバーも可能。同時期にClaudeがMicrosoft Foundry（Azure）でも正式提供され、主要3大クラウド横断の統合管理基盤が整った形。

Source: Anthropic, Claude Code Docs
