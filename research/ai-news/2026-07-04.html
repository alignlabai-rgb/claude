🔴 Claude Code

修正Claude Code 2.1.199：スキル連続起動対応・バックグラウンドデーモン安定化

7月2日リリースのv2.1.199で、`/skill-a /skill-b`のようなスキル連続起動が先頭のみでなく最大5件まで正しく読み込まれるよう修正。TLSプロキシ環境でのSSL証明書エラーへの即時ヒント表示、ストリーミング中のサーバーエラーで部分応答が破棄されなくなる修正、サブエージェントがレート制限時に無言で失敗せず親エージェントへ結果を返す修正、Linuxのバックグラウンドデーモンが不完全シャットダウン後に自身と全エージェントを約50秒毎に強制終了していた不具合の修正が含まれる。

Source: Anthropic, GitHub Releases (anthropics/claude-code)

🔴 OpenClaw / Hermes Agent

メジャーHermes Agent v0.18.0「The Judgment Release」：Mixture-of-Agents標準搭載・P0/P1バックログ完全解消

7月1日公開のv0.18.0は約1,720コミット・998件のマージ済みPR・949件のIssueクローズという大型リリース。複数モデルの推論を並列表示し集約する「Mixture-of-Agents」が標準機能として追加されたほか、Google Vertex AI経由でのGemini接続（OAuth2トークン自動更新付き）にも対応。リポジトリ内の全P0/P1課題をゼロ化し、今後もゼロを維持する方針を表明した。

Source: NousResearch, GitHub Releases (NousResearch/hermes-agent)

🟠 GPT / Codex

新機能OpenAI Codex：Computer UseがWindows対応・旧モデル選択を終了

CodexのComputer Use機能がWindowsに対応し、デスクトップアプリの画面認識・クリック・入力操作がWindows環境でも可能に。あわせてChatGPTサインインユーザー向けにGPT-5.3-CodexとGPT-5.2の選択提供を終了し、GPT-5.5・GPT-5.4系への移行を推奨。7月1日にはトレースログへのWebSocketペイロード誤記録を防ぐメンテナンスリリース（rust-v0.142.5）も実施された。

Source: OpenAI, GitHub Releases (openai/codex)
