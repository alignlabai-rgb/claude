🔴 Claude / Anthropic

新機能VS Code 1.128公開 — Claudeエージェントのマルチチャット対応でセッション内に複数チャットを並走可能に

7月8日リリースのVS Code 1.128で、1つのエージェントセッション内に関連する複数チャットを持てる機能が追加。各チャットは履歴・タイトル・モデル選択を個別に保持し、途中のターンから分岐して別アプローチを比較検討できる。フォルダに紐づかない質問用の「Quick Chat」も新設。あわせてCopilot Visionが正式提供（無料枠でも画像・PDF添付が可能に）。

Source: Visual Studio Magazine, ntcompatible

GAClaude、Microsoft Foundryで正式提供開始 — Azure環境でOpus 4.8・Haiku 4.5が利用可能に（欧州は当面対象外）

7月7日、AnthropicとMicrosoftはClaudeモデルのMicrosoft Foundry（Azure）での正式提供開始を発表。既存のAzure認証・課金・ガバナンス基盤上でClaude Opus 4.8・Haiku 4.5をMessages API経由で利用でき、プロンプトキャッシュや拡張思考にも対応。ただしInfoQによれば欧州企業は現時点でこの経路からのClaude利用ができない。

Source: Anthropic, Microsoft Azure Blog, InfoQ

🟠 GPT / OpenAI

GAOpenAI「GPT-5.6」（Sol/Terra/Luna）が7月9日に一般提供開始 — 米商務省の承認を経て制限解除

6月下旬から信頼できるパートナー約20社限定でプレビュー中だったGPT-5.6系列3モデルが、米政府の追加審査・協議を経て7月9日に世界向け一般提供を開始。旗艦のSolに加え、Sonnet 5と同水準の性能で半額を謳うTerra、最安のLunaが揃い、価格はSol $5/$30・Terra $2.50/$15・Luna $1/$6（100万トークンあたり入力/出力）。

Source: Engadget, VentureBeat, techmymoney

🟠 Grok / xAI

GASpaceXAI「Grok 4.5」が7月9日に一般公開 — 新基盤V9（1.5兆パラメータ）でOpus級性能を低価格実現

6月28日からのプライベートベータを経て、Grok 4.5が7月9日に一般公開。旧Grok 4系（V8-small）の約3倍規模となる新基盤「V9」（1.5兆パラメータ）を採用し、コーディング・エージェントタスクに特化。Musk氏は「Opus級だがより高速・低コスト」と発言し、価格は入力$2/出力$6（100万トークンあたり）とOpus 4.8（$5/$25）より大幅に安い。Cursorとの共同学習も明らかに。欧州展開は7月中旬以降の見込み。

Source: Axios, x.ai, CometAPI

🟡 ビジネス・導入事例

動向中国製AIモデル、米国内API利用の3〜46%に急伸 — AIスタートアップLindyはClaudeからDeepSeekへ全面移行

CNBCが7月7日に報じたところでは、OpenRouter経由の米企業トークン利用に占める中国製モデルの比率が2月8日以降毎週30%を超え、最大46%に達した（2025年通年平均は11%）。中国のオープンモデルは主要な米製フロンティアモデル比で60〜90%安価とされ、AIエージェント企業Lindyは6月に全トラフィックをClaudeからDeepSeekへ移行、CEOは「コスト曲線が地に落ちた」と証言した。

Source: CNBC, Techstrong.ai
