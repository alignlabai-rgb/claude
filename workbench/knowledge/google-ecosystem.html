2. 製品別ガイド

核となる製品を、用途と確度バッジ付きで個別に解説します。

Gemini CANON

フロンティアLLM。テキスト・コード・画像・音声・動画をネイティブに扱う Google の主力モデル群。

  • 最上位 = Gemini 3.1 Pro（2026/2/19）。1M トークン、ARC-AGI-2 77.1%、SWE-bench Verified 80.6%。最高品質の推論・設計・コーディングはこれ。
  • 3.5 Flash：同等性能を高速・低コストで。Gemini アプリと検索 AI Mode のデフォルト。
  • Omni / Omni Flash：任意入出力のマルチモーダル（動画生成を統合）。
  • 3.5 Pro は延期（未提供）。出荷済みと混同しないこと。

💡 深掘りは gemini.html、最新動向は gemini-recent-updates.html。

Gemma 4 OPEN

Google のオープンウェイト／ローカル LLM。Apache 2.0・商用無料。プライバシー重視・オフライン・Fine-tuning が必要なケースで Gemini API の代替になる。

  • 4モデル: E2B（2.3B、スマホ/Raspberry Pi）/ E4B（4.5B、ラップトップ）/ 26B MoE（3.8B 活性、Arena AI 6位）/ 31B Dense（最高精度、Arena AI 3位 スコア1452）
  • 256K コンテキスト・140以上の言語・マルチモーダル（テキスト＋画像、小モデルは音声も）
  • MMLU Pro 85.2% / AIME 2026 89.2% / LiveCodeBench 80.0%（Llama 4 の77.1%を上回る）
  • Ollama で ollama run gemma4:27b 一行で即実行。QLoRA なら 16GB VRAM で1時間 Fine-tuning 可能。

📖 詳細は gemma.html — 4モデル比較・Ollama セットアップ・Fine-tuning ガイド・実例12選・Llama 4/Phi-4 との比較を掲載。ローカル LLM 全般は slm-guide.html も参照。

Veo CANON

動画生成モデル。業界初の映像・音声同時生成を実現した Google の動画 AI 基盤。Flow UI の裏側エンジンであり、Vertex AI API からも直接利用できる。

  • 最新版 Veo 3.1（2025-11-17）: 4K / 最長60秒 / 口パク精度 ±120ms
  • 3バリアント: Lite（0クレジット）/ Fast（20 credits, ~$0.10〜0.15/秒）/ Quality（100 credits, ~$0.20〜0.40/秒）
  • Runway Gen-3・Kling・Sora を超える音声同時生成が最大の差別化。
  • Vertex AI API で veo-3.1-fast-generate-001 を Python から直接呼び出し可能。

📖 詳細は veo.html — モデル進化史・スペック表・API コード例・実例12選・Sora/Runway/Kling 比較を掲載。

Flow

AI フィルムメイキングツール。Veo 3.1 + Imagen 4 + Gemini を組み合わせた映像制作プラットフォーム。テキスト1行から映像・環境音・台詞を同時生成し、Scenebuilder でショットをタイムライン編集できる。

  • エンジン Veo 3.1（2025年10月）: 4K / 最長60秒 / 口パク精度 ±120ms / Lite バリアント = 0クレジット
  • 275M+ 動画生成・140+ か国展開（2026年5月時点）
  • I/O 2026: Flow Agent（自然言語で多段制作タスクを自動実行）／Flow Tools（ノーコードカスタムワークフロー）
  • 料金: Free（50 credits/日）/ AI Pro $19.99（1,000 credits）/ AI Ultra $249.99（25,000 credits）

📖 詳細は flow.html — Veo 3.1 スペック・プロンプトガイド・実例12選・Sora/Runway/Kling との比較を掲載。

Antigravity CANON

エージェント開発基盤。当初は「Gemini CLI 的なツール」だったが、I/O 2026 で総合基盤へ拡張。

  • Antigravity 2.0 は Desktop IDE + CLI + SDK + Managed Agents + Enterprise の5コンポーネント構成。
  • デフォルトエンジンは Gemini 3.5 Flash。Gemini CLI は Antigravity CLI へ移行。
  • エージェントの自律実行・オーケストレーションを構築したい開発者向け。

💡 深掘りは anti-gravity.html。

NotebookLM

ソース接地型リサーチ AI。PDF・YouTube・Google ドキュメントなど自分が持ち込んだ資料のみを参照して回答する。ハルシネーションが少なく、全回答に引用が付く。

  • Audio Overview：資料から AI ホスト 2 名のポッドキャストを自動生成（移動中に聴ける）。
  • 50 ソース / ノートブック（無料）、300 ソース（Plus）。最大 25M トークンのコンテキスト。
  • スタディガイド・ブリーフィング・タイムライン・マインドマップを自動生成。
  • 無料プランあり。Plus は Google One AI Premium（¥2,900/月）に含まれる。
  • NotebookLM → ブリーフィング → Gemini Pro に渡して深掘り、というワークフローが強力。

📖 詳細は notebooklm.html（料金・Audio Overview・API連携・実践ワークフロー）

Google AI Studio

Gemini API の無料開発プレイグラウンド。ブラウザから全 Gemini モデルを試せる。プロンプトが固まったら Python/JS コードをワンクリックでエクスポートして本番に持ち込める。

  • 無料枠大：Flash は 1,500 req/日 無料。クレジットカード不要。
  • マルチモーダル：テキスト・画像・音声・動画・PDF をネイティブ対応。
  • Google 検索グラウンディング：リアルタイム Web 情報を参照できる。
  • Function Calling・JSON モード・Fine-tuningも GUI から設定可能。
  • プロトタイプ → AI Studio、本番スケール → Vertex AI への移行が自然なフロー。

🛠 詳細は ai-studio.html（料金・モデル比較・コード例・Vertex AI との使い分け）

Imagen 4 Whisk → Flow 統合済み

AI 画像生成モデル。Imagen 4 はテキストから最大2K解像度の画像を生成。旧 Whisk（画像リミックスツール）は 2026年4月30日に終了し、機能は Flow に統合された。ImageFX も Flow に合流。

  • 3バリアント: Fast（$0.02/枚・約2.7秒）/ Standard（$0.04/枚）/ Ultra（$0.06/枚・最高精度）
  • SynthID 透かし全出力に自動付与・8言語プロンプト対応（日本語含む）
  • Flow の Ingredients 機能の基盤: Imagen 4 Ultra で生成したキャラを Veo 動画で一貫して使える
  • ⚠️ Whisk は EOL（2026/04/30）: 参照画像リミックスは Flow で代替可能

📖 詳細は imagen.html — 3バリアント比較・Whisk EOL 詳細・実例12選・Midjourney/DALL-E/Firefly との比較・プロンプトガイドを掲載。

Gemini Spark I/O 2026

24/7 クラウド常時稼働パーソナル AI エージェント。ノートを閉じても・スマホをロックしても Google Cloud 上でタスクを実行し続け、完了時に通知。Gemini モデル + Antigravity ハーネス構成。AI Ultra 先行ベータ（米国）。

  • Gmail ネイティブ統合: 専用 Gmail アドレスでメール経由タスク依頼・受信箱トリガー自動化
  • Chrome ウェブ操作: 複数サイトまたがるリサーチ・フォーム入力・データ収集を自律実行
  • MCP 30+ ツール: Adobe・Dropbox・Uber 等のサードパーティツールと連携
  • 高リスクアクション（メール送信等）は明示的承認が必要。定期・スケジュールタスク対応。

📖 詳細は gemini-spark.html — 従来 Gemini との違い・6主要機能・vs Jules 比較・10ユースケース・セキュリティ考慮事項を掲載。

Vertex AI CANON

エンタープライズ向け ML プラットフォーム。Cloud Next 2026 で「Gemini Enterprise Agent Platform」に再ブランド。Gemini はもとより Claude / Llama / Mistral / Gemma も含む 200+ モデルを SLA 付きで提供する Google Cloud の本番 AI 基盤。

  • Model Garden 200+: Gemini 全系列 + Claude on Vertex（Opus / Sonnet / Haiku 一級市民）+ Llama 4 / Mistral Large / Gemma 4
  • Batch API 50% OFF（非同期推論）・RAG Engine Serverless（Public Preview）・Agent Builder（ノーコードエージェント）
  • Provisioned Throughput: 専用容量でレート制限なし・VPC Service Controlsでデータ境界を完全隔離
  • Firebase AI で Flutter / React Native アプリから直接 Gemini 呼び出し可能。65% エンタープライズ ML ワークロード・97% 更新率。

📖 詳細は vertex-ai.html — AI Studio との比較表・Model Garden・RAG Engine コード例・Batch API・Claude on Vertex・Firebase AI・12実例・エンタープライズ移行チェックリストを掲載。

Gemini Advanced CANON

コンシューマー向け高機能 Gemini アプリ。Gemini.google.com で利用する有料プラン群。Deep Research・Gems・Canvas・Gemini Live・Jules コーディングエージェントなど、開発者以外がフル性能の Gemini を活用するための「人間向けインターフェース」。

  • 4プラン: Free / AI Plus $7.99 / AI Pro $19.99 / AI Ultra $249.99（Antigravity 付き）
  • Deep Research: 数百の Web + Gmail / Google Drive を横断して 5〜15 分・10〜20 ページのレポートを自動生成（出典付き）
  • Gems（カスタム AI エージェント・Drive ライク共有）/ Canvas（インタラクティブ可視化・クイズ・Audio Overview）/ Gemini Live（リアルタイム音声）
  • Jules コーディングエージェント + 1M コンテキスト + Google Workspace AI（Docs / Sheets / Gmail / Meet / Vids）統合

📖 詳細は gemini-advanced.html — 4プラン比較・Deep Research 活用法・Gems 設計・Canvas 実例・Workspace AI 連携・Jules・日本向け Google One AI Premium（¥2,900/月 = AI Pro + NotebookLM Plus + 2TB）を掲載。

Google Opal LABS

ノーコード AI アプリビルダー。Google Labs 発のビジュアルワークフローツール。プログラミング不要で Gemini・Imagen・Veo をノードエディタでつなぎ合わせ、URL で共有・公開できる AI ミニアプリを数分で作成できる。

  • 基本3ブロック: User Input → Generate（Gemini / Imagen 4 / Veo 3）→ Output（Docs / Sheets / Slides / URL 共有）
  • Agent Step（2026年2月〜）: Gemini 3 Flash 搭載のゴールベース自律処理・動的ルーティング・セッション間メモリ保持
  • テンプレートギャラリー: ブログライター・動画マーケ・サポートトリアージ・コンテンツリパッケージなど多数
  • 無料ベータ（2026年5月時点）。opal.google.com または Gemini アプリ内「実験的 Gems ビルダー」からアクセス。

📖 詳細は opal.html — 基本ブロック・Agent Step・Workspace 連携・12ユースケース・Opal vs AI Studio / Gemini Advanced / Antigravity 比較表・ステップバイステップビルド手順を掲載。

Jules CODING AGENT

非同期 AI コーディングエージェント。GitHub Issue を割り当てるだけで、隔離された Google Cloud VM でコードを実装してPR を開いて完了報告する。「一緒に書く」ではなく「任せて待つ」設計。2025年8月GA。

  • 非同期バックグラウンド実行: Issue → VM でリポクローン → 実装・テスト → PR 作成の完全自動フロー
  • CI 自動修復: PR の CI が落ちると Jules が自動でログ解析・修正・再プッシュ
  • Scheduled Tasks: 週次依存更新・夜間リントフィックスなどを定期実行
  • Jules API / MCP: CI/CD・Slack・Linear・Jira 等に組み込んで自動化。Linear / Neon / Supabase 等と MCP 連携

📖 詳細は jules.html — 非同期フロー図・3プラン料金・Scheduled Tasks・Jules API コード例・vs Claude Code / Codex / Copilot Workspace 比較・8ユースケースを掲載。

Gemini Live REALTIME

リアルタイム音声・映像 AI。Project Astra の能力を一般公開したモード。スマホのカメラや画面を共有しながらリアルタイムで話しかけると AI が即座に返答。割り込みも自然。2025年5月から全ユーザー無料。

  • カメラ共有: スマホのカメラ映像を見ながらリアルタイムで「これ何？」「どう直す？」と会話
  • スクリーン共有: アプリのバグ・設定・エラー画面を共有しながらトラブルシューティング
  • Google サービス連携: Calendar・Keep・Tasks・Maps を会話で参照
  • Android XR スマートグラスに統合。全プラン（無料含む）で利用可能。

Google Workspace AI ENTERPRISE

4. 創作（クリエイト）視点 — どう組み合わせるか

自動コンテンツ量産の観点で Google 製品を組み合わせる場合の一般的な役割分担を示します（具体的な制作物・IP は本ハブでは扱いません）。

  • 企画・台本・構成：Gemini 3.1 Pro で全体設計・脚本・プロンプト設計を詰める。大量資料があるなら NotebookLM で素材を整理・要約してから渡す。
  • 量産の高速化：定型処理・大量バッチは Gemini 3.5 Flash に寄せてコストと速度を稼ぐ。機密素材やオフライン処理は Gemma 4 をローカルで。
  • ビジュアル：静止画は Imagen / Whisk、動画は Veo、作品としての組み立ては Flow。
  • 仕組み化：上記を手作業でなくパイプラインとして回すなら、AI Studio で検証 → API/Vertex AI で実装 → Antigravity でエージェント化、という流れが素直。

💡 ポイントは「1製品で全部やろうとしない」こと。推論は Gemini、量産は Flash、ローカルは Gemma、映像は Veo/Flow、静止画は Imagen、音楽は Lyria、土台は AI Studio→Vertex AI、コード自動化は Jules、長期タスク委任は Gemini Spark、リアルタイム会話は Gemini Live、ビジネス効率化は Workspace AI、自動化は Antigravity、チームへの展開は Gemini Advanced、ノーコード AI アプリは Opal と役割で割り当てると、増え続ける製品群でも判断が安定します。
