Page Template — 新規ページの boilerplate

このハブで新しいページを作る時の標準テンプレートです。コピペで使えるよう、HTML 全文・CSS・主要コンポーネントをこのページ内に置きました。あわせて スタイルガイド を読むと、執筆の細部ルールが揃います。

テンプレートの選び方

このハブには現状 2 系統の CSS スタイルが共存しています。用途で使い分けてください。

系統用途既存例
Light（明るめ #0b1220） ナビゲーション・運用ドキュメント・参照系（Foundations / Strategy / Logs） glossary.html / decisions.html / hub-health.html
Rich（深め #07111d、CSS 変数あり） 長文記事・LLM トラッカー・トレンド分析（research/* の大半） claude-recent-updates.html / trend-ipo-race.html
判断基準: 「ハブ運用カテゴリ（Foundations / Strategy / Logs）の中の参照ドキュメント」なら Light。「外部に見せるかもしれない長文・分析・トラッカー」なら Rich。迷ったら Light（軽量・統一感優先）。

新規ページ作成のチェックリスト

  1. カテゴリを決める（CLAUDE.md の Folder Rules 参照）
  2. Light / Rich のどちらかを判断（このページの選び方表）
  3. テンプレートをコピー、title と breadcrumb を設定
  4. 本文を書く（スタイルガイド に従って）
  5. 末尾に「最終更新: YYYY-MM-DD」を明記（Light は .small、Rich は .last-update）
  6. 「関連」セクションで親カテゴリ・関連ページへの戻り導線を入れる
  7. 親カテゴリの index.html にこのページへのリンクを追加
  8. 必要なら top index.html のカードにも surface
  9. Site Map に追記
  10. 大きな構造変更なら ADR を書く

関連

  • スタイルガイド — 文体・色・命名の統一ルール
  • Site Map — 全ページ索引（新規追加時の参照先）
  • 決定ログ (ADR) — 構造変更の経緯
  • Onboarding Checklist — セッション開始ルーチン
