組織へ取り込むときの最小記録

providerの「最新」を並べるだけでは運用知になりません。同じ候補を比較できるよう、次の5点を一緒に残します。

01 SURFACEchat / API / coding agent / local weightsを分離
02 CONTRACTmodel ID、履歴、tool schema、parameter制約
03 EFFECTIVEchecked_at、提供開始、価格変更、sunset
04 HARNESSfixture、success、token、elapsed、retry、介入
05 BOUNDARYlicense、公開、credential、cost、不可逆操作
