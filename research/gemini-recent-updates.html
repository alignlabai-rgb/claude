Antigravity 2.0 の意味 — Gemini 版「エージェント開発基盤」

Antigravity は当初「Gemini CLI 的なツール」でしたが、I/O 2026 で 5 つのコンポーネントを持つ総合エージェント開発基盤に拡張されました。

① Antigravity Desktop (IDE)

GUI で managed / deployed agents を構築。Google の各 dev surface（Studio・Cloud）と統合。

② Antigravity CLI

ターミナル中心の開発者向け軽量サーフェス。Gemini CLI からリブランド。Android CLI も新規追加。

③ Antigravity SDK

Google 自身のプロダクトで使われているエージェント harness にプログラムでアクセス。カスタムエージェント定義・自社インフラ運用が可能。

④ Managed Agents (Gemini API)

単一の API コールでリモートサンドボックス付きのエージェントをプロビジョン。Linux 隔離環境でツール使用・コード実行。Claude Managed Agents への対抗。

⑤ Gemini Enterprise Agent Platform

Antigravity を Google Cloud プロジェクトに直接接続。エンタープライズワークロードを簡素化。

⑥ Powered by Gemini 3.5 Flash

Antigravity 2.0 のデフォルトエンジン。フロンティアインテリジェンスを 4 倍速で動かす。

Gemini Spark / Workspace 統合の意味 — 「先回り型エージェント」戦略

Gemini Spark は対話型ではなく「先回り型」のエージェントとして設計されています。 ユーザーが指示する前に Daily Brief を作り、メール・予定・タスクの優先順位を提示する。

  • Gmail / Docs / Slides / カレンダーとディープ統合。ユーザーの「過去の動き」から次のアクションを推測
  • Docs Live：音声で「brain dump」して Gemini に整理させる。今夏ロールアウト
  • Daily Brief：朝のパーソナライズブリーフィング。AI Ultra から先行
  • Neural Expressive：Gemini の新しい視覚デザイン言語（dynamic・vibrant）

Claude が「Cowork で業務を協働」、ChatGPT が「Workspace Agents で組織共有エージェント」と発展したのに対して、 Gemini は「Google が既に持っている個人データ資産（Gmail / カレンダー / 検索履歴）を活かした proactive personal AI」というGoogle だけが取れる戦略。

Android XR と OS レベルの統合

I/O 2026 で Google が示した最大の差別化は、OS / ハードウェアレベルで Gemini を統合することです。

  • Android XR スマートグラス（"intelligent eyewear"）：今年秋発売予告。Gemini が視界の中に存在する形へ
  • Android 17：Gemini を OS にネイティブ統合。アプリ横断のエージェント実行
  • Aluminum OS：新 OS の初公開（詳細は I/O での発表に基づく）
  • Gemini Intelligence：Galaxy / Pixel 向けに今夏から段階展開

Claude / ChatGPT が「アプリ / ブラウザ / CLI 上で動く」に対し、Gemini は「OS とハードウェアの中に組み込まれる」方向。 AI Overviews（検索内表示）が既に 2.5B MAU に到達していることがこの戦略の土台。

注意点とリスク

  • モデル名の混乱：Gemini 3 Pro / 3 Flash / 3 Deep Think / 3.1 / 3.2 Flash / 3.5 / 3.5 Flash / Omni / Omni Flash と数ヶ月で次々追加され、API のモデル ID 管理が複雑化。
  • Gemini CLI → Antigravity CLI のリブランド：旧 CLI を使っている開発者は移行が必要。CLI スクリプト・CI 統合は要更新。
  • Gemini Spark の権限粒度：Gmail / Docs / カレンダーへの広範なアクセスを前提とするため、エンタープライズでは IT ガバナンス審査が必要。
  • マルチモデル戦略の負荷：Gemma 4 + Gemini 3.5 + Antigravity Managed Agents という多軸構成で、企業は「どこに何を使うか」判断が複雑に。
  • Android XR スマートグラスのプライバシー：視界内 AI は EU の AI Act・GDPR との関係で慎重な展開が必要。Brussels は AI 'nudifier' アプリを禁止する動きも（教皇回勅の文脈と並行）。
