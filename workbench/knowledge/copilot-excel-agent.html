01

エージェントモードとは — Plan/Act/Validate サイクル

正式名称：2026年4月22日の GA（一般提供開始）時に "Agent Mode" から "Edit with Copilot" に改称。Build 2026（5月19〜21日）でデフォルト機能となりました。本ガイドでは通称「エージェントモード」を使用します。
観点旧 Copilot（サイドパネル）エージェントモード（Edit with Copilot）
動作方式提案・回答のみ（ユーザーが実行）自律的にマルチステップ操作を実行
実行計画なし実行前に可視化された実行プランを提示（ユーザーが承認）
変更プレビューなし紫色ハイライトで変更予定セルを事前表示
連続実行1ステップずつ手動確認エージェントが自律ループで連続実行
検証シートなし処理後に照合・検証シートを自動生成
LLM 選択なしGPT-5.5 / Claude Opus 4.8 等から選択可能
成果物部分的なテキスト提案完成したチャート・数式・ピボット・シート一式

Plan → Act → Validate のサイクル

  1. Plan：自然言語のプロンプトを受け取り、Copilot が「どのシートを操作するか・どの数式を作るか・何を出力するか」の実行計画を提示。ユーザーが内容を確認・調整できる。
  2. Act：ユーザー承認後、Copilot がワークブックを直接編集。数式作成・ピボット生成・グラフ配置・新シート追加を自律的に連続実行。変更セルは紫色でプレビュー表示される。
  3. Validate：実行後に照合シート（Reconciliation Sheet）を自動生成し、変更内容・行数・差異を記録。共有ブックでは「Copilot edited」ラベルで変更箇所を明示（Show Changes 機能）。
  4. Iterate：結果を見てさらに追加指示。「グラフの色を変えて」「列を追加して」と自然言語でフィードバックを続けられる。

有効化・アクセス方法

前提条件：ファイルは OneDrive または SharePoint に保存し、自動保存（AutoSave）を有効にする必要があります。ローカルファイルでも基本機能は動作しますが、フル機能は OneDrive/SharePoint 保存ファイルで利用可能です。

デスクトップ Excel（Windows/Mac）

  1. ファイルを OneDrive/SharePoint に保存して自動保存を確認
  2. リボン「ホーム」→ 「Copilot」 ボタンをクリック
  3. 右側に Copilot ペインが開く（Build 2026 以降はデフォルトでエージェントモード）
  4. ペイン上部の モデルピッカー から使用 LLM を選択
  5. プロンプト入力欄にタスクを入力

Excel Online（Web ブラウザ）

  1. OneDrive / SharePoint でファイルを開く
  2. 右上の 「Copilot」 ボタンをクリック
  3. Copilot ペインが開く（機能はデスクトップ版と同等）
  4. モデル選択も同様に対応
  5. Microsoft 推奨：機能の早期アクセスは Web 版先行が多い

LLM モデル選択ガイド

Copilot ペイン上部のモデルピッカーでいつでも切り替え可能。タスクに合わせて選ぶと精度が大きく変わります。

Claude Opus 4.8Anthropic2026年5月末追加。複雑なマルチステップ・長期タスクに最適化財務モデル・複合分析・長文データ処理
Claude Opus 4.7Anthropic2026年4月追加。高速・ツール選択の精度向上反復処理・複数シート操作
Think Deeper—長時間推論モード。精度優先・速度は遅いロジック検証・複雑な多ステップ設計

04

コア機能詳解

数式

Formula AI — 数式生成・修復

目的を日本語で説明すると SUMIFS・XLOOKUP・配列数式・Lambda 等を自動生成。入力中に自動補完（Formula Autocomplete）も機能。壊れた数式の自動検出・修復にも対応。

可視化

グラフ・ピボット自動生成

棒グラフ・折れ線・散布図・ウォーターフォール・コンボチャートを自動作成。PivotTable + PivotChart のペアを一括生成。KPI カード付きのサマリーシートも構築可能。

書式

条件付き書式・ハイライト

「売上目標未達を赤でハイライト」「上位 10% を緑で強調」など自然言語で書式ルールを設定。複合条件・カスタムルールの自動生成に対応。

整理

データクリーニング

空白セル・重複行・フォーマット不統一を自動検出・修正。テキスト正規化（全角/半角・大文字/小文字）も指示1つで実行。クリーニング結果のサマリーシートを自動生成。

透明性

Show Changes — 変更追跡

共有ブックで Copilot が編集した箇所に「Copilot edited」ラベルを表示。変更箇所・変更内容・タイムスタンプを記録。AI の編集と人間の編集を明確に区別。

統合

Copilot Notebooks → Excel

Copilot アプリで作成したノートブック（会議メモ・リサーチ等）から構造化 Excel ファイルを自動生成。「このノートブックから Excel スプレッドシートを作成して」で起動。

05

=COPILOT 関数 — セルレベル AI

新機能：=COPILOT() は Excel のセルに直接入力できる AI 関数です。Azure 上の AI モデルを呼び出し、動的な結果をセルに返します。ルックアップテーブルなしでデータを取得・変換できます。
=COPILOT("プロンプトをここに入力")

活用例

数式例返値
=COPILOT("G7諸国と現在の中央銀行金利を一覧で")各国・金利のリストを動的生成
=COPILOT("A2の商品名から業界カテゴリを推定して")カテゴリラベルをセルに返す
=COPILOT("B2の文章を英語に翻訳して")翻訳結果をセルに返す
=COPILOT("C2のテキストから感情（ポジティブ/ネガティブ）を判定して")感情ラベルをセルに返す
=COPILOT("最新の為替レート（USD/JPY）を取得して")ウェブ検索でリアルタイム取得（Insider 展開中）
ウェブ検索統合：=COPILOT 関数からのウェブ検索（リアルタイムデータ取得）は 2026年6月時点で Insider チャンネルへ展開中です。一般リリースは後続予定。
06

Python in Excel × Copilot

Copilot エージェントモードは Python in Excel と統合されており、自然言語で高度な統計・機械学習・データサイエンス操作を実行できます。Python コードを書く必要はありません。

統計

記述統計・相関分析

「このデータの記述統計と相関行列を計算して」→ pandas/scipy を使った統計分析コードを自動生成・実行。結果を Excel シートに構造化して表示。

予測

回帰・予測モデル

「売上予測の線形回帰を作って」→ scikit-learn コードを生成して係数・R²値・残差グラフを出力。Monte Carlo シミュレーション（1,000 回）も1プロンプトで実行可能。

可視化

高度なグラフ（matplotlib/seaborn）

「相関ヒートマップを作って」「ボックスプロットで分布を見せて」→ Python ベースの高品質グラフを生成し、シートに挿入。カスタム SVG 出力も Python コード経由で可能。

財務

財務モデル自動化

「仮定シートの GrowthRate・COGS 率を使って3年間の損益計算書を作成して」→ Python で三表連動モデルを構築。感度分析テーブルも自動生成。

Python in Excel の要件：Microsoft 365 の Python 対応プランが必要です。組織ポリシーで無効化されている場合があります。計算は Microsoft Cloud の分離された安全な環境（Anaconda）で実行されます。
07

Work IQ — 自動グラウンディング

Work IQ は Microsoft Graph に基づくコンテキスト層で、Excel でのエージェント編集中にメール・Teams・SharePoint・カレンダーの関連情報を自動取り込みします。@メンション等の手動指定は不要です。

📁 ファイルコンテキスト

「先月の売上報告書（SharePoint）を参照してこのシートを更新して」→ ファイルを直接コンテキストとして取り込み、シートと統合。

📧 メール・Teams 参照

「先週の顧客フィードバックメールの要点を集めてこのテーブルに追加して」→ Exchange メール・Teams チャットを参照してシートに反映。

📅 会議・カレンダー連携

「先週のミーティング議事録から決定事項をリストアップしてシートに構造化して」→ Teams 会議の文字起こしをアクションリスト化。

Work IQ API（2026年6月2日発表、6月16日 GA）：開発者向けに Chat・Context・Tools・Workspaces の4系統 API が公開されました。サードパーティアプリから Work IQ を活用した Excel 連携が可能になります。

実践プロンプト集 20 選

📊 データ分析・洞察（5選）

PROMPT 01

全体分析サマリー

このシートのデータを分析して、主要なトレンド・外れ値・改善が必要な点を3〜5項目で教えてください

最初の一手として使える万能プロンプト。全体俯瞰に最適。

PROMPT 02

前年比較

売上データの前年同期比を計算して、成長率・減少率の上位5項目をサマリーシートにまとめてください

YoY 比較 + 自動サマリーシート生成まで一括実行。

PROMPT 03

外れ値検出

このデータから IQR 法で統計的外れ値を検出し、対象セルを黄色でハイライトして検出サマリーをSheet2に出力してください

Python in Excel 経由での統計的外れ値検出と書式設定を組み合わせ。

PROMPT 04

財務モデル生成

仮定シートの GrowthRate・COGSMargin・SGA% を使って3年間の損益計算書・貸借対照表・キャッシュフロー計算書を作成してください

三表連動モデルを Claude Opus 4.8 + Python in Excel で一括構築。

PROMPT 05

Monte Carlo シミュレーション

売上に対してMonte Carlo シミュレーション（1,000回試行）を実行し、平均・標準偏差・95%信頼区間をSheet3に表示してください

Python in Excel で確率的シミュレーション。リスク分析に。

📈 ダッシュボード・可視化（5選）

PROMPT 06

KPI ダッシュボード

Sheet1のデータを使って「ダッシュボード」シートを新規作成し、売上・利益率・前月比のKPIカードと複合チャートを配置してください

マルチシートのダッシュボードを一括構築。経営会議用資料に直結。

PROMPT 07

ウォーターフォール

収益からコストを差し引いた利益構造をウォーターフォールチャートで可視化して、財務サマリーシートに配置してください

財務構造の視覚化に最適な定番チャートを自動生成。

PROMPT 08

感度分析テーブル

価格と販売量の2軸感度分析テーブルを作成して、営業利益がゼロ以下のセルを赤でハイライトしてください

What-If 分析の定番。条件付き書式との組み合わせで視認性向上。

PROMPT 09

複合グラフ

売上（棒グラフ・左軸）と利益率（折れ線・右軸）の複合グラフをSheet2に作成してください

2軸グラフの自動設定。月次レポート用グラフに最適。

PROMPT 10

スパークライン一括追加

各行の12か月推移を示すスパークラインをN列に一括追加し、最大値セルを緑・最小値セルを赤で強調してください

全行にスパークライン + 条件付き書式を自動配置。

⚙️ データ処理・整理（5選）

PROMPT 11

マルチシート統合

3つの地域別販売シートを「統合」シートに集約し、行数・合計の照合シートを作成して差異があれば赤でフラグを立ててください

Plan/Act/Validate の真価が発揮されるマルチシート処理。

PROMPT 12

データクリーニング

このシートのデータを整理してください：重複削除・日付フォーマット統一・C列の空白をフラグ・整理結果のサマリーをSheet2に出力

複合クリーニング処理を1プロンプトで指示。

PROMPT 13

高度な数式生成

A列の商品コードをD列の商品マスタと照合し、一致した場合のE列単価を返す数式をB列に作成してください。見つからない場合は「未登録」と表示

XLOOKUP / IFERROR の組み合わせ数式を自然言語から自動生成。

PROMPT 14

重複検出

A列とB列の組み合わせで重複している行を検出し、C列に「重複」フラグを立てて黄色でハイライトしてください

PROMPT 15

ピボット一括生成

このテーブルを元に部門別・月別・商品カテゴリ別の3つのピボットテーブルをそれぞれ別シートに作成してください

複数ピボットの並行生成。エージェントの多ステップ実行能力を最大活用。

ライセンス・制限・注意点

項目詳細
必要ライセンスMicrosoft 365 Copilot アドオン（約 $30/ユーザー/月）。M365 Business Standard/Premium または E3/E5 に追加。
ファイル保存先OneDrive または SharePoint への保存 + 自動保存（AutoSave）有効が推奨。ローカルファイルでも基本機能は動作。
Claude モデルIT 管理者による Anthropic サブプロセッサ有効化が必要。EU/EFTA/UK ではデフォルト無効（データ規制）。政府クラウド（FedRAMP）は未対応。
Python in Excel追加の Microsoft 365 Python 対応プランが必要。組織ポリシーで無効化されている場合あり。
大規模ファイル非常に大きなファイル（数十 MB 以上）では応答が遅延。必要範囲にデータを絞ることを推奨。
SVG・フローチャートExcel Copilot の公式機能としての SVG 直接出力・フローチャート生成は文書化されていません。Python in Excel（matplotlib）を使ったカスタム図表生成は技術的に可能です。
データプライバシーWork IQ は Microsoft Graph のアクセス権に基づいてデータを参照。権限のないファイルは参照されません。
重要：Copilot が生成した数式・財務モデル・ピボットは必ず確認してください。特に財務データを扱う場合、生成された数式の正確性を手動で検証することを強く推奨します。
