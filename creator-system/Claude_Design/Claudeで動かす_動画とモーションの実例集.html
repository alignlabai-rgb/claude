CASE A · STORYBOARD

30秒の商品紹介
絵コンテ4カット

場面新サービス「Inkbird」のSNS用30秒動画。 ラフ画は自分で描く前提で、カット割と内容だけ先に決めたい。
あなたは映像ディレクターです。 30秒のSNS動画の絵コンテを 4カット で。 # プロダクト "Inkbird" — 書く人のための静かなツール # 制約 - 縦9:16 - 字幕主体（音なしで成立） - 「静けさ」を視覚的に表現 - 最初の3秒で離脱させない強い絵 # 出力フォーマット（必須） 各カットに： - カット番号 / 尺（秒） - 構図（カメラ・距離・動き） - 画面内の動き - 字幕テキスト（最大15字 × 2行） - 演出ノート（1行・なぜそうするか） # トーン 詩的・余白多め・コピーは 短く。
振り返り「ラフ画は自分で描く」と 前提を切り分ける と、Claudeは余計な絵描きをせず、構成と言葉に集中する。 縦9:16・無音前提のような 制約 を最初に書くと、出力の精度が一段上がる。

教材動画の
語り台本

場面3分の社内教材動画「Claudeの基本」。 原稿を 読んで自然に響く 日本語に整える。書き言葉のまま読むと、固くて聞いていられない。
下の原稿を、ナレーション用に書き直して。 # 原稿（書き言葉） （記事を貼る） # 直し方 - 1文を25字以内を目安に - 漢字を減らして、ひらがなを増やす - 「〜である」「〜という」を避ける - 「、」より「。」で切る - 数字は読み上げ可能な形に（百分率・年月） # 出力フォーマット | TIME | 話者 | 台詞 | 演出メモ | 各セクションに： - TIME（00:00形式） - 話者（NARRATOR） - 台詞 - 演出メモ（呼吸の置き場所・抑揚） # 全体尺 3分。1分につき約 250-300字 が目安。

ロゴアニメの
5秒タイムライン

場面サービスロゴが現れる「OP 5秒」のアニメ。 いつ何が動くか、Claudeに 表で 出してもらってから手を動かす。
5秒のロゴアニメ用に、タイムラインを書いて。 # 素材 - ロゴ: "Inkbird"（文字のみ・色は黒） - 背景: クリーム（#FBF6E9） - アクセント: 黄色の小さな星 # やりたいこと - 0-2秒: 背景フェードイン - 2-3.5秒: ロゴが下から滑り込み - 3.5-4秒: 星がポップで現れる - 4-5秒: 全体が0.5秒静止して終わる # 出力フォーマット | レイヤー | 入り | 出る | プロパティ | イージング | 備考 | 各動きに： - レイヤー名 - 開始秒・終了秒 - 動くプロパティ（opacity / y / scale） - イージング（easeOut, easeInOut, spring） - 備考（注意点1行） # おまけ 最後に「CSS / GSAP / After Effectsで書くなら」の一言メモ。

20分を整える

場面20分のインタビュー動画。文字起こしはあるが、そのまま字幕にすると 読み切れない。 字幕用のルールを渡して、整え直す。

04

動画づくりでの得意・不得意

Claudeは絵を描けない。けれど、絵を 描く前 と 描いた後 の仕事は、ほぼ全部できる。

◯得意なこと

CLAUDE DIRECTS — 任せて速い領域
  • 絵コンテ・カット割カット番号・尺・構図・字幕を表で量産。ラフ画は人が描く
  • ナレーション原稿の口語化書き言葉→読み言葉。1文短く・ひらがな増やしの整え
  • タイムライン設計「いつ何が動くか」の表化。CSS/GSAP/AEへの落とし込み付き
  • 字幕の物理整形文字数・秒数・改行位置のルールに従って機械的に
  • 構成・尺配分の議論OP/本編/EDの比率や、シーン入れ替えのシミュレーション
  • BGM・SE要望書雰囲気の言葉を、テンポ・拍子・楽器に翻訳して発注書に
  • タイトル・サムネ大量案出し20案・50案レベルの量産はClaudeの十八番

△苦手なこと（人がやる）

YOU SHOOT — 譲ってはいけない領域
  • 絵そのもの写真・実写・複雑なイラストの生成は別ツール／人の仕事
  • 動画ファイルの生成音声合成や動画書き出しは別系統。Claudeは台本担当
  • カット同士の繋がり感覚「次のカットへの引きが弱い」みたいな身体感覚は人が判断
  • 声優の声色・トーン選び「この役の声」は文字で説明しきれない。サンプル試聴は人
  • 音と映像の最終ミックスピーク管理・タイミングの追い込みは編集ソフトと人の耳
  • 権利関係の判断BGM・引用・肖像。Claudeは答えるが、最終確認は人と弁護士
05 / PIPELINE

動画づくり、5段の流れ。

1

構想

PHASE 01
Claudeの役 壁打ち相手。ターゲット・尺・媒体・狙いを、問い返してもらいながら定める。
2

設計

PHASE 02
Claudeの役 台本ライター。絵コンテ・ナレーション・字幕・BGM要望書を、テンプレで一気に。
3

撮影

PHASE 03
Claudeの役 ここはお休み。カメラ・声・音は人の仕事。Claudeはチェックリストだけ用意。
4

編集

PHASE 04
Claudeの役 タイムライン・字幕・テロップの整え役。「短くしすぎてない？」と聞ける相棒。
5

公開

PHASE 05
Claudeの役 タイトル・サムネ・概要欄・SNS告知。同じ素材を 何度も収穫。
