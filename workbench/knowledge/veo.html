Google Veo — 動画生成モデル

音声・映像を同時生成する Google DeepMind の動画 AI。Veo 3.1 は 4K / 最長60秒 / 口パク精度 ±120ms。API と Flow UI の両方からアクセス可能。

1. Veo モデル進化史

2024年前半 — Veo 1

初代 Veo。テキストから動画を生成する基礎モデル。解像度・長さは限定的。音声は別途合成が必要だった。Google I/O 2024 でデモ公開。

2024年後半 — Veo 2

Veo 2。物理法則の再現精度・カメラワーク制御・人物動作の自然さを改善。ImageFX の動画機能として一般公開。Runway Gen-3 と並ぶ水準へ。

2025-05-20 — Veo 3

Veo 3（Google I/O 2025 発表）。業界初の映像・音声同時生成を実現。環境音・台詞・BGM をテキスト1行から自動生成。Flow アプリと同時リリース。

2025-11-17 — Veo 3.1

Veo 3.1（現行最新）。4K 解像度・最長60秒・口パク精度 ±120ms・Lite / Fast / Quality の3バリアント構成。Gemini API と Vertex AI で提供開始。

バージョンリリース主な改善点音声

Veo 22024 後半物理再現・カメラ制御・人物動作なし

3. 主要機能

Text-to-Video

テキストプロンプト一行から映像クリップを生成。カメラワーク・照明・雰囲気を細かく指定可能。環境音・台詞も同時生成される。

Image-to-Video (Frames)

静止画をスタートフレームとして動画を生成。Imagen 4 Ultra で生成したキャラクター/素材を動かすことができる（Ingredients 連携）。

Scene Extension

生成済みクリップの末尾から自然につながる追加クリップを生成。同じシーンを延長したり、次のシーンへの橋渡しクリップを作れる。

カメラモーション制御

パン・ティルト・ズーム・ドリー・クレーン・360度回転など、映像制作の基本カメラワークを自然言語で指定。映画的な演出が可能。

音声生成（3種）

  • 台詞: "セリフ" [感情] 構文で口パク同期
  • SFX: 環境音・効果音の自動生成
  • アンビエント: BGM・雰囲気音

Ingredients（キャラ一貫性）

Imagen 4 で生成したキャラクター画像を Flow に登録。複数のショットで同じキャラクターが登場する映像を一貫した外見で生成できる。

4. API アクセス方法 — 3つの経路

① Vertex AI Python SDK

本番・エンタープライズ向けの主要 API 経路。SLA・VPC・アクセス制御付き。Google Cloud プロジェクトが必要。Paid Preview で利用可能。

モデル ID: veo-3.1-fast-generate-001
または veo-3.1-generate-001（Quality）

② Gemini API

開発・プロトタイプ向け。google-generativeai ライブラリで手軽にアクセス。AI Studio でのプロトタイプから本番移行の第一歩として最適。

③ Flow UI

ノーコードで映像を制作したい場合は Flow アプリ（flow.google.com）を使う。クレジット制で Scenebuilder によるタイムライン編集が可能。詳細は flow.html。

5. Vertex AI Python SDK コード例

① 基本の Text-to-Video 生成

# pip install google-cloud-aiplatform
import vertexai
from vertexai.preview.vision_models import VideoGenerationModel

vertexai.init(project="YOUR_PROJECT_ID", location="us-central1")

# Fast: veo-3.1-fast-generate-001
# Quality: veo-3.1-generate-001
model = VideoGenerationModel.from_pretrained("veo-3.1-fast-generate-001")

operation = model.generate_video(
    prompt=(
        "A samurai in full armor walks through a bamboo forest at dawn. "
        "Morning mist, birds chirping, footsteps on gravel. "
        "Camera slowly pushes forward at knee height."
    ),
    aspect_ratio="16:9",       # "16:9" / "9:16"
    duration_seconds=8,        # 4, 6, or 8
    generate_audio=True,
)

result = operation.result(timeout=300)
video = result.generated_videos[0]
video.save("samurai.mp4")
print("Saved samurai.mp4")

② 台詞付き動画（口パク同期）

operation = model.generate_video(
    prompt=(
        "A news anchor at a desk in a modern studio. "
        '"Breaking news: AI has changed the world." [professional, calm] '
        "Subtle background music. 4K studio lighting."
    ),
    aspect_ratio="16:9",
    duration_seconds=6,
    generate_audio=True,
)

result = operation.result(timeout=300)
result.generated_videos[0].save("news_anchor.mp4")

③ Image-to-Video（参照フレームから生成）

from vertexai.preview.vision_models import Image as VertexImage

reference_image = VertexImage.load_from_file("character.png")

operation = model.generate_video(
    prompt="The character turns to face the camera and smiles warmly.",
    image=reference_image,     # スタートフレームとして使用
    aspect_ratio="9:16",
    duration_seconds=4,
    generate_audio=True,
)

result = operation.result(timeout=300)
result.generated_videos[0].save("character_reaction.mp4")

9. 動画プロンプトガイド

Veo 3.1 は「被写体 → アクション → 環境 → カメラ → 音響」の5要素フレームワークで安定した高品質出力が得られる。

要素説明例
① 被写体誰が・何が主役かA chef in a white coat, mid-30s
② アクション何をしているかcarefully plates a gourmet dish
③ 環境場所・時間・天候in a Michelin-starred kitchen, evening, warm kitchen lights
④ カメラカメラワーク・アングルslow dolly-in from medium shot to close-up
⑤ 音響BGM・SFX・台詞sizzling sounds, ambient kitchen noise, soft jazz
カメラワーク指示語効果
slow dolly-in前進ドリー（緊張感・寄り）
pull back reveal引きながら全景を明かす
drone aerial shot俯瞰ドローン映像
handheld shaky手持ち・リアル感
tracking shot被写体を横から追う
360 orbit被写体を中心に周回
extreme close-up超アップ（質感強調）

🎙 台詞構文: "発話内容" [感情・話し方] 形式で指定。例: "Welcome to the future of filmmaking." [excited, whispering]

10. Flow との関係 — エンジン vs コックピット

🎬 Veo がエンジン、Flow がコックピット。Veo 3.1 はモデル本体（API でも直接呼び出し可能）。Flow アプリはその Veo をノーコードで使える GUI 制作環境。どちらを使うかは用途次第。

シナリオ推奨経路
まず試したい・個人制作Flow UI（flow.google.com）
プロトタイプ → コードに落としたいGoogle AI Studio → Gemini API
本番・大量生成・SLA が必要Vertex AI Python SDK
映像全体のタイムライン編集Flow Scenebuilder
キャラクター一貫性が必要Imagen 4 Ultra → Flow Ingredients → Veo

詳細は flow.html（Flow アプリ全体）と imagen.html（Ingredients の起点となる画像生成）を参照。
