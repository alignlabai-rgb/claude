Big Four 全社の AI 戦略マップ
KPMG / PwC / Deloitte / EY が描く「プロフェッショナルサービスの AI 再定義」

2026年5月、Big Four の AI 戦略は「実験」フェーズを完全に抜けた。KPMG が 276,000名全員へ Claude を統合配備し、PwC が 30,000名の認定プログラムを発表した同じ週、Deloitte と EY はそれぞれ別のレイヤで動いている。 単独ベンダーの広報文だけでは見えにくい「誰が誰と組み、何を顧客にどう請求しようとしているのか」を、 事業企画・M&A 観点で整理する。

最終更新: 2026-05-25 ／ 著者: ALIGN_Lab Research

TL;DR — この記事の要点

  • Anthropic 派の2社（KPMG / PwC）が「Claude を内部生産基盤に組み込む」方向で先行。KPMG は 276,000名へ Digital Gateway 経由で Claude を統合、PwC は 30,000名の Claude 認定 + Joint CoE を設立。
  • Deloitte は「マルチモデル×内製ツール」を維持。OpenAI / Anthropic / Google を併用し、自社ブランド資産（Asset library・Audit & Assurance ツール群）を強化する戦略。
  • EY は「OpenAI / Microsoft 軸の独自プラットフォーム（EY.ai）」路線。Azure ベースの自社配備に投資し、Big Four で唯一「プラットフォーム=自社製品」のポジショニング。
  • 結果として Big Four は「Claude を生産関数に」（KPMG/PwC）と「自社プラットフォームの中で AI を流通」（Deloitte/EY）の二派に分岐した。
  • 請求モデルは 人月から成果・サブスクリプションに押し戻されつつあり、内製ツール保有量と AI 配備規模が 2027年以降の収益構造を決める変数になる。
事実関係の信頼度について： 本記事のうち、KPMG と PwC の Anthropic 提携詳細（人数・製品名・日付）は当行内部の一次ソースで確認済み（Anthropic / KPMG プレスリリース、2026-05-19〜22）。 Deloitte / EY 部分は公開情報に基づく「現時点での合理的な構図」であり、未確認の数値・契約金額は 背景 として明示している。

1. 全体構図 — 4社が「どの AI 派閥」に属するか

2026年5月時点の Big Four を、最大の提携先 LLM ベンダーと「内製プラットフォーム志向の強さ」で分類すると、以下の3つに分かれる。 この分類は「他社モデルを一切使わない」という意味ではない（全社がマルチモデル併用を表明している）。 ここで問うているのは「どの陣営との提携を最大の広報資産・収益チャネルに据えているか」だ。

分類 該当社 主戦略 LLM パートナー 象徴的な指標（2026-05時点） 請求モデルへの含意
Anthropic 派 KPMG Anthropic（Claude / Cowork / Managed Agents）+ Microsoft Azure 276,000名 全員配備 ／ Digital Gateway 統合 ／ KPMG Blaze 監査・税務の納品物単位でツールを売る方向
Anthropic 派 PwC Anthropic（Claude Code / Cowork）+ AWS 30,000名認定 ／ Joint CoE ／ 業務納期 -70% 成果報酬・サブスクに近いハイブリッド請求
中立 / マルチモデル派 Deloitte OpenAI ／ Anthropic ／ Google を併用、自社 Asset/IP を中核に 内製ツール群（Audit & Assurance、Asset library）強化路線 背景 従来の人月×レバレッジを AI で上書き
OpenAI / Microsoft 派 EY OpenAI ／ Microsoft（Azure / Copilot）軸の EY.ai プラットフォーム EY.ai 投資 約14億ドル規模を継続 背景 自社プラットフォーム課金を新規収益化

注：4社とも公的に「マルチモデル」を強調するが、大型提携の経済性と広報の重心には明確な差がある。 ここでは2026年5月時点の重心で分類した。

2. KPMG × Anthropic — 276,000名展開と「Digital Gateway 統合」の重み

一次ソース確認済み

2-1. 何が発表されたか（2026-05-19）

KPMG と Anthropic は 5/19、グローバル戦略アライアンスを締結。KPMG の業務基盤プラットフォーム 「Digital Gateway」（Microsoft Azure 上で稼働）に Claude を組み込み、 全世界 276,000名以上の従業員へ提供を開始した。あわせて Cowork と Managed Agents も Digital Gateway 内から呼び出せるようになっている。

ここでの最大のニュースバリューは「人数」ではなく「統合のレイヤ」だ。 Claude をブラウザ版で配ったのではなく、KPMG が監査・税務・アドバイザリーで全員が使う業務基盤の中に ネイティブ機能として埋め込んだ。これは「Microsoft Copilot を使わせる」の選択肢を捨てたわけではないが、 主軸は Anthropic と内外に明示した意味を持つ。

2-2. クライアント側の製品 — KPMG Blaze

プライベートエクイティ向けには、Claude Code を中核に据えた新製品「KPMG Blaze」が 並行発表された。PE のポートフォリオ企業に対して、KPMG が AI エージェントを伴う形で Value Creation 支援を提供する形態だ。「Big Four が自社の Claude Code を顧客のコードベースに入れる」 という構図は、従来の「コンサルが PowerPoint を作る」モデルからの構造的逸脱を示す。

2-3. 業務改善メトリクス

Anthropic / KPMG 発表によれば、税制変更対応エージェントの構築が「数週間 → 数分」に短縮。 Managed Agents の Memory 機能（5/19 public beta）と組み合わせ、税法改正のたびに監査チームが 手で書き直していたチェックリストを、エージェントが規制原文から自動生成する形に切り替わった。

2-4. なぜ Anthropic だったか — 観察できる理由

  • 監査・税務のリスクプロファイルに Anthropic の安全研究志向が適合。KPMG 側からは「constitutional AI / interpretability の方向性が監査適合性と整合的」という説明
  • Claude Code の長尺タスク完遂能力が、KPMG Blaze（PE クライアント向け）の差別化要素として効く
  • 競合（PwC が同時期に Anthropic 提携を発表）に先んじて「全員配備」の規模優位を取りに行く必要があった

3. PwC × Anthropic — 30,000名認定と Joint CoE

一次ソース確認済み

3-1. 提携の中身（2026-05-17〜22）

Anthropic と PwC は同時期にアライアンス拡大を発表。KPMG が「業務基盤への組み込み」を強調したのに対し、 PwC は「人材の認定と業界別ユースケース」を前面に出している。

  • Claude Code と Claude Cowork を PwC 米国チームから本格展開、その後グローバル化
  • 30,000名の PwC 専門家を対象とした Claude 認定プログラムを立ち上げ
  • Anthropic との Joint Center of Excellence を共同設立
  • プロスポーツ運営、保険引受、メインフレーム近代化、HR 変革、サイバーセキュリティで本番稼働済み
  • 業務納期で最大70%短縮の実績が報告されている

3-2. KPMG との戦略差分

同じ Anthropic 派でも、ポジショニングはきれいに分かれている。 KPMG は「自社の生産基盤（Digital Gateway）に Claude を埋め込み、PE 向けに パッケージ製品を売る」方向。 PwC は「業界別ユースケース集を蓄積し、人材の Claude スキルをレバレッジ可能な資産として認定で可視化する」方向。

軸 KPMG PwC
展開規模276,000名（全員）30,000名（認定対象）
クラウドMicrosoft Azure（Digital Gateway）AWS 中心
象徴製品KPMG Blaze（PE 向け Claude Code）Joint CoE + 業界別ソリューション
主軸メッセージ「業務基盤への統合」「人材認定とユースケース蓄積」
請求モデル含意納品物パッケージ寄りサブスク + 成果報酬寄り

どちらが優位という話ではなく、Anthropic 側から見れば「同じ週に Big Four の2社を獲得した」こと自体が、 Anthropic の B2B 流通戦略における 5月最大の戦果と言える。

4. Deloitte の動向 — マルチモデルと「内製 Asset の AI 化」

背景情報（公開情報に基づく構成）

Deloitte は Big Four 最大の売上規模（年間 約700億ドル規模）を持ち、AI 関連支出も最大級と推定される。 ただし2026年5月時点で、Deloitte が「単独の AI ベンダーと象徴的なグローバル提携」を打った様子はない。 観察できる戦略は次の3つの組み合わせだ。

  • マルチモデル戦略：OpenAI（早期からの戦略提携）、Anthropic、Google Gemini、自社モデル評価環境を併用
  • Audit & Assurance の AI 化：監査調書・テスト自動化・Anomaly Detection など、監査ワークフローそのものに内製 AIを組み込む方向
  • Asset library 拡張：業界別の AI アクセラレータ（金融、ヘルスケア、製造）を社内 IP として蓄積し、コンサルの納品物に組み込む

4-1. なぜ「単独ベンダー提携」を打たないのか — 仮説

Deloitte の収益構造（コンサル比率が高く、監査でも独立性が論点になりやすい）を考えると、 特定 LLM ベンダーへの過度なロックインはクライアント側の独立性審査で不利になりかねない。 また、Microsoft / Google / AWS いずれとも Tier 1 パートナーであり続けることが、 顧客のクラウド事情に左右されない営業力を保つ条件になる。 この構造は 「Big Four で最も慎重に旗を立てる」選択を合理化する。

ただし Deloitte が Anthropic / OpenAI のどちらかに "後追いの大型提携" を仕掛ける可能性は高い。 KPMG / PwC が Anthropic で固めた以上、Deloitte が市場メッセージで取り得る差別化は 「OpenAI 軸での同等規模の提携」か「マルチモデルを最後まで貫く」の二択。 2026年下期のウォッチポイントになる。

5. EY の動向 — EY.ai と OpenAI / Microsoft 軸

背景情報（公開情報に基づく構成）

EY は2023年以降、社内 AI プラットフォーム「EY.ai」に約14億ドル規模の投資を継続表明しており、 Big Four で唯一「自社プラットフォーム=自社製品」のポジショニングを取っている。 基盤は Microsoft Azure / OpenAI 軸、社内アシスタント「EY.ai Agent」も Microsoft Copilot Studio との統合を強調する。

  • EYQ — 全パートナー・スタッフ向け社内 LLM 環境（OpenAI モデルを Azure 経由で配信）
  • EY.ai for Audit / for Tax — 監査・税務領域別の AI アシスタント。テンプレートと自社規律を含んだ専用 UI
  • EY Fabric — 顧客向け SaaS プラットフォーム。EY のメソドロジをソフトウェアとして売る方向の中心装置

5-1. 戦略的含意

EY が「OpenAI / Microsoft」を選んだ意味は、KPMG / PwC が「Anthropic」を選んだ意味の鏡像である。 EY の顧客基盤は大企業のエンタープライズ ITに深く食い込んでおり、 その大半は既に Microsoft 365 / Azure 上にある。OpenAI を中核に据えることは、 顧客の既存 Microsoft 投資との連続性を最大化する選択だ。

逆に、Anthropic 派の KPMG / PwC は「監査・税務のリスク管理上、constitutional AI / interpretability に近い設計が望ましい」 という別の論拠で旗を立てている。同じ Big Four でも、AI の選び方が顧客基盤の特性と一致するように分岐したのが、 2026年5月の重要な観察ポイントだ。

6. プロフェッショナルサービス業界の構造変化 — 請求モデルの再定義

6-1. 人月モデルの「上限」が見えてきた

Big Four の伝統的な収益モデルは、レバレッジ比（パートナー1人あたりのスタッフ数）× チャージレート × 稼働率の三要素積だった。 生成 AI は、このうち スタッフ稼働率の前提を破壊する。具体的には：

  • 従来「ジュニア5人 × 2週間」で完了していた論点整理が、Claude Code / Cowork で「シニア1人 × 2日」に圧縮される
  • 結果として人月 × チャージレートの請求では、顧客側が「同じ仕事に AI で半額のはず」と値切る根拠を持つ
  • PwC が報告する「業務納期 -70%」は、同じ単価で請求し続けると顧客の AI リテラシー向上に勝てない未来を示唆する

6-2. 移行先の3つの請求モデル

モデル 性格 Big Four での親和度
成果報酬（Outcome-based） 納期短縮・コスト削減・売上向上を共有 PwC が「業界別ユースケース」の蓄積でここに寄せている
サブスクリプション（Asset-as-a-Service） 監査テンプレ・税務エンジン等を SaaS 化して定額課金 EY（EY Fabric）・Deloitte（Asset library）が先行
パッケージ製品販売 特定領域（PE Value Creation など）を製品化して売る KPMG Blaze がこのパターンの典型

6-3. 監査独立性とのテンション

4社とも監査法人を内包するため、自社が監査している企業に自社 AI 製品を売ることには独立性審査がかかる。 EY Fabric や KPMG Blaze のような「自社プロダクトを売る」モデルは、SEC・PCAOB 等が AI 製品をどう扱うかの ガイダンス次第で動きが制約されうる。ここは2027年に向けた制度リスクとして要観察だ。

7. 投資 / M&A 視点 — Big Four の AI 投資が示すもの

7-1. 「ベンダーの選好」=「次の数年の AI 流通シェア」

Big Four が合計で動かす AI 関連支出は、年間で数十億ドル規模に達すると推定される（広報投資・トレーニング・社内基盤・クライアント向けライセンス転売を含む）。 この支出が Anthropic に流れるか OpenAI に流れるかは、両社のエンタープライズ売上の構造を直接動かす。

  • KPMG / PwC の選好が固まったことで、Anthropic の監査・税務・PE バーティカルでの流通が固定化される
  • EY の Microsoft / OpenAI 軸は、Azure OpenAI のエンタープライズ売上の継続性を担保する
  • Deloitte が「最後の主要票」になっており、ここをどちらが取るかで2026年下期の AI 流通シェアの綱引きが決まる

7-2. 競合の動き — Accenture / IBM / Capgemini

Big Four 外では、Accenture・IBM Consulting・Capgemini がそれぞれ独自の AI 戦略を持つ。 Accenture は Anthropic と Microsoft の両方と組む「ハイブリッド派」、 IBM は自社 watsonx + Anthropic / Meta モデル併用、Capgemini は Google Gemini との結びつきが強い。 この層はBig Four より早く成果報酬モデルへ移行しており、Big Four にとっての真の競合になりつつある。

7-3. M&A シナリオ — 何が買われるか

  • 業界別 AI ブティック：監査・税務・FP&A 領域に特化した AI スタートアップは、Big Four による買収候補
  • MCP コネクター / 業務システム連携ベンダー：Claude / ChatGPT エコシステムへの接続を提供する層は、Big Four の内製化候補
  • AI ガバナンス / Audit Tech：自社の監査独立性とクライアントへの AI ガバナンス助言を両立させるための買収。EY / Deloitte に動機が強い
投資判断としては、「Big Four のどの陣営に売れるか」を成長戦略の主軸に据える AI スタートアップが 2026年下期に増える可能性が高い。Anthropic / OpenAI のエンタープライズ売上の「下流」として、 Big Four 経由の流通網が機能し始めている。

8. 結論 — 2026年5月から見える「次の構図」

2026年5月のスナップショットを一文にすると： 「KPMG / PwC は Claude を生産基盤に組み込み、EY は OpenAI で自社プラットフォームを売り、Deloitte は最後の旗を立てる前に観察している」。 この3パターンが Big Four 内で確立されたこと自体が、プロフェッショナルサービス業界における AI の「実験フェーズ完了」を示すマーカーだ。

事業企画・M&A 観点での示唆は次の3点：

  1. AI スタートアップは「自社製品の顧客」だけでなく「Big Four 経由の流通網」を成長戦略に組み込む段階に入った
  2. 監査法人を持つ Big Four は、AI ガバナンス / Audit Tech 領域での内製化または買収を2026年下期に加速する可能性が高い
  3. 顧客企業（特に金融・公共・規制業種）の AI ベンダー選定は、自社の監査法人がどの AI 派閥かに影響されやすくなる。サプライチェーンとしての「Big Four × LLM ベンダー」の組合せが、エンドユーザー側の意思決定に染み出す

次の重要なウォッチポイントは、(1) Deloitte の旗の立て方、(2) EY.ai の Anthropic 採用の有無、 (3) Big Four 各社の AI 関連売上の開示精度向上、の3点。次回更新は2026年8月を予定。
