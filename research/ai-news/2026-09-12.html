🔴 Claude / Anthropic

安全性提言AnthropicのCEOアモデイ氏、AI開発の意図的減速「Pacing the Frontier」を提言

Anthropicのダリオ・アモデイ氏は9月12日、AI企業・各国政府に能力開発ペースの意図的な減速を求めるエッセイを公表。再帰的自己改善や直近のエージェント関連インシデントを踏まえ、暴走AIエージェント群が半年程度でインターネットを乗っ取りうると警告した。第三者評価者を社内に常駐させる取り組みへのコミットを表明したほか、民主主義国の主要AI企業が安全基準とペースの制約で合意する枠組みを提案。OpenAIのサム・アルトマン氏も速やかに同調した。

Source: Bloomberg / Washington Post / Axios

アップデートClaude Code v2.1.269公開、`plugin eval`コマンドと`/output-style`切替を追加

Anthropicは9月11日、Claude Code v2.1.269を公開。プラグインのevalスイートを実行しJSON/HTMLで再現可能なスコアを出力する`claude plugin eval`、Remote Control・クラウド・ヘッドレスセッションでも出力スタイルを一覧・切替できる`/output-style`を追加。Bashツールがコマンドで変更したファイルのdiffを結果に含める設定（bashEditDiffEnabled）なども加わり、98件のCLI変更を含む更新となった。

Source: Claude Code Changelog

脆弱性セキュリティ企業Accomplish、Claude Code・Codex・Cursorの「サンドボックス漏洩」問題を指摘

セキュリティスタートアップAccomplishは、AIコーディングエージェントがサンドボックス内で生成したファイルが、後にホスト上の信頼済みソフトウェアによって処理されることでサンドボックス外のコード実行につながる構造的な問題を、Claude Code・OpenAI Codex・Cursorで確認したと公表。Anthropic・OpenAI・Cursor各社へ今夏に報告済みで、修正に最大50日を要したケースもあったとしている。

Source: Accomplish / Upstarts Media

🟠 GPT / OpenAI / Codex

脅威レポートロシア系脅威アクター、Codex×DeepSeekのAIエージェント群でPaperCut脆弱性を悪用し395組織を侵害

ロシア語圏とみられる脅威アクターが、OpenAI Codexハーネスと DeepSeekモデルを組み合わせた数百のAIエージェントを用い、PaperCutの脆弱性CVE-2026-81578/82078を悪用。8月31日開始のキャンペーンで48カ国440台のPaperCutサーバー・395組織を侵害し、空のワークスペースから4時間弱で初回のリモートコード実行に到達したという。ロシア・中国など26カ国は標的から意図的に除外されていた。

Source: BleepingComputer / The Hacker News

新機能ChatGPT Work/CodexにDeep Research追加、Codexはスレッドの共有・固定機能を強化

OpenAIはChatGPT WorkプランとCodexに「Deep Research」機能を追加。あわせてCodexでは会話スレッドのスナップショットを共有できる機能や、複数スレッドをまとめてピン留めできる機能を導入し、チームでの調査・開発タスクの引き継ぎをしやすくした。

Source: OpenAI

🟠 Grok / xAI

延期Grok 4.7、目標だった9月12日を過ぎても未公開 マスク氏「あと数日」

イーロン・マスク氏が9月2日に予告していた2.1兆パラメータの新モデル「Grok 4.7」（SpaceX由来のエンジニアリングデータで学習）は、目標リリース日としていた9月12日を過ぎても公開されなかった。マスク氏は9月11日、強化学習による追加チューニングに「あと数日」必要と説明しており、正式なモデルID・価格・ベンチマークは依然として未公表。

Source: BigGo Finance / Orca Router
