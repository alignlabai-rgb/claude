エージェントモードとは — 旧 Copilot との違い

正式名称：2026年4月22日の GA（一般提供開始）時に "Agent Mode" から "Edit with Copilot" に改称。Build 2026（5月19〜21日）でデフォルト機能となりました。本ガイドでは通称「エージェントモード」を使用します。
観点旧 Copilotエージェントモード（Edit with Copilot）
動作方式提案・回答のみ（ユーザーが実行）自律的にマルチステップ操作を実行
デッキ生成部分的なスライド提案アウトラインから全スライドを一括生成
逆質問なし（単方向）対象・スタイル・枚数を確認質問してから実行
参照ファイル限定的最大 5 ファイル（Word・PDF・Excel・PPT）を参照
Web 参照なし公開 Web ページ URL をソースとして追加可能
画像生成基本的なデザイン提案GPT-Image・MAI-Image-2.5・Flux.2 Flex 等から選択
Brand Kit手動適用SharePoint ブランドキットを自動参照・適用

デッキ作成の流れ

  1. プロンプト入力：「Q4決算の役員向け10スライドのデッキが必要」など大まかな指示を入力
  2. 逆質問：Copilot が対象オーディエンス・スタイル・スライド枚数・使用するファイルを確認質問。回答することで精度が向上する。
  3. アウトライン提示：スライド構成案（タイトル・各スライドの要点）を提示。ユーザーが承認・修正できる。
  4. 一括生成：承認後、Copilot がスライドを自動生成。レイアウト・デザインテーマ・スピーカーノートまで一括作成。
  5. 反復精緻化：チャットで追加指示「3枚目のグラフを棒グラフに変更」「ブランドカラーに合わせて」と継続改善。

有効化・アクセス方法

デスクトップ PowerPoint（Windows/Mac）

  1. ファイルを開く（新規 or 既存）
  2. リボン「ホーム」→ 「Copilot」 ボタンをクリック
  3. 右側に Copilot ペインが開く
  4. Build 2026 以降はエージェントモードがデフォルト
  5. ペイン上部のモデルピッカーでテキスト LLM・画像モデルを選択

PowerPoint Online（Web）

  1. OneDrive / SharePoint でファイルを開く
  2. 右上の 「Copilot」 ボタンをクリック
  3. 機能はデスクトップ版とほぼ同等
  4. Web 版は新機能の先行展開が多い
  5. ブランドキット機能は Microsoft 365 Copilot アプリとの連携が必要

画像生成モデル選択 — PowerPoint 特有の強み

PowerPoint の独自性：Excel と異なり、PowerPoint の Copilot ペインにはテキスト LLM とは別に画像生成モデルを選択できるピッカーがあります。4 種類のモデルから用途に合わせて選択可能です。これは PowerPoint がビジュアルコミュニケーションの主役であるため特別に拡充された機能です。
GA 済み

GPT-Image

提供元: OpenAI

高品質なフォトリアリスティック画像。プロンプトへの忠実度が高く、複雑なシーンも精度よく表現。旧 DALL-E 3 の後継シリーズ（DALL-E 4 という名称は採用されていない）。

2026年4〜5月展開

Flux.2 Flex

提供元: Black Forest Labs

テキストレンダリング・レイアウト処理に優れた高品質ビジュアル。プレゼン用のインフォグラフィック・アイコン・図解に特に強い。2026年4月下旬〜5月に PowerPoint 展開。

Microsoft 製

MAI-Image-2 Efficient

提供元: Microsoft

高速・高品質のバランス型。編集ワークフローに最適化されており、既存スライドへの画像追加・差し替えがスムーズ。2026年4月展開。

Build 2026 展開中

MAI-Image-2.5

提供元: Microsoft

Microsoft の最先端画像モデル。テキスト→画像・画像→画像編集の両対応。Arena.ai ランキング 3位。タイポグラフィ・ロゴ・テキスト編集をナチュラルキューで生成。PPT 向けインフォグラフィック・フロー図生成対応。アイデンティティ一貫性保持・フルフレーム再スタイリングも可能。

モデル選択ガイド

用途推奨モデル理由
フォトリアルな写真・情景GPT-Imageプロンプト忠実度が高く、人物・風景の自然な表現に強み
インフォグラフィック・フロー図Flux.2 Flex または MAI-Image-2.5テキスト・レイアウト処理に特化。PPT 向け図解生成に最適
既存スライドへの素早い画像追加MAI-Image-2 Efficient速度重視。編集ワークフロー最適化
ロゴ入り・テキスト入り画像MAI-Image-2.5タイポグラフィ・ブランド要素のナチュラルキュー編集
通常使用・自動判断AutoCopilot がコンテキストに応じて最適モデルを自動選択

モデルピッカーの使い方

  1. Copilot ペインを開く
  2. ペイン上部のモデルピッカーをクリック
  3. 「テキストモデル」セクションでテキスト LLM を選択
  4. 「画像モデル」セクションにスクロールして画像生成モデルを選択
  5. 画像生成を含むプロンプトを入力（例：「このスライドにブランドに合ったイラストを追加して」）

コア機能詳解 — デッキ作成ワークフロー

生成

フルデッキ一括生成

自然言語の指示から逆質問→アウトライン確認→スライド一括生成の流れで完全なデッキを作成。レイアウト自動選択・コンテンツ配置・デザインテーマ適用まで一貫して実行。

ノート

スピーカーノート生成

「このスライドにスピーカーノートを追加して」「全スライドに 300 字のノートを入れて」で一括生成。コンテキストを踏まえた自然な発話原稿を自動作成。

変換

デザイン変換（Visualize this slide）

テキスト中心のスライドをビジュアル重視のデザインに変換。ビルトインスキル「Visualize this slide」で 1 クリック実行。

構成

スライド構成の再編

「このデッキを5スライドにまとめて」「課題→解決策→効果の構成に変更して」でスライド順序・統合・分割を自動実行。

Web

Web ページ参照（2026年5月〜）

公開 Web ページの URL をソースとして追加可能。最新情報をコピペなしで取り込み。「このURLを参照して業界概況スライドを作って」で起動。

AI 画像

AI 画像のスライド自動配置

プレゼン生成時に画像生成モデルを選択すると、各スライドのコンテキストに合わせた画像を自動生成・配置。スタイル指定（フォト/イラスト/インフォグラフィック等）も可能。

07

マルチファイル対応 — Word・PDF・Excel から生成

最大 5 ファイルを参照：OneDrive/SharePoint に保存されたファイルを最大 5 本を参照してデッキを生成できます。ファイル名で検索するか URL を貼り付けて指定。異なる種類のファイルを組み合わせることで、多角的な情報を1つのデッキに統合できます。
Word → PPT

Word 文書からプレゼン生成

Word ファイルを参照ソースとして指定してプレゼンを生成。Word の見出しスタイル（Heading 1/2等）を適用しておくとスライド分割精度が大幅に向上します。Word 内の画像も取り込み対象。

Excel → PPT

Excel データを取り込んだデッキ

Excel ファイルを参照ファイルの 1 つとして指定可能。データのハイライト・グラフの説明・KPI サマリーをスライドに組み込み。最大 5 ファイルのうちの 1 本として使用。

PDF → PPT

PDF・資料からスライド生成

PDF レポートや調査資料を参照して要点を抽出しプレゼンに変換。複数のリサーチ文書をまとめて1つのデッキに統合することも可能。

マルチファイル指定の手順

  1. Copilot ペインを開いてプロンプト入力欄の「+」ボタンをクリック
  2. OneDrive/SharePoint のファイルを検索または URL を貼り付けて参照先を追加
  3. 最大 5 ファイルまで追加可能
  4. 参照ファイルを確認してからプロンプトを入力「これらの資料を元にプレゼンを作成して」
  5. Copilot が逆質問後にアウトラインを提示
Word → PPT のコツ：Word 文書に Heading 1（章タイトル）・Heading 2（節タイトル）スタイルを適用しておくと、Copilot がスライドの区切りを正確に判断します。構造化された文書からはより論理的なデッキが生成されます。
08

ブランドキット × Copilot

ブランドキットとは：組織の承認済みブランド要素（ロゴ・カラー・フォント・画像・アイコン・テンプレート）のコレクションです。SharePoint の Organization Assets Library（OAL） と連携し、Copilot がデッキ生成時に自動適用します。

ブランドキットの動作原理

  • テンプレート優先：ブランドキットよりもテンプレートが先に適用される
  • Brand Kit 補完：テンプレート適用後に Brand Kit のルールで補完
  • 両方設定があれば、テンプレートを土台に Brand Kit でブランド一貫性を担保
  • Brand Kit の画像ライブラリから AI が視覚素材を自動取得・挿入

管理者タスク

  • SharePoint の OAL でブランド画像フォルダを設定
  • M365 Copilot アプリで Brand Kit を作成・公開
  • Brand Kit にはブランドガイドライン・カラーパレット・ボイスを含める
  • 承認済みテンプレートを SharePoint テンプレートライブラリに格納
活用フロー：「このWordレポートをもとに、会社のブランドに合わせた10スライドのデッキを作って」→ Copilot が Brand Kit + OAL のテンプレートを参照してブランド準拠デッキを自動生成。デザインチームのレビュー工数を大幅削減。

PowerPoint Live × Teams（2026年5月〜）

📺 スライド説明機能

Teams ミーティング中に参加者がスライドのテキストを選択 → Copilot に説明を依頼できる。発表者を中断させずに、自分の画面のみで解説を受信。理解が追いつかない参加者の強い味方。

🌐 多言語対応

PowerPoint Live の字幕機能と組み合わせることで、Copilot の解説も字幕表示が可能。国際会議での活用に適している。

🔒 個別体験

各参加者が自分のペースで Copilot に質問できる。発表の本流を邪魔せず、参加者全員が自分の疑問を解消できる非同期型学習体験。

展開状況：PowerPoint Live の Copilot 説明機能は 2026年5月中旬〜下旬に展開完了。Microsoft 365 Copilot ライセンス保持者に自動有効化。

項目詳細
必要ライセンスMicrosoft 365 Copilot アドオン（約 $30/ユーザー/月）。M365 Business Standard/Premium または E3/E5 に追加。個人向けは M365 Personal/Family Premium。
Claude モデルIT 管理者による Anthropic サブプロセッサ有効化が必要。EU/EFTA/UK テナントではデフォルト無効（データ規制）。
MAI-Image-2.5Build 2026（2026年6月〜）でロールアウト中。全ユーザーへの展開は順次進行。表示されない場合はリリース待ち。
Flux.2 Flex2026年4月下旬〜5月展開。テナント/リージョンによって展開タイミングが異なる場合あり。
参照ファイル上限最大 5 ファイル。参照ファイルは OneDrive/SharePoint に保存されている必要あり。ローカルファイルは直接参照不可。
Brand Kit 要件IT 管理者が SharePoint OAL の設定と M365 Copilot アプリでの Brand Kit 作成・公開が必要。
生成画像の著作権Copilot が生成した画像の商用利用条件は Microsoft のコンテンツポリシーに準拠。重要な商業用途では利用規約を確認すること。
PowerPoint LiveTeams ミーティング中の Copilot 説明機能は 2026年5月より展開。M365 Copilot ライセンス保持者に自動有効化。
重要：Copilot が生成したスライドの内容・数値・引用は必ず確認してください。特にファイル参照を使用した場合、参照先の情報が正確にスライドに反映されているかを検証することを推奨します。
