🔴 Claude / Anthropic

Claude APIClaude Opus 4.5の廃止予定を告知：Claude APIでの提供終了は2027年1月22日

Claude Platform Release Notesの11/23付項目で確認。対象は claude-opus-4-5-20251101 と alias の claude-opus-4-5。Anthropicは Claude Opus 5.5 への移行を推奨し、移行ガイド（Migrating from Claude Opus 4.5 or earlier）を案内している。同日のAnthropic SDK Python v2.13.0でもOpus 4.5がdeprecated（end-of-life 2027-01-22）としてマークされた。運用への影響：model IDを固定しているスクリプトやエージェント設定を棚卸しし、期限前にOpus 5.5での出力差を試験してから切り替える。

Source: Claude Platform Release Notes移行ガイド

Claude PlatformEnterprise Frontier Safeguards（EFS）をbeta提供、organization webhooksにexternal storageの障害・復旧イベント

Claude Platform Release Notesの11/23付項目で確認。EFSはClaude Platform、Claude Platform on AWS、Claude Models on Google Cloud（Anthropic managed）で利用でき、対象organizationが最上位モデルをZero Data Retentionで使うための仕組み。Anthropicはpromptとresponseを保持せず、暗号化したコピー（Sealed Safety Data）を顧客自身のcloud accountのbucketへ送る。Anthropic管理storageのworkspaceはEFSの対象外。organization webhooks（beta）には、顧客所有のbucketが日次チェックに失敗したときの external_storage.failed と、復旧時の external_storage.recovered が追加された。運用への影響：EFSを使う場合はbucket側の監視をwebhookで受ける構成にしておく。

Source: Claude Platform Release NotesEFS Setup guide
