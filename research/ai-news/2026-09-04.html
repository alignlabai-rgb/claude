🔴 Claude / Anthropic

アップデートClaude Code v2.1.260公開、フルスクリーン/diffパネル追加・Bash権限規制の巻き戻し修正

Source: Claude Code Changelog

🟠 GPT / OpenAI / Codex

アップデートCodex CLI v0.153.1/0.153.2公開、次期モデル「GPT-6-Astra」をモデルピッカー非表示のままAPI経由で設定可能に

v0.153.1で、モデルピッカーに表示せず既定モデルも変更しないまま、API経由でGPT-6-Astraを設定できるようになった。v0.153.2では「GPT-6-Astra Fast」ティアの説明文の誤りを「1.5倍速」から「2倍速・利用量増加」に修正（表示文言のみでリクエスト挙動に変更はない）。

🟠 動画・画像生成ツール

アップデートxAI、Grok Imagineの画像生成を強化——参照画像5枚対応・シネマティック比率追加、旧モデルの廃止予告も

画像生成・編集の品質パラメータに「auto」を追加し、未指定時の既定値をmedium一律からauto（生成はlow・編集はmedium相当を採用）に変更。画像編集で使える参照ソース画像を3枚から5枚に拡大し、21:9（シネマティック）・5:2（ワイドバナー）の新しいアスペクト比にも対応した。あわせて旧モデル「grok-imagine-image-quality」を11月2日付でAPIから廃止すると9月2日起算の60日前予告を出した。

Source: xAI API Docs

🟡 音楽生成AI

仕様変更Suno、9月3日からProプランの月間ダウンロード数を20曲に制限

9月3日付でProサブスクライバーの月間ダウンロード数を20曲、Premierを60曲に制限（無料ユーザーは生涯7曲まで）。大量生成・大量配信への対策と位置づけており、音楽業界と共同開発中とされる新世代モデル投入に向けた布石ともみられるが、新モデル自体の投入時期は未定。

Source: RouteNote / Suno Release Notes
