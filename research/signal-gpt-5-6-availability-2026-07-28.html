GPT-5.6の「使える」を
4つのsurfaceで読み分ける

GPT-5.6 Sol / Terra / Lunaの一般提供は確認できました。ただし、GA、標準ChatGPTでの選択、ChatGPT Workの利用、Codexでの利用、API提供は同じ意味ではありません。このページは2026年7月28日時点の公式情報だけで、利用可否の境界を整理したローカル公開候補です。

要修正候補 「GPT-5.6がGA」だけでは読者が実際に使える場所を判断できません。

既存トラッカーのGA・価格・モデルIDの骨格は公式情報と整合します。一方、「ChatGPTで利用可能」という表現にはsurfaceとplanを必ず添える必要があります。

観測: 2026-07-28 JST · source class: OpenAI公式のみ · provider実行なし · 公開反映未承認

先に結論

確認済み モデルファミリー

APIの現行モデルは gpt-5.6-sol、gpt-5.6-terra、gpt-5.6-luna。gpt-5.6 aliasはSolへrouteします。

誤読注意 標準ChatGPT

TerraとLunaは標準ChatGPT会話では選択できません。GPT-5.5 Instantが高速応答のdefaultで、Solは対象planのreasoning optionを担当します。

surface依存 ChatGPT Work

desktop版のWork入口は全planに提供されていますが、web/mobileはFree・Goを除くplanへ展開。さらに、Work内で使えるGPT-5.6 modelはplan別です。

明示済み Codex / API

CodexではFree・GoにTerra、Plus / Pro / Business / EnterpriseにSol・Terra・Luna。APIでは3モデルすべてが提供されています。

既存トラッカーへ適用できる安全な修正文

ChatGPT / OpenAI最新アップデートの「GPT-5.6 GA」「ChatGPT Work」記述を置き換える場合は、次の粒度なら一次情報の天井を越えません。

修正文候補: GPT-5.6 Sol / Terra / Lunaは2026年7月9日に一般提供へ移行した。APIでは3モデルすべてを利用できる。標準ChatGPT会話では対象planのreasoning optionをSolが担い、Terra / Lunaは選択できない。ChatGPT Workはdesktop版では全planに入口がある一方、web / mobileはFree・Goを除くplanへ展開され、利用できるmodelもplanとworkspace設定に依存する。CodexではFree・GoにTerra、Plus / Pro / Business / EnterpriseにSol・Terra・Lunaが提供される。

このwaveでは既存トラッカー本文を変更していません。上記は公開反映前のローカル修正候補です。

再利用できる「availability claim」チェック

  1. 日付: 発表日、観測日、rollout完了日を混ぜない。
  2. surface: standard Chat / Work / Codex / API、desktop / web / mobileを分ける。
  3. plan: Free、Go、Plus、Pro、Business、Enterprise、Eduを「全ユーザー」で丸めない。
  4. 対象: featureの入口と、そこで選べるmodelを分ける。
  5. 状態語: preview、rolling out、GA、model picker表示を同義にしない。
  6. 根拠: plan可否は公式Help / release notes、API model IDはDeveloper Docsを優先する。
  7. 不明: 公式資料が列挙しないplanやsurfaceは推測せず「未確認」とする。
