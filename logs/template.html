変更記録テンプレート

実施したことと未確認のことを分離する、短い公開運用記録です。

最終更新: 2026-10-13 / 入口の編集日と、個別記事の公式確認日は別です。

実際の区切りを記録する

日付 / 対象 / 読者への価値
実施した変更 / 固定commitまたはPR
実施した検査と結果 / 未検査
修正した失敗 / 残るgap
外部反映: local | branch | PR | main | deployment確認
次の再確認trigger

作業予定、author確認、独立レビュー、サイト配備は別の状態です。記事数やtokenを価値の証明にせず、何が読みやすくなり、どの判断を支えるかを短く書きます。個人情報、credential、内部host経路は公開記録に載せません。
