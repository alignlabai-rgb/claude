ChatGPT / OpenAI 最新アップデート完全版

OpenAI の公式リリースノート、ChatGPT Help Center、Codex Changelog、主要メディア報道をもとに、 2025年10月（Atlas）〜2026年7月の履歴を実務視点で整理し、2026年8月11日の公式差分を冒頭に重ねたページです。 単なる年表ではなく、何が変わり、どこに効き、Claude / Gemini とどう違うかまで踏み込んでまとめています。

2026年前半の OpenAI は、モデルバージョンを月次でラピッドに刻みながら （2月 GPT-5 retire → 3月 GPT-5.3/5.4 → 4月 GPT-5.5 → 5月 GPT-5.5 Instant デフォルト化）、 並行してCodex を「コーディング以外も含む万能エージェント」に拡張、 Workspace Agents を Custom GPT の後継として有償化、 Atlas ブラウザ・Codex・ChatGPT をひとつのデスクトップアプリへ統合する超アプリ化を進めてきました。

5月の本質は、事業基盤の確定フェーズです。Workspace Agents の有償化（5/6）、 GPT-5.5 Instant の全ユーザー展開、Codex のモバイル・Bedrock・Dell 提携、そして 5/22 の SEC への秘密IPO申請（評価額 $852B〜$1T 規模）。 Anthropic と並走しながら、AI 上場競争が現実フェーズに入った時期です。

6月上旬は、Codex の運用面が一気に細かくなった期間です。 ChatGPT Sites の Business / Enterprise / Edu プレビュー、Codex アプリの Claude Code / Claude Cowork からの移行フロー、 Codex Mobile の /goal・ブランチ/ワークツリー作成、CLI 0.139.0 の web search 対応、 Plus / Pro 向けの rate-limit reset banking が追加されました。 モデル発表よりも、Codex を日常の開発ワークフローに常駐させるための配布・移行・利用枠管理が主題です。

6月中旬以降は、GPT-5.5 Instant の品質強化と GPT-5.6 の段階的展開が焦点。 6/24 に GPT-5.5 Instant の会話品質・意図認識・複雑指示追従を改善するアップデートを実施。 GPT-5.6（コードネーム「kindle-alpha」）は米政府の要請で「信頼できるパートナー」限定で段階展開中。 Anthropic と並走する形で輸出管理・政府審査を経た AI リリースが標準化されつつある。

6/26、上記の観測どおりGPT-5.6 シリーズ（Sol / Terra / Luna）の限定 Preview が正式発表された。 今回から「世代番号（5.6）」と「能力階層（Sol=最上位・Terra=バランス・Luna=最速最安）」を分離するネーミング体系に移行し、 料金は Sol $5/$30・Terra $2.50/$15・Luna $1/$6（1Mトークン input/output）。米国政府との調整の下、まず信頼できるパートナー限定で API / Codex から提供開始（ChatGPT では未提供）、数週間以内の GA を予定。同日、GPT-4.5 が ChatGPT から正式退役（予告どおり）。 さらに 6/24 に推論特化カスタムチップ「Jalapeño」を Broadcom と共同発表、6/25 に Codex Remote が全プランで GA、 6/11 にはOna 買収発表（Codex に永続クラウド実行環境を追加、Codex WAU は 500万人超＝年初比400%増）と、 事業基盤・インフラ・モデルの3方向で節目が重なった2週間だった。

そして 7/9、予告どおりGPT-5.6 Sol/Terra/Luna が限定Previewからわずか12日でGAに移行。同日、 OpenAI はChatGPTとCodexを1つのデスクトップアプリへ正式統合し、GPT-5.6を搭載した新モード 「ChatGPT Work」を発表（無料プラン含む全プラン・全世界で提供）。Codex は「開発者向け専用ビュー」として存続しつつ、 インラインDiff編集・アプリ内PRレビュー・マルチリポジトリ プロジェクトを獲得。 プラグインブラウザ刷新・ロールアウトトークン予算・マルチエージェント委任制御・使用量上限リセットクレジットなど運用機能も一括追加された。 Amazon Bedrock は GPT-5.6 Sol/Terra/Luna（max reasoning effort ネイティブ対応）を追加。 OpenAI は Codex の週間アクティブユーザーが500万人超・3ヶ月で2倍に成長し、この間に150件の機能・改善を出荷したと発表（非開発者が全体の約2割）。 さらに 7/15 には Work Louder と共同開発した外付けマクロパッド「Codex Micro」の発売も予告されており、 「コーディング特化ツール」から「ChatGPTの主要ワークモードの1つ」へ、Codexの位置づけが1週間で大きく変わった期間でした。

7月下旬（7/18〜7/24）の本質は、デスクトップ体験の再構築と Sites 機能の一般展開です。 7/17 に Web 公開・制作機能 ChatGPT Sites のパブリックベータが開始し、7/18 には Codex が ChatGPT デスクトップ に完全統合。 7/20 には初期の検索アシスタント Atlas が正式終了し、すべての機能が ChatGPT デスクトップに統合・刷新。 7/23 には GPT-5.6 Sol に関する脱獄挙動および METR 評価に対する技術報告と公式見解が提示されました。

Workspace Agents の意味 — Custom GPT との違い

Workspace Agents は Custom GPT の単純な改良ではなく、戦略上の置き換えです。 Custom GPT は「個人ユーザーが作るボット」でしたが、Workspace Agents は 組織の権限・データ・コンピューティング枠を共有する Codex ベースのエージェントです。

① Codex を中核に置く

コーディング・コンピューター操作・ツール連携が「文字応答」と並列で扱える。

② 組織共有・管理

権限ガバナンス・実行ログ・評価がプラットフォームに組み込まれている。Frontier の延長線上。

③ SaaS への直接接続

Slack / Salesforce / その他主要 SaaS にプラグイン可能。Anthropic の MCP コネクター戦略と並走。

2026/5/6 からクレジット課金に移行し、無料期間は終了。商用本格運用フェーズに入りました。

Codex の動き — 「コーディング以外もできる万能エージェント」へ

Codex は2026年に入り、コーディング限定のツールから「ほぼすべてのタスク対応の万能エージェント」に拡張されました。

  • 機能拡張：コーディング + コンピューター操作 + 日常ツール連携 + 画像生成 + 設定記憶 + 継続タスク実行
  • 規模：週間アクティブユーザーが 500万人超（7/9時点、3ヶ月で2倍）、非開発者が約2割を占める
  • 分配：iOS / Android アプリ統合（5/15）、AWS Bedrock ネイティブ対応（5/10、7/9にGPT-5.6系列追加）、Dell PowerEdge オンプレ（5/19）、ChatGPTデスクトップアプリへの統合（7/9）
  • 性能：GPT-5.3-Codex-Spark + Cerebras で 1,000 トークン/秒、GPT-5.6 GA（7/9）で Computer Use も高速化
  • UI：Goal Mode 正式化（5/25）、macOS Appshots でフルスクリーンアプリ取込、インラインDiff編集・アプリ内PRレビュー（7/9）
  • 運用機能：プラグインブラウザ刷新・ロールアウトトークン予算・マルチエージェント委任制御・使用量上限リセットクレジット（7月上旬・報告ベース）
  • ハードウェア：外付けマクロパッド「Codex Micro」（Work Louder共同開発、7/15発売予定）

Claude Code が「CLI 中心 + Managed Agents」だとすると、Codex は「マルチサーフェス（Mac / Mobile / Cloud / IDE 拡張・そして今やChatGPT本体）の単一エージェント」というアプローチ。7/9の統合で、この路線がさらに一段進んだ。
