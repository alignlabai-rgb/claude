Comfy Cloud & Comfy MCP

「ComfyUI をローカルGPUなしでクラウド実行」がついに公式化。2026年3月に Comfy Cloud が正式ベータ卒業、6月30日には AI エージェントから自然言語で ComfyUI を操作できる「Comfy MCP」が登場した。Claude Code・Claude Desktop から直接つながる、このハブの制作パイプラインに直結する更新。

Comfy Cloud 正式版（2026-03） Blackwell RTX 6000 Pro Comfy MCP 発表（2026-06-30） Claude Code / Claude Desktop 対応 $30M 調達・評価額$500M

1. Comfy Cloud とは — 公式ホスティング版 ComfyUI

workbench/knowledge/comfyui.html（既存の完全ガイド）で扱ってきた ComfyUI は、これまでローカルPCに GPU を用意してインストールするのが前提でした。Comfy Cloud（comfy.org/cloud / cloud.comfy.org）は、Comfy Org 自身が提供する公式の完全ホスティング版です。セットアップ・GPU調達が一切不要で、ブラウザから既存のワークフロー資産（JSON・カスタムノード）をほぼそのまま実行できます。

2026年3月にベータを卒業して正式サービス化。ローカル版ワークフローの約90%のカスタムノードがそのままクラウド上で動作すると報告されており、既存の資産（LoRA・ControlNet・IP-Adapter構成など）を大きく作り直す必要はありません。

💡 このハブにとっての意味: manga-pipeline.html や video-pipeline.html が前提としてきた「ComfyUIを動かすローカルGPU環境」が、必須条件ではなくなりつつある。低スペックPCやノートPCからでも同じ生成パイプラインを回せる可能性が出てきた。

課金はワークフローが実際に実行されている時間のみ発生し、ノードをつなぐ・設定するといったアイドル時間には課金されません。今後は複数人での同時編集（マルチユーザー編集）・ノードツリーのバージョン管理・共有モデルライブラリといったコラボレーション機能が追加される計画も報じられています（未リリース・要確認）。

3. Comfy MCP — AIエージェントからComfyUIを直接操作

2026年6月30日、Comfy Org は Comfy MCP を発表しました。これは Model Context Protocol（MCP）経由で、Claude Code・Claude Desktop のような AI エージェントから ComfyUI の生成機能を自然言語で直接呼び出す仕組みです。ノードグラフを手で組む必要がなく、モデルの手動ダウンロードもローカルGPUも不要になります。

🔌 なぜ重要か: これまで「エージェントに画像/動画生成をさせる」には API を個別に叩くコードを書く必要がありました。Comfy MCP はこれを標準化し、harness-engineering.html でいう「Tool層」を ComfyUI エコシステムに対して一気に整備した形になります。

実装①

Hosted MCP Server（推奨・最も手軽）

  • cloud.comfy.org/mcp に接続するだけ
  • Comfy Cloud の GPU上でワークフローを実行
  • プリインストール済みモデル・テンプレートライブラリ全体を検索・利用可能
  • Claude Desktop・Claude Code などチャット駆動のエージェントに最適
  • ローカルGPU・モデルダウンロード一切不要
実装②

Local MCP Server

  • ローカル環境で動作しつつ、30以上の外部パートナープロバイダへの統一生成ツールを提供
  • 対応例: BFL（FLUX）・Ideogram・Kling・Runway・Veo・Meshy・ElevenLabs など
  • 複数社のAPIをComfyUI経由で1つのインターフェースに統合
実装③

CLI Companion

  • ターミナル・スクリプト・CIパイプライン向け
  • comfy generate: パートナーAPIへの単発呼び出し
  • comfy run: Comfy Cloud 上でワークフロー全体を実行
  • OpenClaw・自動化スクリプトへの組み込みに向く

Claude Desktop / Claude Code からの接続例

Claude Desktop の場合、カスタムコネクタとして以下のURLを追加し、OAuthでサインインするだけで利用開始できます（Claude Code など他クライアントも同様の MCP 接続手順に準拠）。

# Claude Desktop: Settings → Connectors → Add Custom Connector URL: https://cloud.comfy.org/mcp 認証: OAuth サインイン（Comfy Cloud アカウント連携） # 接続後、エージェントへの指示例（自然言語） "このキャラクター画像を参照に、雨の夜の路地に立っているシーンを Kling で10秒の動画にして、ネイティブ音声で環境音も入れて" # → エージェントがモデル選定・ノード構成・実行までを裏側で処理

この構成は creator-system/stack-map.html で扱っている「MCPコネクター時代の接続方式」の延長線上にあり、Blender・Adobe系の創作系MCPコネクター（2026年4月28日発表）と同じ潮流に位置づけられます。

📈 対応エージェントの拡大（報告ベース）: 発表直後は「Claude Desktop / Claude Code は確定、Codex・Cursor・Hermesは対応予定だが未確定」という段階でしたが、その後の情報ではパブリックベータとしてClaude・Codex・Hermes・Cursorなど複数エージェントに向けて公開されたと報じられています。Comfy Org 自身「本番パイプライン向けに作られた初のMCP」と位置づけており、対応状況は流動的なため導入前に公式ドキュメント（docs.comfy.org/agent-tools/cloud）で確認してください。

6. 現場での実例 — 「ここまで来たか」という導入事例

ComfyUI／Comfy Cloud／Comfy MCP がどこまで実戦投入されているかを示す、複数の一次報道で確認できた実例をまとめます。「個人のノードいじり」から「全国ネットのCM」まで実用域が一気に広がっている点が、このエコシステムの勢いを象徴しています。

最も象徴的な実例

SVEDKAの「Shake Your Bots Off」— 初のAI主体スーパーボウルCM

2026年2月9日放映のSuper Bowl LX。SVEDKA（ウォッカブランド）が広告制作会社 Silverside AI と組み、ロボットキャラクター「Fembot」と新キャラ「Brobot」が踊る30秒CM「Shake Your Bots Off」を制作。複数の一次報道（Hollywood Reporter・AdWeek・TechCrunch・GenMediaLab）が「主にAIで生成された初の全国ネットSuper Bowl CM」と報じました。Fembotの再構築とダンス動作の学習に約4ヶ月を要し、振付は公募で選ばれた一般人（Jessica Rizzardi氏、23歳）のTikTok動画を参照。Silverside AI はComfyUIのグラフエディタを使って主要ブランドキャンペーンを制作していると報じられており、同社は物議を醸したCoca-ColaのAI生成CMも手掛けたチームです。

エンタープライズ導入

Netflix・Apple・Ubisoftでの採用

TechCrunchの報道によれば、ComfyUIは4,000,000人以上のユーザーを抱え、VFXハウス・広告代理店・ゲームスタジオ・（報道内では）諜報機関までもが「ほぼ全面的にComfyUIのグラフエディタに集約している」とされ、Netflix・Apple・Ubisoftでの導入実績が確認されていると報じられています。ComfyUIは「アーティストのデスクトップ」と「本番バックエンド」の両方で動く二重の立ち位置を獲得しました。

雇用市場への影響

「ComfyUIアーティスト」という新職種

求人サイト・LinkedInの分析では、「ComfyUI artist」あるいは「ComfyUI artist/engineer」という肩書き自体が、大手企業やクリエイティブスタジオの求人票に登場する採用シグナルになったと報告されています。ノードベース生成AIの操作スキルが、単なるツール知識ではなく独立した職能として市場価値を持ち始めた実例です。

スタジオ導入例

Black Math — モジュール型クリエイティブパイプライン

クリエイティブスタジオ Black Math は、モーション・テクスチャ・生成ツールを接続するモジュール型パイプラインの構築にComfyUIを採用していると報じられています。単発の画像生成ツールとしてではなく、複数の制作工程を横断する基盤インフラとして使われている点が、本ハブの stack-map.html / spec.html が目指す設計思想と共通します。

Comfy MCP 公式ユースケース

「3枚の絵コンテから映画的な動画クリップを作って」

Comfy Org 自身が公開している代表的な利用例が "Turn three storyboard frames into a cinematic clip — then explain the workflow so my teammate can reuse it"（3枚の絵コンテフレームから映画的なクリップを作り、チームメイトが再利用できるようワークフローを説明して）という指示文です。upload_file で静止画を渡し submit_workflow で動画テンプレートを実行するだけで、エージェントが絵コンテを動画化。生成は100%再現可能でURL共有もでき、ワークフローを知らないチームメイトでも「エージェントに実行させる」だけで再利用できる、という設計思想が示されています。

サードパーティ実装

artokun/comfyui-mcp — 108ツール・29スキルの野心的OSS実装

個人開発者によるOSS実装 artokun/comfyui-mcp は、108個のMCPツールと29個のAIスキル（Flux・WAN・LTX 2.3・Qwen・Z-Image・Ideogram4・ERNIE・ANIMA対応）を提供するClaude Codeプラグイン。13個のインストーラーパック・11個のスラッシュコマンド・4体の自律エージェント・4個のフックを含み、Claude・ChatGPTどちらのサブスクリプションでもAPIキー不要で動作し、ComfyUIサイドバー内で自律エージェントがライブでグラフを編集できる、という報告があります（公式Comfy MCPとは別の第三者プロジェクト）。公式・非公式の双方でエコシステムが急速に厚みを増している状況が伺えます。

7. creator-system パイプラインへの応用シーン

  • GPU非保有環境での漫画コマ生成: manga-pipeline.html のLoRA+ControlNet+IP-Adapter構成を、ノートPCからComfy Cloud経由で実行できる可能性。ただし1ワークフローの実行時間上限（Standard/Creator: 30分、Pro: 1時間）に注意
  • Claude Code からの直接生成: Comfy MCP のHosted Serverに接続すれば、Claude Codeのセッション内から「このシーンを生成して」と指示するだけでComfyUIワークフローが実行される。loop-engineering.html でいう「Act」フェーズがMCP経由でComfyUIに直結する
  • CI/バッチパイプラインでの活用: comfy run をOpenClawや自動化スクリプトに組み込めば、openclaw.html のワークフロー定義から直接クラウドGPUでの生成をキックできる
  • コスト設計上の論点: ローカルGPU（初期投資型・固定費）とComfy Cloud（従量課金・変動費）のどちらが量産体制に適するかは、月間生成本数とワークフロー当たりの実行時間次第。kpi-dashboard.html のコスト指標と突き合わせて判断する余地がある

⚠️ 未検証事項: 本ページの内容はWebSearchによる一次情報・複数の比較記事の突き合わせに基づく。実際の90%カスタムノード互換性・具体的なクレジット消費量・Claude Codeとの接続時の細かい挙動は、このハブの制作パイプラインで実地検証していない。導入前に小規模なワークフローで動作確認することを推奨。
