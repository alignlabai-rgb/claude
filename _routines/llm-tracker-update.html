実施手順（Claude セッションで実行）

1

前月比較 — 何が変わったか把握

各トラッカーページの「最近の更新」セクションを読み、前月末時点での最新モデル名・バージョンを控える。git log で当該ファイルの最終コミット日も確認する。

2

新情報の収集（Web 検索）

Claude に WebSearch で各ベンダーの直近 30 日のリリース情報を調査させる。確認項目: ① 新モデルリリース ② API 仕様変更（入出力トークン上限・モダリティ） ③ 料金改定 ④ 廃止予告

# Claude への指示テンプレート 「[ベンダー名] の [前月日付] 以降の以下情報を調査してください: 1. 新モデルリリース（モデルID・機能概要・対象プラン） 2. API 仕様変更（context window・vision対応・tool use） 3. 料金改定（input/output $/1M tokens） 4. 廃止・非推奨モデルの予告 情報源: 公式ブログ・公式ドキュメント・GitHub リリースノートを優先」
3

トラッカーページの更新

収集した情報を対象ファイルの「最近の更新」セクション冒頭に追記する。既存エントリは削除せず下に残す（最新が上）。フォーマット例:

<!-- 新エントリ（先頭に追加）--> <div class="update-entry"> <span class="date">2026-06-01</span> <span class="badge badge-teal">NEW</span> <strong>モデル名 X.Y リリース</strong> <p>概要説明。前バージョンとの差分を 2〜3 文で。</p> </div>
4

claw-stack/comparison.html の確認

新モデルが claw-stack/comparison.html の「LLM エンジン」欄に反映されているか確認。OpenClaw が使う LLM に変更があれば更新する。

5

workbench/knowledge/ 個別ページの確認

重大な仕様変更（モデル廃止・APIレート大幅変更）があれば、workbench/knowledge/[vendor].html にも反映する。小規模更新はトラッカーのみで OK。

6

コミット & プッシュ

git add research/*-recent-updates.html git commit -m "Monthly LLM tracker update — 2026-XX-XX Updated: claude, chatgpt, gemini, grok, qwen, glm trackers Key changes: [変更点の概要]" git push
