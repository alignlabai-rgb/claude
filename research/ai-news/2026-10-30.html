🔴 Claude Code

Claude CodeClaude Code v2.1.314（10/30）：permissions.blockWritesOutsideWorkingDirectories を追加、Foundry/Bedrock/effort上限の失敗を修正

GitHub Releasesで確認。新設定 permissions.blockWritesOutsideWorkingDirectories で、Write・Edit・NotebookEditが全permission modeで作業ディレクトリ外のパスを拒否。Claude appsゲートウェイのupstreamに groups（IdPグループ別の振り分け）、Bedrock upstreamに guardrail_trace（どのguardrailが作動したかを一致テキストなしで記録）。VS CodeとClaude Desktopは放置された200Kトークン超の会話を要約。管理者がeffortを上限設定した際の「Invalid effort level」失敗は、effortを下げて再試行する形に修正。Foundryで既定のSonnet/Opus/Haikuのデプロイがない場合は旧モデルへフォールバック、Bedrockで画像が多いセッションは古い画像を除去して圧縮。claude -p は起動失敗時にエラーを出して終了コード1を返す。PreCompact hookの出力は1つ1万文字までに制限。リリースノートは一部省略されている可能性がある。v2.1.313はページに見当たらなかった。
