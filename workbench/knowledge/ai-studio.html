Google AI Studio とは

Google AI Studio は、Gemini モデルを無料でブラウザ上から試せる開発者向けプレイグラウンド。プロンプト設計・モデル選択・パラメータ調整のすべてを GUI で行い、結果が満足いけばコードに変換してアプリに組み込める。

OpenAI Playground に相当するが、無料枠が大きく、マルチモーダル入力（画像・音声・動画・PDF）がネイティブ対応している点が異なる。

開発フロー上の位置付け: 「アイデアを試す場所」。ここで固めたプロンプト・システム指示をそのまま本番コードに転用する。Vertex AI は本番 API のホスティング先。

特徴的な強み

  • ✅ 無料で全 Gemini モデルにアクセス
  • ✅ 1M トークンコンテキストをブラウザで試験可
  • ✅ マルチモーダル: テキスト・画像・音声・動画・PDF
  • ✅ Google 検索グラウンディング（リアルタイム検索）
  • ✅ 関数呼び出し（Function Calling）のテスト
  • ✅ コード出力（Python/JS/Go/REST）ワンクリック
  • ✅ Fine-tuning（チューニング）も無料枠で可能
  • ✅ API キー管理と即時利用

UI 構成と各モード

AI Studio のインターフェースは用途別に複数のモードに分かれている。左サイドバーで切り替える。

💬

Chat（チャット）

会話型インターフェース。システム指示を設定し、マルチターンの対話をテストする。最もよく使うモード。温度・Top-P・Max tokens をリアルタイムで調整。

✍

Generate text（単発生成）

1 回の入力 → 1 回の出力のシンプルな補完モード。コンテンツ生成・要約・翻訳のプロトタイプに使う。FEW-shot 例を直接記述できる。

{}

Structured output（JSON モード）

出力を特定の JSON スキーマに強制するモード。フォーム入力の処理・データ抽出・API レスポンス設計のテストに。response_schema を GUI で定義できる。

🖼

Image generation（画像生成）

Imagen 3 / Imagen 4（2026-05 最新）を利用した画像生成。テキスト→画像。アスペクト比・スタイルを選択可能。

🎵

Generate speech（音声合成）

テキストを自然な音声に変換（TTS）。30+ 言語、複数の音声スタイルから選択。Audio Overview の音声クオリティをイメージ。

システム指示（System Instructions）

モデルの振る舞い・役割・制約を定義するプロンプト。毎回ユーザーメッセージに含める必要がなく、ターンを超えて持続する。AI Studio で最も重要な設定項目。

システム指示は API での system_instruction パラメータに対応。AI Studio で作成したシステム指示をコードにエクスポートすればそのまま使える。

Context Caching でコスト削減

同じ長いドキュメントを繰り返し参照するワークフローでは、Context Caching（コンテキストキャッシュ）を使うと大幅にコストを削減できる。

  • 最低 32,768 トークン以上のコンテキストが対象
  • キャッシュ保存コスト: 通常の 1/4
  • キャッシュ保存期間: 最大 1 時間（延長可）
  • ストレージ料金: $1.00 / 1M tok / hour
# Context Caching の使い方（Python SDK） import google.generativeai as genai # 長いドキュメントをキャッシュ cache = genai.caching.CachedContent.create( model='models/gemini-2.5-flash', system_instruction=long_document, ttl=datetime.timedelta(hours=1), ) # キャッシュを使ってリクエスト model = genai.GenerativeModel.from_cached_content(cache) response = model.generate_content("この文書の要点は？")

主要機能詳細

🌐 Google 検索グラウンディング

Gemini にリアルタイムの Google 検索結果を参照させる機能。「今日の天気は？」「最新の為替レートは？」など時系列に敏感な質問に対して正確な回答が可能になる。

  • 有効化: システム指示パネルの「Tools」→「Google Search」をオン
  • 回答に検索引用が付く
  • 追加コスト: $35/1000 リクエスト（有料プラン）
  • NotebookLM との違い: 特定ドキュメントでなく広範な Web から検索

🔧 Function Calling（関数呼び出し）

モデルに「外部ツールを呼び出す能力」を与える機能。AI Studio で JSON Schema として関数を定義し、モデルが適切なタイミングで呼び出す。

# 関数定義の例 get_weather = { "name": "get_current_weather", "description": "Get the current weather", "parameters": { "type": "object", "properties": { "location": { "type": "string", "description": "City name" } }, "required": ["location"] } }

📤 コードエクスポート

AI Studio で動作確認したプロンプト・設定をワンクリックでコードに変換する。プロトタイプから本番実装への最短ルート。

📁 Files API（ファイルアップロード）

大きなファイルを API に直接アップロードして参照させる機能。

  • 対応形式: PDF・画像（JPG/PNG/WebP）・音声（MP3/WAV）・動画（MP4）
  • 最大ファイルサイズ: 2GB / ファイル
  • 保存期間: アップロードから 48 時間で自動削除
  • 無料枠: 20GB の一時ストレージ

🔬 Evaluate（評価）

複数のプロンプトバリアントを体系的に評価する機能。A/B テスト・品質評価の自動化が可能。

  • テストデータセット（CSV / JSONL）をアップロード
  • 複数モデル・プロンプトの比較表を自動生成
  • スコアリング基準を定義して自動採点

クイックスタート（5 分で最初の API 呼び出し）

1

aistudio.google.com にアクセス

Google アカウントでログインするだけ。クレジットカード不要。

2

「Create new prompt」→ Chat を選択

左上の「+ New prompt」から「Chat」を選ぶ。

3

モデルと System Instructions を設定

右パネルでモデル（Gemini 3.5 Flash 推奨）を選択。「System instructions」欄にロール・制約を記述。

4

プロンプトを試してパラメータを調整

チャット欄で対話しながら Temperature・Max tokens を調整。期待通りの出力になるまで反復。

5

「Get code」でコードをエクスポート

右上の「Get code」ボタンで Python/JS コードを取得。API キーを「Get API key」ページで発行して置き換えれば即動く。

コード例集

基本: テキスト生成（Python）

# pip install google-generativeai import google.generativeai as genai genai.configure(api_key="YOUR_API_KEY") model = genai.GenerativeModel( model_name="gemini-2.5-flash", system_instruction="あなたは日本語で回答するリサーチアシスタントです。" ) response = model.generate_content("AI エージェントの主要なアーキテクチャパターンを教えて") print(response.text)

マルチモーダル: 画像 + テキスト

import google.generativeai as genai import PIL.Image genai.configure(api_key="YOUR_API_KEY") model = genai.GenerativeModel("gemini-2.5-flash") # 画像ファイルを直接渡す image = PIL.Image.open("character_design.png") response = model.generate_content([ image, "このキャラクターデザインの特徴を分析して、改善点を提案して" ]) print(response.text) # URL の画像も直接参照可能 response2 = model.generate_content([ {"url": "https://example.com/image.jpg", "mime_type": "image/jpeg"}, "この画像を説明して" ])

ストリーミング生成（長文を逐次表示）

model = genai.GenerativeModel("gemini-2.5-flash") # stream=True でトークンごとに受け取る for chunk in model.generate_content("長い記事を書いて", stream=True): print(chunk.text, end="", flush=True)

JSON モード（構造化出力）

import json import google.generativeai as genai from google.generativeai.types import GenerationConfig genai.configure(api_key="YOUR_API_KEY") model = genai.GenerativeModel("gemini-2.5-flash") response = model.generate_content( "以下の記事から登場人物の情報を抽出してください:\n\n太郎は35歳のエンジニア...", generation_config=GenerationConfig( response_mime_type="application/json", response_schema={ "type": "object", "properties": { "name": {"type": "string"}, "age": {"type": "integer"}, "occupation": {"type": "string"} } } ) ) person = json.loads(response.text) print(person) # {"name": "太郎", "age": 35, "occupation": "エンジニア"}

チャット（マルチターン会話）

model = genai.GenerativeModel( "gemini-2.5-flash", system_instruction="あなたは漫画の脚本アドバイザーです。" ) chat = model.start_chat(history=[]) # 会話の継続（history が自動管理される） r1 = chat.send_message("主人公が過去の失敗から立ち直るシーンのアイデアは？") print(r1.text) r2 = chat.send_message("それを3ページの漫画にするとしたら各ページのコマ構成は？") print(r2.text) # 会話履歴を確認 for msg in chat.history: print(f"{msg.role}: {msg.parts[0].text[:50]}...")

Google 検索グラウンディング（Python）

from google.generativeai import protos model = genai.GenerativeModel("gemini-2.5-flash") # Google 検索ツールを有効化 response = model.generate_content( "2026年5月の最新の AI ニュースを教えて", tools=[protos.Tool(google_search=protos.GoogleSearch())] ) print(response.text) # grounding_metadata にソース URL が含まれる for src in response.candidates[0].grounding_metadata.grounding_chunks: print(src.web.uri)

上級機能

Fine-tuning（チューニング）

少数のサンプルデータから自分専用のモデルをファインチューニングできる。AI Studio の GUI から操作可能。

  • 対象モデル: Gemini 2.5 Flash-Lite（主）
  • 必要データ: 最低 10〜20 件の例（推奨 100〜500 件）
  • 形式: JSONL（{"text_input": "...", "output": "..."}）
  • トレーニング時間: 数分〜1 時間
  • コスト: トレーニングデータ量に応じた課金
ファインチューニングが有効なケース: 特定のトーン・スタイル・フォーマットへの適応。数百例で既存モデルの挙動を大きく変えられる。

Long Context 活用（1M トークン）

1M トークン（≒ 約 75 万文字）のコンテキストは、他の LLM の 4〜8 倍。

  • 本 1 冊丸ごと: ~100K トークン × 10 冊分
  • コードベース全体: 中規模プロジェクトなら丸ごと入る
  • 長編動画（1.5時間 MP4）: 直接解析可能
  • データベース的な Q&A: テーブル全体を渡して問い合わせ

Live API（リアルタイム音声・映像）

Gemini の音声入出力をリアルタイムでストリーミングする API。低遅延の音声会話アプリ構築に使用。

  • WebSocket ベースの双方向ストリーミング
  • 音声入力 → テキスト変換なし → 直接 Gemini が処理
  • テキスト・音声の混合出力
  • カメラ映像のリアルタイム解析にも対応
# Live API（WebSocket）の概念コード import asyncio from google import genai client = genai.Client(api_key="YOUR_API_KEY") async def live_session(): async with client.aio.live.connect( model="gemini-live-2.5-flash-preview" ) as session: # 音声データを送信 await session.send(audio_data, end_of_turn=True) # 音声応答を受信 async for response in session.receive(): if response.data: play_audio(response.data)

Imagen 4 による画像生成

from google import genai client = genai.Client(api_key="YOUR_API_KEY") response = client.models.generate_images( model='imagen-4-preview', prompt='A manga-style illustration of a futuristic city at dusk', config={'number_of_images': 4} ) for img in response.generated_images: img.image.save('output.png')

実践的なヒント集

📌 プロンプト設計の鉄則

  • システム指示でペルソナ設定: 「あなたは〇〇のエキスパートです」で品質が安定
  • 出力形式を明示: 「JSON で」「箇条書きで」「500字以内で」
  • Few-shot 例を入れる: 入力→出力の例を 2〜3 個入れると精度が上がる
  • CoT を促す: 「ステップバイステップで考えてください」で推論精度向上

📌 コスト最適化

  • 開発中は Flash-Lite で試してから Flash / Pro に切り替え
  • 同じ長文ドキュメントを繰り返し参照 → Context Caching
  • 大量バッチ処理は夜間 or 並列化でレート制限を回避
  • Max tokens を適切に設定してコスト管理

📌 デバッグ・品質向上

  • Temperature を下げる: 事実確認や構造化出力は 0.1〜0.3 推奨
  • モデルを切り替えて比較: 同じプロンプトを Flash / Pro で試して差を確認
  • Evaluate 機能: 複数プロンプトを体系的に比較評価
  • System instructions のバージョン管理: プロンプトもコードと同様に Git で管理

📌 AI Studio → 本番への橋渡し

  • 「Get code」→ コピペで即動くベースコードを取得
  • API キーは環境変数で管理（GOOGLE_API_KEY）
  • 本番では google-cloud-aiplatform SDK に移行検討
  • レート制限対策: exponential backoff を実装
