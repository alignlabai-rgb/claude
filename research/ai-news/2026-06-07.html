Claude / AnthropicClaude 自己コード記述率 80% 超 — 自律的後継開発への警鐘

Claude Code/reload-skills コマンド追加 — スキル自動ロード対応

.claude/skills/ ディレクトリ内のプラグインがマーケットプレイス登録なしで自動ロードされるようになった。claude plugin init で新プラグインをスキャフォールド可能になり、/reload-skills コマンドで再起動なしのディレクトリ再スキャンが実現。セキュリティレビュープラグインは同一セッション内で脆弱性を検出・修正する機能も搭載。

📌 Anthropic Release Notes

Codex / OpenAICodex 週次アクティブユーザー 500 万突破 — ナレッジワーカー急増

2 月のデスクトップアプリ展開以降、Codex の週次アクティブユーザーが 6 倍増となり 500 万を超えた。ナレッジワーカーが全体の 20% を占め、開発者の 3 倍速で伸長中。マルチエージェント v2 のクリーンなフォローアップ・メタデータ対応も含む最新アップデートが並行リリース。

📌 OpenAI

Grok / xAIGrok 4.4 / 4.5 / 5 開発ロードマップ公開

Grok 4.4（1 兆パラメータ）と Grok 4.5（1.5 兆パラメータ）が数週間以内にリリース予定。Grok 5 は Colossus 2 スーパークラスターで最大 10 兆パラメータのバリアントを訓練中。段階的スケールアップ路線が鮮明になった。

📌 xAI / BenchNorMean

Grok / xAIGrok Imagine 1.5 Preview API 一般公開 — Grok Voice も同時ロールアウト

xAI が Grok Imagine 1.5 Preview を API 経由で一般提供開始。同時に Grok Voice（モデルとの自然な音声対話）が正式ロールアウト。どちらも xAI API を通じた外部統合が可能になり、マルチモーダル活用の幅が広がった。

📌 xAI

MCPMCP 次期仕様リリース 2026-07-28 確定 — 「成熟マイルストーン」
