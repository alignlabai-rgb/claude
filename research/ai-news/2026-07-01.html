🔴 Claude / Anthropic

GAClaude Sonnet 5 正式リリース：ネイティブ1Mトークン窓・Opus 4.8に迫る性能

Anthropicが新フラッグシップSonnetモデル「Claude Sonnet 5」を発表。ネイティブ100万トークンのコンテキスト窓を持ち、推論・ツール利用・コーディングなどエージェント性能でOpus 4.8に近づきつつ低コストを実現。Free/Proプランのデフォルトモデルとなり、Max/Team/Enterpriseでも利用可能。8月31日まで$2/$10（百万トークンあたり入力/出力）の導入価格を適用、以降は$3/$15。

Source: Anthropic, TechCrunch, AWS Blog

更新Claude Code 2.1.197：Sonnet 5デフォルト化＆組織既定モデル設定

Claude Code CLIがv2.1.197にアップデートし、Claude Sonnet 5をデフォルトモデルに採用（ネイティブ1Mトークン窓対応）。管理者が組織コンソールでデフォルトモデルを設定できる新機能、セッションへの読みやすいデフォルト名付与、チャット内ファイル添付のクリック対応も追加された。

Source: Claude Code Changelog

🟠 Grok / xAI

新機能X、ホスト型MCPサーバーをGA：GrokなどAIエージェントがリアルタイムX データに直接アクセス

X Developersが6月30日、ホスト型X MCP（Model Context Protocol）サーバーを発表。GrokやCursorなどのAIエージェントが、API認証情報の設定や独自コネクタなしにXのリアルタイム投稿データへ直接アクセス可能になった。エージェント開発における主要な摩擦点の一つを解消する。

Source: X Developers

Source: X (Elon Musk)
