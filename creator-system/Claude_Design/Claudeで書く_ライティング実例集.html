Claudeで書く。

ライティング実例集

書くことは、考えること。だから書くのが苦しいときは、たいてい考えがまだ整っていない。 Claudeはその「整える」ところに、何度でも付き合ってくれる。 このノートでは、書く仕事を10カテゴリに分け、ブログ・コピー・小説・SNSの4実例を追いかけ、 すぐ使い回せるプロンプトを6つ並べた。最後に、書く現場でClaudeにどう頼るかの早見表を置いた。

01

Claudeで書ける 10種

書き仕事は形を変えても、骨は似ている。ジャンルごとの「型」をClaudeが先に出してくれる。

記01 / ARTICLE

記事・ブログ

構成案→見出し→本文。導入と結論を先に決めると速い。

未来は、書く人のもの。
ことばは、ちいさな技術だ。
3行で、ひとを動かせ。
考えてから、書こう。
売02 / COPY

キャッチコピー

5案・10案・30案と桁を変えて発注。バリエの幅で選ぶ。

　雨はもう、何時間も降りつづけていた。
　駅前のロータリーは灰色に沈み、
彼女は一本の傘も持たないまま、
ただ、立っていた。
　「来ないかもしれませんね」
　声は、後ろから聞こえた。

02

実例集：プロンプト → 出力

頼み方によって、返ってくる文章の表情が変わる。4つの典型で型を盗む。

CASE A · BLOG ARTICLE

ブログ記事を
骨組みから書く

場面「Claudeで毎日の文章仕事がどう変わったか」というテーマで、媒体「働く人のためのノート」に寄稿。3,000字、読了7分。
あなたは熟練のWeb編集者です。 下のテーマで、3,000字のブログ記事を書いて。 # テーマ Claudeで毎日の文章仕事がどう変わったか # 媒体 「働く人のためのノート」/ 読者は30-40代の会社員 # 構成 1. まず構成案だけ出して（H2見出し5つ、各H2の要点3行） 2. OKしたら本文を書く # トーン 語り口は親しみやすく、断定しすぎない。 「結論先・具体例・小さな提案」の順で。 1段落は3-4文。 ではまず構成案から。
振り返り「まず構成だけ」「OKしたら本文」と2段にすると、方向違いで丸ごと書き直す事故が消える。 構成のH2が5つ出てきたら、気になる順に並べ替えて返すだけで、記事の骨は決まる。
WORK 2026.05.26 READ 7min

毎日の文章仕事を、もう一度好きになるまで

書くことが、いつのまにか「片付ける作業」になっていた。Claudeと半年並走して、それがまた「考える時間」に戻ってきた話。

もくじ
  1. 書くのが嫌いになっていた頃のこと
  2. 「叩き台が一瞬」がもたらしたもの
  3. 編集者役を、もう一人雇った気分
  4. うまくいかなかった日もある
  5. これからの「書く」の意味
書くのが嫌いになっていた頃

正直に言うと、去年の秋ごろから、書くのが面倒だった。会議メモ、議事録、企画書、社内向けの告知…。「書く」という行為が、頭で考えるよりも先に、フォーマットに流し込む作業になっていた。

その頃に出会ったのが、Claudeだ。

CASE B · CATCH COPY

キャッチコピーを
10案ふらせる

場面新サービス「Inkbird」のキャッチコピー候補がほしい。「書く人のための静かなツール」というコンセプトを軸に、方向の違う10案を比較したい。
あなたは凄腕のコピーライターです。 新サービス「Inkbird」のキャッチコピーを10案。 # コンセプト 書く人のための、静かなツール。 気が散らない場所と、いつでも頼れる相棒。 # 出し分けの軸 - 短い詩のような3案 - 機能を匂わせる3案 - 挑発的・反語的な3案 - ユーザーの内側の声1案 # 出力フォーマット 番号 / コピー本文 / 30字以内 / 狙い1行 「静寂」「ひとりの時間」「考える」あたりの語彙を活かしつつ、 被らないように。無難なのは捨てて、振り切ったやつを混ぜて。
振り返り「出し分けの軸」を3-4方向に区切るのが効く。 並べて読むと、自分が反応したのが「詩寄り」か「機能寄り」か分かる。それが今の自分の気分。
INKBIRD — TAGLINE DRAFT 10 / 10
  1. 書く人に、静けさを。
    詩余白の多さで、ブランドの世界観を示す。
  2. ことばが、またじぶんに追いつく。
    詩「追いつく」で書き手の内側を描く。
  3. 気が散らないことが、機能だ。
    機能引き算をベネフィットに反転。
  4. 下書きを、ひとりにしない。
    機能相棒機能をやわらかく示唆。
  5. 速く書くより、深く書こう。
    挑発「速さ偏重」の時代へのカウンター。
  6. SNSの逆を、ゆこう。
    挑発静かに書きたい層への旗印。
  7. 今日も、書けなかった。
    内省失敗から始める一行。共感を引く。
CASE C · NOVEL OPENING

短編小説の
冒頭を書く

場面「雨の駅で誰かを待っている女性」を起点に、短編の冒頭3段落を書きたい。視点・文体・空気感を細かく指定する。
あなたは静かな短編を書く小説家です。 # 場面 雨の夕方、私鉄の小さな駅前ロータリー。 30代後半の女性「美里」が、傘も持たず、誰かを待っている。 # 視点 三人称・美里の内面に寄った視点。 # 文体 - 一文短め、しかし詩的に - 比喩は1段落に1つまで - 漢字とひらがなのバランス重視 - 句点で止めて余韻 # お願い 冒頭の3段落だけ書いて。 状況説明より、空気の重さを先に伝えて。 タイトル候補も3つ添えて。タイトルだけは名詞ひとつ。
振り返り「比喩は1段落に1つまで」のような 禁則 を入れると、Claudeの文章は途端に締まる。 書き手は「足す」より「引く」を指示するほうが、文体が育つ。

OUTLINE

① 構成から始める

# テーマ
[何を書くか]

# 読者
[誰のため・前提知識]

# 目的
[読んだあとの行動・気持ち]

まず構成案だけ出して：

04

書く現場での得意・不得意

Claudeは万能の書き手ではない。とくに「書く」は人間の領分が大きい。だから付き合い方が肝心。

◯得意なこと

CLAUDE WRITES — 任せて速い領域
  • 叩き台の量産白紙からの最初の30分を、ほぼ消してくれる
  • 構成の組み替え「H2を5つから3つに」「順番を入れ替えて」が一瞬
  • 言い換え・別案出し「もう少しやさしく」「もっと硬く」が無限にやれる
  • 削る・短くする長文を3行・1行に圧縮するのが極めて得意
  • 翻訳とリライト直訳→意訳→自分の文体への3段階移植
  • 校正と整合チェックてにをは・敬語・固有名詞の表記揺れ
  • 役を変えての批評「厳しめ編集者」「初学者の読者」など、視点を借りられる

△苦手なこと（人がやる）

YOU WRITE — 譲ってはいけない領域
  • 原体験を語ること本当に自分が見た風景・触れた肌触り・痛みは、本人にしか書けない
  • 固有名詞と最新情報学習以降のことは知らない・人や店の細部は確認が必要
  • 「振り切り」の判断無難な平均点を出すのは得意。尖らせるのは人が決める
  • 本人の声色を最初から持つことお手本を渡してはじめて近づく。最初の数行は人が書く
  • 事実関係の最終責任もっともらしく嘘を書くことがある。固有名詞は必ず確認
  • 「書かないほうがいい」判断頼まれれば書く。書かないという編集判断は人の仕事
