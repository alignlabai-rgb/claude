動画AIKling 3.5 公開 — 1080p/60fps・ブラウザ完結型に進化

Kuaishouが「Kling 3.5」を正式公開。ネイティブ1080p・60fpsに対応し、高スペックローカル環境不要のブラウザ完結型へ移行。Sora撤退後の市場でKlingの週間アクティブユーザーは260万人規模に拡大。競合比でSoraより65%・Runwayより44%低コストを維持しつつ映像品質を向上させた。

出典：Bloomberg / rctv.com

Claude CodeClaude Code アップデート — project purge・Rewind要約・ゲートウェイ対応モデルピッカー

Claude Codeが広範なアップデートを実施。新コマンド claude project purge [path] でプロジェクトのClaude状態を一括削除可能に。Rewindメニューに「ここまで要約（Summarize up to here）」を追加し、古いコンテキストをインタラクティブに圧縮できる。モデルピッカーはゲートウェイの /v1/models エンドポイントを参照する形に改善。ANTHROPIC_WORKSPACE_ID 環境変数も追加された。

出典：Anthropic / releasebot.io / github.com/anthropics/claude-code

5月15日、OpenAIはChatGPTモバイルアプリからCodexを利用できる「Work with Codex from anywhere」機能を発表。MacのCodexアプリに接続することで、プロジェクト・ファイル・プラグイン・スキルをスマートフォンからフル活用できる。Windows対応のサンドボックス整備も進行中。

出典：OpenAI / developers.openai.com
