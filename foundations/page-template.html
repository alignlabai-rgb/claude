記事テンプレート：根拠と用途から書く

最新というラベルではなく、読者が選択・試験できる本文を作るための型です。

最終更新: 2026-10-13 / 入口の編集日と、個別記事の公式確認日は別です。

新しい解説の最小構成

目的 / 読者が決められること
製品・API・weights・提供段階を分けた現行事実
仕組みと選択肢 / 固有の具体例
失敗条件 / 合成fixture / 未実施か実測か
近傍の一次source / 確認日 / 未確認範囲
関連guide / 旧本文の固定版

この型は編集の補助です。すべての章を同じ一般論で埋めず、そのtopicにしかない失敗と比較を選びます。未確認値を空欄のまま残す方が、推測で埋めるより有益な場合があります。
