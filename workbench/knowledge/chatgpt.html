💡 reasoning effortが6段階に拡張: 最上位のmaxはxhighよりさらに高コスト・高精度で、OpenAIは「代表的なワークロードでxhighと比較してから採用すべき」と案内している（Sol・max実行で1タスクあたり最大$0.4855相当という試算も報告ベースで存在）。むやみにmaxを既定にするとコストが跳ね上がる点に注意。

Unified Architecture — GPT-5.5 の進化

GPT-5.4で実現した「Codex＋Reasoning統合」を GPT-5.5 がさらに拡張。音声・動画のネイティブ処理と NVIDIA GPU 最適化により、マルチモーダル・エージェント能力を一段引き上げた。

Self-Correction Loop

コードを書き → 自分で実行 → エラーログを読み → 修正して再実行。このサイクルをユーザー介入なしに高速で回す。SWE-bench ~80%はこの自律サイクルの賜物。

Computer Use (Desktop Automation)

OSWorld 75%が示す通り、GUI操作・フォーム入力・ブラウザ操作を人間専門家レベルで自律実行。単なるコード生成から「PCを使う作業者」としての能力を持つ。

🔗 2026-07-09 — ChatGPT と Codex がついに1つのデスクトップアプリに統合

2026年3月に予告されていた「ChatGPT・Atlas・Codexの単一アプリ統合」構想が、まずChatGPT × Codexの形で実現した。macOS / Windows 向け ChatGPT デスクトップアプリの中に、Chat（従来の対話）・Work（新設のエージェントモード）・Codex（開発者向け専用ビュー）という3つの動作モードが統合され、無料プランを含む全プラン・全世界で提供開始された。

ChatGPT Work とは何か

GPT-5.6を搭載した新モード。プレーンな日本語・英語の指示だけで、数時間にわたってプロジェクトに張り付き、レポート・スプレッドシート・簡易Webアプリなど「完成した成果物」をチャット応答ではなく成果物そのものとして返す。Scheduled Tasks（定期実行・トリガー駆動タスク）に対応し、たとえば「顧客フィードバックメールを毎朝要約してSlackに投稿する」といった継続運用を、都度の指示なしで自律実行できる。

実務向けプラグイン2本

Data Analytics プラグイン：Snowflake / Databricks / Hex / Tableau に接続し、ダッシュボードをアプリ内に直接表示。Creative Production プラグイン：Figma / Canva / Shutterstock / Picsart と連携し、広告・ビジュアル素材の制作を支援。「ChatGPTの中で業務システムに触れる」方向性がWorkspace Agents（4月）からさらに具体化した。

💡 Codexは消えない： 「統合」といっても Codex がChatGPTに吸収されて機能縮小したわけではない。開発者向けの専用ビューとして存続し、むしろインラインDiff編集・アプリ内でのGitHub PRレビュー（サイドパネルでレビュアーコメントとDiffを並べて確認）・マルチリポジトリ プロジェクトという、単体アプリ時代より踏み込んだ機能を獲得している。既存のCodexアプリユーザーは通常どおりアップデートすればプロジェクト・設定・ワークフローを保持したまま移行できる。

🧩 Codex 新機能まとめ — プラグイン・委任制御・トークン予算（2026年7月）

ChatGPTアプリ統合と同じタイミングで、Codex側の運用機能も一括アップデートされた。個別の追加日はOpenAI Codex Changelogでの確認を推奨（本ページでは7月上旬としてまとめて報告ベースで記載）。

🔌 プラグインブラウザ刷新
/plugins が「OpenAI Curated」「Workspace」「Shared with me」の3セクションに整理。会話の文脈に応じてプラグインを自動推奨・インストールできるようになった。プラグイン管理自体もSettings配下に集約。
🎛️ マルチエージェント委任制御
app-serverクライアント向けに、サブエージェントへのタスク委任をdisabled / explicit-request-only / proactive の3段階でスレッド・ターン単位に設定可能。委任の暴走を防ぎつつ、必要な場面では自律的な分業も許可できる。
📊 ロールアウト トークン予算
エージェントスレッド横断でトークン使用量を追跡し、残量が少なくなるとリマインドを表示、予算超過時はターンを自動中断。長時間の自律実行タスクでのコスト暴走を防ぐガードレール。
🔍 索引付きツール検索（MCP）
対応モデル・プロバイダではMCPツールの検索が既定で索引ベースに変更され、大量のMCPツールが登録された環境でもツール発見が高速化。旧モデル・旧プロバイダとの互換性は維持。
⏰ UTCスケジュールリマインダー
Codexがスケジュールされた時刻（UTC）にリマインダーを受け取り、現在時刻を直接クエリできるようになった。定期実行タスクや期限付き作業の管理に有効。
💳 使用量上限リセットクレジット
/usage コマンドで、貯まった使用量上限リセットクレジットの確認・引き換えが可能に（確認・リトライ・残クレジット表示つき）。6月導入の「rate-limit reset banking」（Plus/Pro向け、30日間有効）の使い勝手をさらに改善したもの。

☁️ Amazon Bedrock — GPT-5.6 Sol / Terra / Luna ネイティブ対応

Amazon BedrockにGPT-5.6 Sol / Terra / Lunaが追加され、新設された最上位のmax reasoning effortを含む全推論強度がファーストクラスでサポートされる。あわせて、Auth・Responses APIのトラフィックがmacOS / WindowsのシステムプロキシPAC / WPAD設定経由でルーティングできるようになり、企業のネットワークポリシー配下でもCodex / GPT-5.6が扱いやすくなった。

🏢 エンタープライズへの含意： GPT-5.4のBedrock対応（2026年前半）・Codex自体のBedrockビルトインサポート（5月）に続き、GPT-5.6系列もBedrock経由でAWS環境に閉じた形で利用できるようになった。HIPAA等の規制対応が必要な組織にとって、Dell PowerEdgeオンプレ展開（5月）と並ぶ「規制環境でのOpenAI採用ルート」の1つ。

Why use for Vibe Coding?

Vibe Codingにおいて、ChatGPT / GPT-5.5は「頼れる現場監督」です。

  • 実装スピード: フルマルチモーダル統合により、設計→コーディング→テストが1モデルで完結。思考の切れ目がなく、開発フローが滑らか。
  • 曖昧な指示への対応: Instruction Followingが高水準。「なんとなくいい感じに」を汲み取る自然言語理解は業界随一の評価を維持。
  • GUI自動化との統合: Computer Use能力により、コード生成だけでなく「実際のブラウザ・アプリ操作」も同一モデルが担う。
  • チームエージェント（Workspace Agents）: 2026年5月より、組織内でエージェントを共有し、長期・複雑なワークフローをチームで自動化可能。

Comparison

  • vs Gemini 3.1 Pro: Geminiはコンテキスト長・Googleエコシステム連携・ハルシネーション抑制で優位。GPT-5.5はOSWorld（デスクトップ自動化）・会話の自然さ・ChatGPT UIの洗練度で競合。価格は拮抗（$2.50 vs $2.00）。
  • vs Claude Opus 4.8: SWE-bench Verifiedでほぼ同スコア（両者~80%）。Claudeは長文分析・Effort Control・倫理的配慮で優れるが、GPT-5.5はGUI自動化とNVIDIAハードウェア最適化で差別化。SWE-Bench Proはクロード優位（64.3% vs 58.6%）。
  • vs Claude Mythos Preview: セキュリティ特化の非公開モデルとは比較の土俵が異なる。一般利用ではGPT-5.5が現実的な選択肢。
