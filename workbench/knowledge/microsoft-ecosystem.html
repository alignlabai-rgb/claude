01 全体像 — 5つの軸で整理する

Microsoft の AI 製品はざっくり次の5軸に分類すると迷いません。 「Foundation LLM」「Productivity（M365統合）」「Power Platform（ローコード）」「Developer Platform（Azure）」「Open Weights（Phi）」です。 OpenAI との深い連携が軸にあり、GPT-4o / o3 系が各サービスの基盤モデルとして機能しています（2026年5月現在）。

Foundation LLM

  • Azure OpenAI Service（GPT-4o / o3 / o4-mini）
  • MAI（自社モデル群）
  • モデルカタログ 1,900+

Productivity

  • Microsoft 365 Copilot
  • Word / Excel / PowerPoint / Teams / Outlook / OneNote / Loop
  • Agent Store（70+ 事前ビルド）

Power Platform

  • Copilot Studio
  • Power Automate AI
  • Power Apps Copilot
  • Power BI（Copilot）
  • AI Builder

Developer Platform

  • Azure AI Foundry
  • Semantic Kernel / AutoGen
  • GitHub Copilot
  • Windows Local AI

Open Weights

  • Phi-4 系（14B / 3.8B）
  • MIT ライセンス
  • ローカル・エッジ実行

⚠️ ブランド整理 (2026/03): Microsoft は Copilot 部門を Jacob Andreou EVP のもとに統合し、コンシューマー・商用 Copilot チームを一本化。以前は 80+ 製品が "Copilot" を名乗り混乱を招いていたが、現在は階層構造（コンシューマー Copilot → M365 Copilot → Copilot Studio → Azure AI Foundry）として整理されつつある。

02 製品別ガイド

核となる製品を、用途・確度バッジ・判断軸付きで個別に解説します。

Copilot（コンシューマー） CANON

microsoft.com/copilot から誰でも使える無料 AI アシスタント。 旧 Bing Chat を刷新したもの。テキスト生成・画像生成（DALL-E 3）・Web 検索グラウンディングを提供する「入口」製品。

  • 無料プラン：Web 検索統合・DALL-E 3 画像生成・1日あたり制限あり
  • Copilot Pro $20/月：GPT-4o 優先アクセス・M365 アプリへの Copilot 追加・Designer 強化
  • Edge ブラウザ・Windows 11 スタートメニューにも統合
  • Microsoft アカウントで Microsoft Graph（個人の OneDrive / Outlook）を参照可能

💡 使う場面：個人ユーザーが Web 検索連携で素早く調べる・文章を書く・画像を作る。エンタープライズ利用なら M365 Copilot へ移行。

Microsoft 365 Copilot CANON ENTERPRISE

Office アプリ全体に埋め込まれたエンタープライズ AI。 Microsoft Graph（メール・チャット・会議・ファイル）を参照しながら、Word / Excel / PowerPoint / Teams / Outlook / OneNote / Loop を横断して動く。

  • 価格：$30/ユーザー/月（年契約・M365 E3/E5 等ベースライセンス必須）。SMB 向け $18 → 2026/7月以降 $21。
  • Business Chat（BizChat）：自然言語でメール・会議録・ドキュメントを横断検索して回答。権限外データは参照しない（Entra ゲートで制御）
  • Agent Store：70+ 事前ビルドエージェント。カスタムエージェントは Copilot Studio で構築
  • Agent2Agent（A2A）プロトコル（2026/03〜）：複数エージェントが互いに連携して複合タスクを実行
  • Copilot Cowork（2026/03〜）：Anthropic Claude と共同開発。タスクをプランに変換しバックグラウンド実行
  • Word で長文要約・文体修正、Excel でデータ分析・グラフ生成、Teams 会議の議事録・アクション自動生成

💡 使う場面：M365 を既に使っている企業が、既存の業務フロー（メール・会議・文書作成）を AI で高速化したい場合の第一選択。

📖 詳細は m365-copilot.html — アプリ別機能・価格詳細・BizChat・エージェント連携・ROI 試算

Copilot Studio CANON

ノーコード〜ローコードのカスタムエージェントビルダー。 自社データ・業務フローに合わせたエージェントを Power Platform の UI で構築し、Teams・Web・WhatsApp・M365 に公開できる。

  • 価格：M365 Copilot ライセンス保有ユーザーの内部利用は追加クレジット不要。外部公開・大量利用は Copilot Credits（$200/月 = 25,000 credits）。PAYG は $0.01/credit（Azure 経由）
  • クレジット消費の目安：通常レスポンス 1 credit、生成AIレスポンス 2、エージェントアクション 5、Graph グラウンディング 10
  • Work IQ：インテリジェンスレイヤー。社内の業務知識・コンテキストに合わせてエージェントを調整
  • MCP（Model Context Protocol）対応で外部ツール連携
  • Copilot Studio → Azure AI Foundry への移行パスあり（複雑な要件・高度な安全設計が必要な場合）
  • Teams・WhatsApp・Azure Communication Services (SMS) に1クリック公開

💡 使う場面：IT 部門や業務担当者がプロコードを書かずに自社ナレッジベース連携のチャットボット・業務エージェントを作りたい場合。

📖 詳細は copilot-studio.html — ビルドステップ・クレジット設計・Foundry との使い分け

Power Platform AI CANON

Power Automate / Power Apps / Power BI / AI Builder の AI 統合ライン。 ローコード基盤全体に Copilot が組み込まれ、プログラミング不要で業務自動化・アプリ開発・BI 分析が行える。

  • Power Automate Copilot：自然言語でフローを記述するだけでワークフロー自動生成。Azure AI Foundry・MCP 接続でマルチエージェント連携。Workflows Agent・Human-in-the-loop 承認・インテリジェント文書処理（AI Builder 統合）
  • Power Apps Copilot：業務要件を自然言語で伝えるとアプリとデータモデルを自動生成。新開発体験 vibe.powerapps.com でバイブコーディング的に作成・反復
  • Power BI Copilot：レポートの自動要約・「先月と比べて売上はどう変化した？」と質問するだけで DAX クエリと可視化を生成
  • AI Builder：Document Processing Agent（構造化・非構造化文書からデータ抽出）・OCR・感情分析・カスタム予測モデル。Copilot Studio と 2025/9 以降統合
  • 2025 Release Wave 2 〜 2026/3：自律エージェント・MCP・AI ファーストな UX を全製品に順次展開

💡 使う場面：市民開発者（IT 非専門の業務担当者）が承認フロー・データ収集アプリ・レポートを自力で作りたい場合。ガバナンスは IT 部門が Power Platform 管理センターで制御。

📖 詳細は power-platform-ai.html — 製品ライン比較・AI Builder 料金・実例

Azure AI Foundry CANON PRO-CODE

エンタープライズ AI 開発の統合プラットフォーム（旧 Azure OpenAI + Azure ML 統合）。 モデルの選択・Fine-tuning・評価・デプロイ・モニタリングをワンプラットフォームで行う。Build 2025 以降「Microsoft Foundry」とも表記。

  • モデルカタログ 1,900+（Build 2025 時点）→ 11,000+ に拡大（2026年）：GPT-4o / o3 / o4-mini・Claude（Haiku 4.5 / Sonnet 4.5 / Opus 4.1）・Llama 4・Mistral Large・Phi-4・DeepSeek・Cohere 等
  • Azure OpenAI Service：GPT 系モデルを SLA 付きで本番提供。プロビジョニングスループット（専用容量）・バッチ API で大量処理
  • Semantic Kernel + AutoGen → Microsoft Agent Framework（GA 2025）：オープンソース SDK。A2A プロトコル・MCP 対応のマルチエージェントオーケストレーション
  • Foundry Agent Service（GA 2025/05〜）：エージェントの構築・デプロイ・ガバナンスを一元化。M365 への1クリック公開
  • Azure AI Content Safety / Responsible AI ツール：ハルシネーション検出・コンテンツフィルタ・コスト予算管理（Build 2026）
  • VPC Service Controls・Microsoft Entra Agent ID でエージェント単位のアクセス制御・監査
  • MAI モデル群（Build 2026 公開）: 自社開発7モデルを Microsoft Foundry で展開（下記 MAI セクション参照）

💡 使う場面：最大のモデル選択肢・SLA・コンプライアンス要件でエンタープライズアプリケーションを構築したい開発チーム。Copilot Studio では要件を満たせない複雑なロジックが必要な場合。

📖 詳細は azure-ai-foundry.html — Foundry vs Azure ML・モデルカタログ・Semantic Kernel・Agent Service コード例

GitHub Copilot CANON

コーディングエージェントに進化した AI ペアプログラマー。 単なる補完ツールから、GitHub Issue を受け取って自律的に PR を作成する「AI チームメンバー」へ。2026年にコード生成の 46% を占める。

  • 価格（2026/04 時点）：Free $0 / Pro $10/月 / Pro+ $39/月 / Business $19/ユーザー/月 / Enterprise $39/ユーザー/月。2026/06/01 から usage-based billing に移行（ベース価格は変わらず、プレミアムモデル利用はトークン消費ベースに）
  • Agent Mode（VS Code / JetBrains GA 2026/03〜）：コードベース全体を把握してタスクを自律実行。割り込み不要。
  • Coding Agent（非同期）：GitHub Issue を割り当てると Cloud VM で独立実装 → PR 自動作成 → CI 失敗なら自動修正。まさに「任せて待つ」設計
  • Agentic Code Review（2026/03〜）：プロジェクト全コンテキストを参照してレビュー→修正 PR も自動生成
  • GitHub Spark：自然言語でアプリを記述してライブプレビュー付きで即作成
  • Semantic Code Search：キーワードではなく概念で関連コードを検索
  • VS Code・JetBrains・Neovim・GitHub.com・CLI から利用可能

💡 使う場面：ソフトウェア開発チームの生産性向上。補完・レビュー・非同期コーディングエージェントを用途に合わせて組み合わせる。

📖 詳細は github-copilot.html — Agent Mode 詳細・Coding Agent フロー・料金比較・vs Cursor / Codex

Phi-4 OPEN CANON

Microsoft のオープンウェイト SLM（小型言語モデル）ファミリー。 MIT ライセンスで商用利用・Fine-tuning・蒸留が無制限。「小さくても賢い」をコンセプトに、671B の DeepSeek-R1 を AIME 2025 で上回るスコアを 14B で実現。

  • Phi-4-reasoning（14B）：推論特化。chain-of-thought 学習 + RL で訓練。32K コンテキスト（最大 64K で安定）。AIME 2025 でフル DeepSeek-R1（671B）超え
  • Phi-4-reasoning-plus（14B）：SFT + RL のハイブリッド。さらに高精度。OpenAI o1-mini・DeepSeek-R1-Distill-Llama-70B を超過
  • Phi-4-mini-reasoning（3.8B）：エッジ・モバイル向け。数学教育に特化（中学〜博士レベル 100万問以上で訓練）
  • Phi-4-reasoning-vision（最新）：マルチモーダル推論モデル。グラフ・図表・数式を画像として理解
  • Azure AI Foundry・HuggingFace から取得。Ollama でローカル実行可能
  • Fine-tuning・蒸留に制限なし（MIT）。オンプレ・エッジデバイス・プライベートクラウドに最適

💡 使う場面：データを外に出せない・低レイテンシ必須・API コストを抑えたい・カスタム Fine-tuning が必要な場合。数学・論理推論タスクはコスト対効果が特に高い。

📖 詳細は phi.html — モデル比較・Ollama セットアップ・Fine-tuning ガイド・Gemma 4 / Llama 4 との性能比較

Windows Local AI Build 2026

端末上でオンデバイス推論を実行する API / ランタイム群。 Build 2026 で発表されたロードマップ。NPU（Neural Processing Unit）搭載の Copilot+ PC で、レイテンシゼロ・プライバシー完全分離の AI を実現する。

  • Windows AI API：アプリから NPU / GPU を統一 API で呼び出し。Phi-4-mini など SLM をローカル実行
  • Windows Copilot Runtime：OS レベルで Phi-4 系モデルを管理。アップデートは Windows Update 経由
  • Copilot+ PC（Snapdragon X / Intel Core Ultra / AMD Ryzen AI 搭載）が前提ハードウェア
  • ユースケース：オフライン翻訳・プライバシー優先の文書要約・低レイテンシ音声処理（MAI-Transcribe-1）

💡 使う場面：Copilot+ PC 向けアプリを開発したいエンジニア、またはオフライン・プライバシー優先の AI 処理が必要なエンタープライズ展開。

✅ Build 2026（6/2〜3）完了。Windows AI API・Phi-4-mini オンデバイス実行の詳細はカンファレンス資料（news.microsoft.com/build-2026）を参照。

04 クリエイター・ビジネス視点 — どう組み合わせるか

Microsoft AI の最大の強みは、「エンタープライズの既存インフラ（M365・Azure・GitHub）と AI を継ぎ目なく接続できること」にあります。 Google の強みがモデル最先端とマルチモーダル表現にあるとすれば、Microsoft の強みは 組織の権限・セキュリティ・ガバナンスを維持したまま AI を業務フローに組み込める深度です。

業務生産性（非エンジニア）

  • 日常業務 → M365 Copilot
  • 自動化 → Power Automate Copilot
  • アプリ → Power Apps Copilot
  • 分析 → Power BI Copilot
  • 文書処理 → AI Builder

IT 部門・内製開発

  • 社内エージェント → Copilot Studio
  • 本番 API → Azure AI Foundry
  • マルチエージェント → Semantic Kernel / AutoGen
  • ガバナンス → Entra Agent ID

ソフトウェア開発チーム

  • 日常コーディング → GitHub Copilot Pro
  • 非同期タスク → Coding Agent
  • チームスケール → Copilot Enterprise
  • プライベート推論 → Phi-4

クリエイター（個人・スモールチーム）

  • 文章・素材 → Copilot Pro（DALL-E 3 統合）
  • アプリ試作 → GitHub Spark
  • ローカル実験 → Phi-4-mini
  • 動画は → Google Veo / Flow（現時点で MS 優位製品なし）

💡 「組み合わせの鉄則」：M365 を基盤として 使う側（非エンジニア）は M365 Copilot + Power Platform、 作る側（開発チーム）は GitHub Copilot + Azure AI Foundry、 プライバシー・コスト最優先はローカル Phi-4、 全体ガバナンスは Entra Agent ID + Agent 365 と役割で割り当てると、 増え続ける製品群でも判断が安定します。

⚠️ Google との差別化でよく誤解されること： 動画生成（Veo 系）・高品質マルチモーダル画像（Imagen 4）・音楽生成（Lyria）の領域では現時点で Microsoft に同等製品はありません。 コンテンツ制作パイプラインに動画・音楽生成が必要なら Google AI も併用を検討してください。 Microsoft の優位はエンタープライズの既存資産と AI を接続する深度にあります。

05 Microsoft AI の強み — Google との差別化

2026年5月現在、Microsoft vs Google の AI 戦争における各社の優位点を整理します。 モデル性能の競争は拮抗しており、真の差別化はエコシステム統合の深さと展開速度にあります。

  • テナント境界のセキュリティ：M365 Copilot のエージェントは Entra（Azure AD）の権限を自動継承。SharePoint ドキュメントや Exchange メールのアクセス権限がそのまま Copilot の参照範囲を規定する。IT 管理者が追加設定不要で情報漏洩を防止できる。
  • 開発者エコシステム：GitHub Copilot は開発者の 62% が利用（Google IDX は 15%）。Visual Studio・VS Code・JetBrains の圧倒的シェアに統合済み。コードの 46% が Copilot で生成される水準。
  • エンタープライズ採用実績：Fortune 500 企業の 85% が Azure を利用。M365 は世界 4 億人超のビジネスユーザー。AI 導入の「最後の1マイル」（変更管理・IT ポリシー適合）で既存関係が効く。

Anthropic・OpenAI・Meta に依存せず、Microsoft 自社開発のモデル群が Microsoft Foundry で展開開始。ゼロから自社データで学習した enterprise-grade モデル群。

MAI-Thinking-1 Private Preview

35B active パラメータ・MoE・256K コンテキスト。複雑な多段階指示・長文推論・コード生成に特化。エンタープライズグレードのクリーンデータでゼロ蒸留学習。

  • Microsoft Foundry でプライベートプレビュー（アクセスリクエスト受付中）

MAI-Image-2.5 / MAI-Image-2.5-Flash

  • 既存画像の編集・スタイル変換も対応
  • Microsoft Foundry で利用可能
