🔴 Claude / Anthropic

更新Claude Code v2.1.214公開 — 権限バイパス修正とEndConversationツール追加

Anthropicは7月18日にClaude Code v2.1.214をリリースした。Windows PowerShell 5.1での権限チェック回避、`dir/**`許可ルールがcwd外にも書き込みを誤って許可してしまう不具合など、権限・セキュリティ関連で40件超の修正を実施。悪意あるユーザーやジェイルブレイク試行に対しClaude自身がセッションを終了できる新ツール「EndConversation」も追加された。長時間実行ツール呼び出しの進捗ハートビートやOTELログ項目の追加も行われている。

Source: GitHub anthropics/claude-code Releases

課金変更Claude Fable 5、7月20日からクレジット制課金へ移行

Anthropicが6月に実施したClaude Fable 5の無償・割引提供期間は7月19日23:59（PT）で終了し、7月20日からProおよびTeam StandardプランでのFable 5利用はプリペイド式の利用クレジット制（入力$10/百万トークン、出力$50/百万トークン）に移行した。MaxおよびTeam Premiumプランは引き続き通常利用枠の50%相当でバンドル提供される。

Source: Anthropic Newsroom, Forbes, Help Net Security

🟠 GPT / OpenAI / Codex

刷新ChatGPTデスクトップアプリが大型刷新 — 統合レイアウト、Atlasは8月9日に終了

OpenAIはmacOS/Windows向けChatGPTデスクトップアプリに、Chat/Workを統合したレイアウトやWeb・モバイル・デスクトップ間で同期する「Work」会話、アプリ内Projectsなどを全プランに展開した。Enterprise/Business/Education向けにはカスタム指示の文字数上限を1,500から5,000へ拡大。一方でブラウザエージェント「Atlas」は8月9日に提供終了し、機能はChatGPT/Codexのエージェント型ブラウジングへ統合される。

Source: OpenAI Help Center Release Notes

🟠 Grok / xAI

新機能xAI、画像・動画生成機能「Grok Imagine」の完成を発表

イーロン・マスク氏は7月上旬、画像・動画生成機能「Grok Imagine」の完成をXで発表し、続報でプレビュー動画や自律的な画像・動画生成へのGrok統合を明らかにした。コーディングツール「Grok Build」でも同モデルを用いた高品質な画像編集が可能になっている。

Source: Basenor, CryptoBriefing

🟡 音楽生成AI

提携Udio、BuyDRMとDRM提携 — ダウンロード再開に向け体制強化

音楽生成AIのUdioは7月17日、BuyDRM（OVHcloud）のKeyOS MultiKey DRMシステムとの提携を発表した。UMGとの和解後にダウンロード・ステム機能を無効化していたが、正規ライセンス済みのダウンロード対応プラットフォームとして2026年内の再展開を目指す。

Source: Digital Music News
