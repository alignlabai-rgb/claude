🔴 最優先GLOBAL

Amazon AWS — Nova family

現行トラッカーの最大の盲点。OpenAI / Anthropic / Gemini を呼び出す際も Bedrock 経由を選ぶ組織は多く、Nova Pro / Nova Premier が GPT-5.6 / Claude Sonnet 5 と横並びで検討される場面でトラッカーにない。

現行モデルNova Premier / Nova Pro / Nova Lite / Nova Micro（+ Nova Canvas / Reel） Nova Premier最上位マルチモーダル。200K context。text + image + video + doc 入力。コードエディタ統合。 Nova Proバランスモデル。300K context。マルチモーダル。エンタープライズ向け recommended。 Nova Lite / Micro低レイテンシ・高スループット。Lite は multimodal、Micro は text のみ。 API / SurfaceAmazon Bedrock（us.amazon.nova-pro-v1:0 等）。Converse API / InvokeModel API。 架け橋Bedrock に Claude / GPT-5.6 / Llama も存在するため、Nova は「Bedrock 上の Amazon 純正モデル」として別管理が必要。 Open weightsなし（closed） 価格感Nova Pro: 約 \$0.8/M input・\$3.2/M output（Sonnet 5 の約 1/4 コスト）

Source: Amazon Nova docs / Bedrock model catalog

🔴 最優先CHINA

Shanghai AI Lab — InternLM / InternVL

中国 open-source では Qwen・DeepSeek・GLM がトラッカーに入っているが、InternLM がない状態はオープンウェイト選定の網羅性が不完全。SWE-Bench では GLM と同クラスの成績。InternVL はマルチモーダル open-source の事実上の最上位。

LLM flagshipInternLM 3.5（8B / 70B / 141B-A35B MoE）。推論・数学・コードに強化。Apache 2.0。 マルチモーダルInternVL 3（2B〜78B）。画像・動画理解でオープンウェイト最上位クラス。MathVista / ChartQA 等で首位争い。 コードInternLM-Coder は SWE-Bench Verified で 65%+（2026 前半）。 ContextInternLM 3.5-141B: 最大 1M context。通常は 128K〜256K。 LicenseApache 2.0（LLM 系） / InternVL は MIT 系。商用可。 API公式 hosted API なし。HuggingFace / ModelScope からの self-host または推論 providers 経由（Together AI、Fireworks 等）。 OrgShanghai AI Laboratory（上海人工知能実験室）。中国政府系研究機関と民間の中間的な立場。

Source: InternLM GitHub / InternVL GitHub / HuggingFace

🔴 最優先CHINA

iFlytek / 科大訊飛 — Spark（星火）

月次アクティブユーザー数・教育/医療/行政での展開規模は Baidu に次ぐ中国第2位クラス。現在のトラッカーに「中国コンシューマー AI 第2位」が存在しないのは地図の穴。ただし API 公開範囲が限定的で、日本語対応も弱いため「使う」動機は低め。

現行モデルSpark 4.0 Ultra（Xinghuo 4.0）。text / image / audio multimodal。 specialty音声認識（iFlytek ASR は中国 No.1）・教育 AI（学習型 tablet）・医療 AI（診断支援）。LLM 単体より「AIとハードウェアの垂直統合」が本体。 Benchmark中国の CEVAL / GAOKAO ベンチマークで上位（中国語特化）。英語ベンチでは中堅。 API 公開iFlytek Open Platform 経由。中国本土向け中心。国際 API は限定的。 Open weightsなし（proprietary） 日本語公式対応表記なし。中国語・英語が主。

Source: iFlytek Xinghuo / iFlytek EN

🟡 検討GLOBAL

AI21 Labs — Jamba

現行Jamba 2.5（旧 Jamba 1.6-Large / Mini） アーキMamba SSM + Transformer MoE hybrid。理論的に長文での KV-cache コストが低い。 Context256K（推奨）〜 最大 1M APIAI21 Studio API / Amazon Bedrock / Azure AI Foundry で利用可 Open weightsJamba 1.5 Mini は Apache 2.0 公開済み。Jamba 2.5 は商用 API 優先。 競合ポジション「大量文書を安く処理したい」時に GPT-4o / Claude Sonnet の代替候補として検討される。

Source: AI21 Jamba docs / AI21 Studio

トラッカー収録の判断基準

以下のいずれかを満たすものを収録候補とする（現行トラッカーの暗黙的な基準を明文化）。

① API から実際に呼び出せる

公式 API が存在し、一般開発者・企業が契約できる状態。on-device 専用・エンタープライズ限定のみは対象外。

② Open weights で self-host できる

HuggingFace / GitHub で weights が公開され、ライセンス上使用可能。「近日公開予定」は対象外。

③ 他プロバイダーと比較対象になる

性能・コスト・言語・用途の面で既存候補と横並びで検討される実績がある。SNS 速報だけでなく公式 benchmark または事例が存在。

この基準で言えば：Amazon Nova・InternLM・Jamba は①③を満たし収録推奨。Falcon・Nemotron は②③。iFlytek Spark・HyperCLOVA X は③のみで②①が弱い（検討）。Apple・Samsung・Pangu は③のみで①②なし（把握で十分）。
