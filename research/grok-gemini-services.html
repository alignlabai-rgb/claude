NEW 8月 Grok Bot — 自律 AI エージェント（常時稼働）

これが「Grok Bot」の実態。チャットボットではなく、クラウド VM 上でユーザーがオフラインの間も24時間自律実行するエージェント。SuperGrok ($30/月〜) に含まれる。
アクセスSuperGrok ($30/月〜) に含まれる。X アカウント連携で X API クレジットも付与。 稼働クラウド VM 上で24時間/7日、ユーザーがオフラインでも継続実行 できることWeb ブラウズ・ファイル操作・ターミナル実行・サードパーティツール連携・メール管理

📬 受信トレイ管理エージェント

メールを24時間監視 → 優先度でトリアージ → 返信案を生成して承認待ち → 毎日 Slack にダイジェスト投稿。人間が作業しない時間も動き続ける。

実例：スタートアップ創業者がサポートメール対応用 Grok Bot を設定 → Bot が緊急度を判定して草稿を作成 → 創業者は承認するだけ。

📊 マーケット監視エージェント

特定キーワード・競合企業・X 投稿を24時間監視 → センチメント変化を検知 → アラートと日次レポートを自動生成・配信。

実例：PR 担当者の Grok Bot が自社ブランドへの X 言及を毎時スキャン → ネガティブ投稿を検知したら即座にアラート送信。

🤝 会議代理エージェント

ユーザーが参加できない会議に代わりに参加（リスニング） → 議事録・アクションアイテム・決定事項をまとめて報告。

🛠️ X API 連携

X アカウントと連携した Grok Bot は X API クレジットを取得し、投稿検索・タイムライン読み取り・ブックマーク管理を自動化できる。

5月・7月 Grok Build / Workflows — コーディング・マルチエージェント

URLgrok.com/build / ターミナル: npm install -g grok-build IDE 統合Warp / Kilo Code / OpenCode / OpenClaw（Antigravity） Workflows 追加2026年7月23日
Workflows の核心：並列エージェントスワーム。標準予算 128 エージェント、最大 1,024 エージェント を並列稼働させ、大規模タスクを分散実行する。

⚙️ Workflows の仕組み

多フェーズのタスク分解 → 各フェーズを並列エージェントが独立実行 → 「懐疑論者（skeptic）」エージェントが成果物を相互検証 → 結果を統合して最終成果物を生成。.grok/workflows/ にスラッシュコマンドとして保存・チーム共有可能。

🔍 セキュリティ監査の実例

50万行のコードベース全体を対象に128エージェントが並列でセキュリティ脆弱性を検索 → 懐疑論者エージェントが検出結果をクロスチェック → 修正提案付きの最終レポートを自動生成。

一時停止/再開長期タスクの状態保存・再開に対応 Agent Dashboard複数の並行セッションを一画面で管理 アクセスSuperGrok ($30/月〜) / xAI API

X 統合 Grok on X — プラットフォームネイティブ

アクセスX Premium ($8/月〜) / 一部機能は無料ユーザーも制限付き利用可 特徴X のリアルタイムデータストリームにネイティブアクセス（知識カットオフなし）

📊 Trending Grok・Grok Stories

トレンドトピックの AI リアルタイム要約カードを検索上部に表示。毎日 AI 生成ニュースダイジェストを Stories 形式で配信。

実例：地震速報が X で拡散 → 検索上部に Grok Summary カードが自動表示。発生時刻・震源・目撃情報をリアルタイム合成。

🤖 @GrokAI メンション / カスタムタイムライン

投稿に @GrokAI をメンション → Grok が公開リプライを自動投稿。ユーザーは最大75個の Grok 管理トピックフィードを作成可能。For You フィードは Grok LLM スコアリング全面移行済み。

実例：「この論文 @GrokAI 要約して」→ Grok が要約・主要発見・限界点を公開リプライで返信。フォロワー全員が閲覧可能。

8/31 新規 Grok for Government — 米国防総省 GenAI.mil

展開日2026年8月31日 対象米国連邦政府・DoD 職員のみ（約170万〜300万人）。一般商業利用不可。 インフラStarshield（SpaceX の国防向けセキュリティ基盤） 認定Impact Level 5 (IL5) — 管理対象非機密情報（CUI）最高ティア認定 競合GenAI.mil 上で Google Gemini・ChatGPT Mil と並列提供（マルチベンダー方針）

📋 Playbooks（ワークフロースクリプト）

軍・政府業務向けの保存済みワークフロー。調達書類ドラフト・日次報告書・状況評価など繰り返しタスクをテンプレート化してチーム共有。

📁 Persistent Projects

作戦・ミッション単位の AI セッションを永続保持。前回の分析結果・意思決定の経緯を参照しながら継続的な AI 支援が可能。推論モード: Auto / Fast / Expert から選択。

公式 DoD 発表より：調達担当者が「Expert」推論モードで市場調査データを分析 → Playbook として保存 → 次回の調達でチーム全員が同じワークフローを再利用。

📱 Guided Vision（9月 Android Feature Drop）

カメラを向けると Gemini Live が周囲を口頭で説明。細かい文字の読み上げ・メニュー案内・物体の位置確認など。視覚障がい者向けアクセシビリティ機能として設計。カメラの向きが合っていなければ「少し左に向けて」と音声ガイド。

実例：食料品店でスマートフォンを缶詰に向ける → Gemini Live が栄養表示を口頭で読み上げ、アレルゲン情報を確認。スーパーの棚を移動しながらリアルタイムで会話継続。

🌍 リアルタイム翻訳 / 画面共有

外国語を検出してリアルタイム翻訳・字幕表示。デスクトップ画面共有でアプリやドキュメントを見ながら音声会話が可能。フローティング pill UI で他のアプリと同時使用。

実例：デザイナーが Figma 画面を共有 → 「このレイアウトの UX 的な問題点は？」→ Gemini が画面をリアルタイム分析して口頭でフィードバック。コピペ不要。
