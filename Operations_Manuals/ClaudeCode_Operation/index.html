実行面を選び、場所を確認する

Claude CodeはCLIや開発環境などの入口を持つ製品です。Messages APIへ一度依頼することと、Codeでファイルやコマンドを扱うことは別です。Coworkも別の製品面なので、名称がClaudeというだけで同じ操作や接続条件を使いません。公式Overview。

CLIでは対象のプロジェクトへ移りclaudeを起動する入口があります。導入済みの環境で、まず現在のディレクトリと既存の変更を確認します。インストールやログインを、本稿の教材に必要な作業として実行することはありません。使う版と実際に選べるモデルは開始時点に確認し、古い表から決め打ちしません。

指示・設定・権限を区別する

CLAUDE.mdへはプロジェクトの継続的な指示を置けますが、長い資料すべてを詰める必要はありません。目的、範囲、テスト、禁止する作用を短くし、必要な出典へ参照させる構成を考えます。保存してある資料が現在読まれたかは別に確認します。公式Memory。

permissionは操作の許可を扱い、設定は適用範囲と優先順位を持ちます。モデルへの禁止文だけで外部アクセスや書込を強制的に隔離できるとは扱いません。読み取り、編集、コマンド、接続先を必要な範囲へ限定し、実効条件を確認します。権限・設定。

コマンド一覧ではなく一件の依頼を作る

未実行の依頼例は『合成仕様Aと説明Bを照合し、Bの空データの説明だけを直す。コードや依存関係は変えない。差分と根拠位置、未確認を返す』です。対象、入力、変更可能な範囲、完了条件が揃っています。『全部よくする』という依頼から範囲を推測して広げないようにします。

CLIオプションは更新されるため、使う機能の正式な参照を確認します。古いthinking budgetやtool形式を現在のモデルにそのまま当てはめないことも重要です。非対話実行は対話CLIと承認の扱いが違うため、対話で一件が成功しただけで自動化へ進みません。CLI参照・非対話実行。

小さな実行と証拠

資料を読む、矛盾を見つける、許された変更をする、結果を検証する順序を使います。コードなら対象テスト、記事なら出典とリンク、表なら単位と計算を観測します。何を実行したかを返し、実行できなかった検査は未確認とします。公式Best practices。

合成教材には、仕様が欠けている入力、似た名前の別資料、途中で変わった対象版を加えます。誤った推測で穴を埋めるより、必要な条件を狭く返す方が合格です。変更が想定より広がったら止め、依頼の受入条件と差分が対応しているかを点検します。

MCPとSkillを追加する前に

MCPは資料やツールへの接続、Skillは方法や参照の再利用です。便利な名前を増やす前に、一件の仕事に何が不足しているかを確認します。接続は読み取りから試し、返る資料の種類、欠損、権限不足を区別できるかを評価します。MCP・Skills。

Agent teamsは実験的な機能で既定は無効です。Routineもresearch previewです。CLIの/scheduleはv2.1.225以降でcloud routineを作成する入口です。一覧・更新・即時実行などの/schedule管理はv2.1.227以降が必要です。/loopとcron toolsはsession内の定期実行、Desktop scheduled taskは端末側の実行です。同じCLIに入口があっても、実行先と寿命は異なります。並列や定期化は独立した採用対象として、重複、統合、停止を評価します。Teams・Routines・Session scheduling。

停止・再開・復元

想定外の変更や入力の不足を見つけたら、対象セッションの作業を中断し、残ったコマンドや子作業を確認します。再開には最後に確定した入力と成果、未完了の工程、次の一手を短く渡します。会話の要約だけで、実ファイルが以前の状態と同じになったとは仮定しません。

checkpointは追跡する変更の復元機構ですが、Bashや外部システムまで全てを戻すバックアップではありません。Gitの変更、ユーザーの既存差分、外部の副作用を別々に確認します。公式Checkpointing。全体の強制復元を標準手順にせず、正確な対象と復旧方法を決めます。

終了時の五つの記録

対象版、変更差分、検査結果、未確認、次のGit区切りを記します。ファイルを保存した、commitした、pushした、mainへmergeした、Web公開したという状態を別に報告します。Codeが作業を終えたことから、どれかが自動的に成立したとは判断しません。

操作を方法化するなら、同じ合成反例で次回も試せる短い手順を残します。モデル名や作業時間だけより、不足時にどう止まったかが役立ちます。実環境の機能、契約、実行結果は本稿で確認していないため、導入時はその時点の公式資料と有効な設定へ照合してください。
