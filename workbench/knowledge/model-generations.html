現行モデル世代 SSOT — ベンダー別フラッグシップの確認表

このページは公式に現行世代を確認できたproviderの詳細表です。21 providerの網羅状況、専用tracker、鮮度gapは先にLLM Coverage Ledgerを見てください。各深掘りページ・トラッカー・パイプライン記事の世代表記はこの確認表へ合わせ、新世代が出たらここを先に更新します。

最終更新: 2026-08-26 ／ provider公式のmodel catalog・release notesで再確認

このページの使い方

  • 参照する側: providerの有無・未確認gapはCoverage Ledger、ここに掲載したproviderの現行世代は本表を見る。矛盾する表記はバグ扱いで直す。
  • 更新する側: 新世代リリース・延期・繰り下げを観測したら、このページを先に直す。出典 URL を確認し、確証のある日付・数値だけを書く。
  • 個別ベンダーの詳細・実装メモは各深掘りページ、横断比較は intelligence-matrix、週次の動きは各 *-recent-updates トラッカーを参照。
この表は公開ハブ内の参照用SSOTです。噂・予定段階のものは「未確認／延期」と明示し、公式現行層へ昇格させません。組織canonやprovider採用判断ではありません。

やってはいけない表記（ドリフト防止）

以下は事実誤認です。各ページでこの書き方を見つけたら直してください。

  • ❌ 「Gemini 3.6 Flashが現行Flash最上位」 — Gemini 3.7 Flashが8/13にGA済み。
  • ❌ 「GPT-5.6は未リリース」 — 現行family。Codexの8/31退役はChatGPT sign-in surfaceに限る。
  • ❌ 「Opus 4.8が現行advanced flagship」 — 7/24にOpus 5が公開済み。
  • ❌ 「Fable 5が現行highest capability」 — 今回確認したAnthropic公式current docsでは裏づけられない。速報履歴からSSOTへ昇格させない。
  • ❌ 「Claude Code Auto Modeが8/14から既定」 — 現行公式FAQは組織有効化 + user opt-in。
  • ❌ 「Qwen3.8全体が一律Apache 2.0」 — repository codeとweightsのlicenseは別。各model cardで確認する。
  • ❌ 「GLM-5.2 がhosted現行最上位」 — hosted currentは GLM-5.3。5.2はopen-weight / local servingの確認済み層。
  • ❌ 「DeepSeek V4 GA」 — 公式API aliasが提供中であることとGA表記を混同しない。
  • ❌ 「Hailuo 2.3がMiniMaxの最新映像モデル」 — 7/31公開のH3を別generation surfaceとして併記する。
  • ❌ 確証のない日付・ベンチ数値の記載 — providerの公式model card・release noteで条件まで確認できる値だけを書く。
最重要: model名だけで「現行」を決めない。stable / preview、chat / API / coding agent / local weights、認証surfaceを必ず分ける。
