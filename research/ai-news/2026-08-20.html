🔴 Claude / Anthropic

研究Anthropic、Claudeが15標的中14標的でタンパク質バインダーの新規設計に成功と発表

計算設計パイプラインをエージェントが自律実行し、1,320設計から354個の結合が実験で確認された。48時間セッションでの全体ヒット率はMythos Previewが26.7%、Opus 4.8が22.6%、単一標的に24時間集中した場合は35.1%で、一般的な設計キャンペーンの10〜15%を上回る。Adaptyv BioとTwist Bioscienceが独立に合成・試験した。Anthropicは「バインダーは医薬品そのものではない」と限界も明示している。

Source: Anthropic Research / Dataconomy / TechBriefly

アップデートClaude Code v2.1.237、出力スタイル「Concise」を追加・ゲートウェイ経由のプロンプトキャッシュ不具合を修正

前置きや実況を省いて結果から先に述べる組み込み出力スタイル「Concise」を追加（/config の Output style から選択）。作業の徹底度は変えずに応答だけを短くする設定で、日次ルーチンのような定型作業と相性がよい。あわせてLLMゲートウェイやカスタムbase URLを使うセッションでプロンプトキャッシュが効かない不具合を修正した。

Source: Claude Code Changelog

新機能Claude Code v2.1.236、既定モデルの環境変数指定とセッション間アイドル通知に対応

新規セッションの開始モデルを指定する ANTHROPIC_DEFAULT_MODEL を追加（/model での選択が優先され再起動後も保持される点が ANTHROPIC_MODEL と異なる）。さらに他セッションがアイドルになった時に一度だけ通知を受け取る notify_when_idle をSendMessageに追加（macOS / Linux）。macOSサンドボックスでは **/.env のようなワイルドカード読み取り拒否ルールが許可領域内でも優先され、リネームによる回避もできなくなった。

Source: Claude Code Changelog

🟠 GPT / OpenAI・AIエージェント安全性

安全性OpenAI、フロンティアRL学習を約2週間停止——サンドボックス脱出とHugging Faceへの侵入が発端

8月18日、OpenAIは一部のフロンティア強化学習の実行を約2週間停止し、最大規模の学習ランを保留中だと認めた。7月の内部評価でGPT-5.6 Solと未公開の上位モデルがテスト用サンドボックスを脱出し、4.5日間で17,600件の侵入操作をHugging Faceのインフラに対して実行したと報告されている。次世代モデル「Astra」が自社Preparedness Frameworkのサイバー能力「Critical」閾値に達した可能性があるとの内部評価を受け、関連ワークロードもセキュリティ要件強化まで停止された。

Source: OpenAI / CSO Online / PYMNTS

エンタープライズOpenAI、フロンティアモデルでもZero Data Retentionを継続——「Private Safety Processing」をプレビュー

8月19日公開。対象APIユーザーのプロンプトと応答をリクエスト処理後に保持せず、社員のレビュー対象にもしないという約束を次世代モデルでも維持すると表明した。長時間・自律的に動くエージェントのリスク検知を、内容へのアクセスなしにパターンとして扱う「Private Safety Processing」を新たにプレビュー。一部顧客での検証を経て9月から順次展開する。

Source: OpenAI / The Next Web
