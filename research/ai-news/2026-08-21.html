🔴 Claude / Anthropic

アップデートClaude Code v2.1.238、キーバインド設定と自己ホスト型ランナーの機能を拡張

Ctrl+Wの挙動をreadlineモード風に変更できる keybindingFlavor 設定を追加。自己ホスト型ランナーには猶予付きシャットダウン（--defer-shutdown-max-min）とプロキシ認証コマンド指定を追加した。長時間セッションでサブエージェントのツール結果がメモリに溜まり続ける不具合を修正し、Remote Controlの接続耐性・モデル/エフォート変更の同期も改善した。

Source: Claude Code Changelog

APIClaude APIに「ブラウザ操作ツール」を新規公開、コンピュータ操作ツールも正式版に

8月19日、アプリ全体ではなくブラウザのビューポート内でアクセシビリティツリー・要素参照・フォーム入力・タブ管理を扱う「browser use tool」を新規公開。既存の「computer use tool」も同日ベータを終え、複数操作を1ターンでまとめる バッチ実行や既定ズームに対応した。Fable 5 / Mythos 5 / Opus 5 / Sonnet 5 / Opus 4.8で利用可能。

Source: Claude Platform Release Notes

新サービスAnthropic、社内研修をベースにした無料学習ハブ「Claude Academy」を開設

8月20日公開。Anthropicが新入社員研修で使う「4D AIフルーエンシー・フレームワーク」（委任・記述・見極め・注意）をそのまま一般公開の教材化。Skilljar上でClaude 101・Claude Codeの実践・Claude API構築・MCP入門など19以上の自習コースを無料提供する。

Source: Claude Blog / Anthropic

SDKAnthropic Python SDK v1.0公開、httpxからhttpx2への移行など破壊的変更あり

8月20日公開。HTTP層が保守継続中のフォーク「httpx2」に切り替わり、Python 3.10以上が必須に。レガシーText Completions APIやMessagesのtemperature/top_p/top_kなど旧仕様を削除。AnthropicBedrockはAWSリージョン未設定時にエラーを返すよう変更された。移行ガイドが公開されている。

Source: Claude Platform Release Notes

新機能ChatGPT、Apple SiliconのMacでiMessage/SMS/RCSの読み書き・送信に対応

8月20日公開。ChatGPTデスクトップアプリのプラグインとして、メッセージの検索・要約・下書き作成・送信までを許可制で代行できるようになった。処理はローカルで行われ会話の別インデックスは作らないとOpenAIは説明している。無料プランを含む全ティーク対象だがApple Silicon Mac限定でIntel機は非対応。
