🔴 Claude / Anthropic

更新Claude Code v2.1.212公開 — /fork刷新とバックグラウンドエージェント上限の追加

Anthropicは7月17日にClaude Code v2.1.212をリリースした。`/fork`が会話をバックグラウンドセッションへコピーする形に刷新され、これまでの用途は新設の`/subtask`が引き継ぐ。WebSearch呼び出し数（既定200回）やサブエージェント起動数（既定200件）にセッション単位の上限を追加したほか、2分超のMCPツール呼び出しを自動的にバックグラウンド化。Plan modeがファイル変更を伴うBashコマンドを無許可で実行してしまう不具合、WindowsでのSIGTERMプロセス孤児化も修正された。

Source: GitHub anthropics/claude-code Releases

🔴 OpenClaw / Hermes Agent

更新OpenClaw、v2026.7.2-beta.2を公開 — Android向けフォアグラウンドVoice Wakeとチャンネル安全性強化

OpenClawは7月17日、v2026.7.2-beta.2を公開した。クラウドワーカー上でControl UIセッションを実行するリモートコーディング機能を継続改善し、Android向けにフォアグラウンドで動作するVoice Wakeを追加。headless Linuxノードからカメラ・位置情報・通知機能を公開する対応も進んだ。あわせてTelegramの受信ロス防止など、チャンネル連携の安全性を高める修正が加えられている。

Source: GitHub openclaw/openclaw Releases

🟠 中国系LLM

新モデルMoonshot AI、2.8兆パラメータの「Kimi K3」を発表 — 過去最大級のオープンウェイトモデル

Moonshot AIは7月16日、896エキスパート中16個を活性化するMoE構成の新モデル「Kimi K3」を発表した。総パラメータ数2.8兆、コンテキスト窓は104万8576トークンで価格は帯域を通じて一律。Artificial Analysisの複合Eloスコアで1,547を記録しClaude Fable 5に次ぐ2位となり、Frontend Codeのブラインド評価ではFable 5を上回り首位。大規模リポジトリでのコーディング・エージェント作業に強いとされる。フルウェイトの公開は7月27日を予定。米中対立下での中国AIの急伸として市場でも注目された。

Source: Tom's Hardware, Fortune, Simon Willison's Blog

🟠 AIエージェント全般

仕様策定MCP、エンタープライズ向け認可拡張を安定版へ昇格 — 7月28日に正式仕様公開予定

Model Context Protocolの2026-07-28仕様に向け、組織のIDプロバイダー経由でMCPサーバーへのアクセスを一元管理する「Enterprise-Managed Authorization」拡張が安定版に昇格した。すでにAnthropic・Microsoft・Oktaなど複数のMCPサーバーで採用が進んでいる。今回の改訂はプロトコル層のステートレス化が最大の変更点で、通常のHTTPインフラ上でスケールしやすくなるほか、機能ごとにActive/Deprecated/Removedのライフサイクルと最低12か月の移行猶予を設ける廃止ポリシーも導入される。

Source: Model Context Protocol Blog, InfoQ
