シリーズ完結の経緯（2026-06-01）

このノートシリーズは VOL.1 + VOL.2 の全 10 章で完結です。VOL.3 以降の新規制作は行いません。

背景

  • 2026-04 に Claude Design GA、5月に AlignLab Note → Studio Notes として 10 章を制作
  • 2026-06 に Claude Design の使用枠が 通常 Claude 枠に統合された
  • 専用クォーターを「使い切るための制作」インセンティブが消失
  • 制作リソースは Claude Hub の主軸である Creator System 本体（実プロダクトのパイプライン）に集中させる方が事業価値が高いと判断

完結する 10 章の位置づけ

Claude Design 運用ルール（ADR-009）

このフォルダは Claude Design の出力を受け入れる正式な置き場。Claude Design は直接既存フォルダに書き込めないため、ユーザーがここに置く → 次回 Claude セッションで整理・統合のワークフロー。

3 ステップワークフロー

  1. 制作: ユーザーが Claude Design に依頼。出力は手元の Claude Design 環境に生成
  2. 投入: ユーザーが軽量版だけをこのフォルダに配置（standalone 版は不要、.gitignore で除外済）
  3. 整理: 次回 Claude セッションでこの書架に章を追加 → ステータス更新 → Site Map と Changelog に反映

軽量版 vs standalone 版

種類サイズ目安リポへの扱い
通常版（軽量）30-80 KBcommit する。編集・差分追跡対象
standalone 版（重い）15-28 MB.gitignore で除外。配布が必要なら都度ローカルで再生成
