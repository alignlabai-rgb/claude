ALIGN_Lab 道しるべ

ALIGN_Lab は本ハブとは別の非公開リポジトリです。 作品（IP コンテンツ）の制作・戦略・固有資産が置かれており、商品候補となる中身を保護するため公開はしません。

このハブ（Claude Knowledge Hub）は公開リポで、Claude をどう使うかの方法論・公開情報の整理を担います。 2つのリポは役割が異なるため、Claude Hub 内では ALIGN_Lab の中身を直接書きません。 AI セッション（Claude / Codex）が方向性を理解する必要がある時は、ローカルの sibling フォルダから直接参照します。

最終更新: 2026-05-26（道しるべ化）

役割分担

ALIGN_Lab（非公開） Claude Hub（公開・このリポ）
作品・IP コンテンツ本体 Claude を使う方法論・公開情報の整理
戦略・ロードマップ・固有資産 運用プロトコル・スタイルガイド・LLM 追跡
商品候補となるキャラクター・物語・分析 Creator System のパイプライン設計・Studio Notes
公開しない 他の人に見られても困らない範囲のみ

AI セッションでの参照ワークフロー

Claude / Codex の新セッションが、ALIGN_Lab の方向性を理解する必要がある時:

# 1. ローカル sibling フォルダの存在確認
ls ../ALIGN_Lab/

# 2. ある場合 → README から読む（書き込まない）
cat ../ALIGN_Lab/README.md

# 3. ない場合 → clone する（要 GitHub 認証）
cd ../
git clone https://github.com/alignlabai-rgb/ALIGN_Lab.git
原則: AI セッションは ALIGN_Lab を読むだけ。Claude Hub 側に ALIGN_Lab の中身を抜粋・コピー・要約することは原則しない。具体的なキャラクター名・戦略文書・IP の詳細は Claude Hub に書かない。
