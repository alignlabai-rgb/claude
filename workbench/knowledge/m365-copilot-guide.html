01

Microsoft 365 Chat（BizChat）完全活用

BizChat（Microsoft 365 Chat）は M365 Copilot の中核。 Web 検索（Web モード）と社内データ参照（Work モード）を切り替えられる AI アシスタント。Graph コネクタで社内の全データソースをつなぐことで真価を発揮する。

Web モード vs Work モード

モード参照データ典型ユースケース注意点
Web モードBing Web 検索（最新情報）市場調査・競合情報・最新ニュース収集社内データにはアクセスしない
Work モードTeams メッセージ・メール・ファイル・Dataverse（Graph経由）社内文書検索・会議振返り・担当者検索ユーザーがアクセス権を持つデータのみ参照

BizChat 高精度プロンプト術

Work モード — 社内文書横断検索
「先月の〇〇プロジェクトの進捗報告書の要点をまとめて。Teams のメッセージとメールも含めて」
💡 ファイル名がわからなくても文脈で検索できる。期間や関係者名を加えると精度が上がる。
Work モード — 担当者・専門家の特定
「Azure OpenAI の導入に詳しい社内の人を教えて。最近その話題でチャットやメールをしている人」
💡 Graph API が社員のコミュニケーション履歴から専門性を推定して提示する。
Work モード — 会議内容の横断まとめ
「今月 Teams で開催した〇〇チームの会議をすべて振り返り、未完了のアクションアイテムを一覧にして」
💡 Intelligent Recap のデータを横断的に集約できる。
Web モード — 競合調査
「[競合社名] の最新製品発表と価格改定について、今週のニュースをまとめて。営業提案書用に3つのポイントで」
💡 Web モードに切り替えてから使う。「営業提案書用に」と用途を伝えると出力が整う。

Microsoft Graph コネクタ — 社外データを Copilot に接続

Graph コネクタを使うと SharePoint・Teams 以外の外部データも BizChat から参照可能になる。 Salesforce・ServiceNow・Confluence・GitHub・Jira などの外部サービスを M365 Copilot のナレッジとして取り込める。管理者が Microsoft 365 管理センターから設定。
コネクタ接続先Copilot での活用例
Salesforce顧客情報・商談・活動履歴「〇〇社との最新商談状況を教えて」
ServiceNowIT チケット・ナレッジベース「過去に類似のシステム障害はあった？」
Confluence社内 Wiki・技術ドキュメント「オンボーディング手順書の要点を教えて」
GitHubIssue・PR・コード「リポジトリの未クローズ Issue 一覧をまとめて」
Azure DevOpsバックログ・スプリント「今スプリントの残タスクと担当者は？」
カスタムコネクタ任意の REST API社内基幹システム・業務DB

Word Copilot 実践

文書生成プロンプト集

ゼロから文書を生成（Draft with Copilot）
「新規サービス導入提案書を作成して。背景・課題・解決策・期待効果・スケジュールの構成で、読者は経営層、2ページ以内で」
💡 構成・読者・ボリュームを最初に伝える。"2ページ以内" などの制約が出力品質を高める。
既存ファイルから文書生成（/参照ファイル指定）
「[会議メモ.docx] の内容をもとに、議事録を正式フォーマットで作成して。決定事項・アクションアイテム・期限の表を含めて」
💡 / を入力するとファイル・メール・会議を参照できる。OneDrive・SharePoint のファイルも可。
文体変換（Rewrite）
「このメール文面を、社外の重要顧客向けに丁寧なビジネス敬語に書き直して。現状の内容・主張はそのままで」
💡 選択テキストに対して右クリック → Rewrite、またはサイドパネルから指示。
要約（Summarize）
「この文書の要点を5箇条で、それぞれ1文で教えて」
💡 長大レポートや契約書の初読みに有効。
表・データの挿入
「本文中の競合比較の説明を、製品名・価格・特徴・推奨用途の4列比較表に変換して」

Word Copilot でよく使うコマンド早見表

操作場所プロンプト例
新規ドラフト生成空白文書 → Draft ボタン「〇〇についての報告書を書いて」
選択テキストの書き直しテキスト選択 → Rewrite「もっと簡潔に」「箇条書きに変換」
文書全体の要約サイドパネル → Summarize「このドキュメントの要点は？」
トーン調整サイドパネル → 指示入力「フォーマルに」「カジュアルに」「説得力を高めて」
参照文書から生成サイドパネル → / → ファイル選択「[spec.xlsx] をもとに要件定義書を作って」

Excel Copilot 実践

Excel Copilot は「テーブルに変換済みのデータ」に最も強く機能する。 分析前にデータをテーブル（Ctrl+T）に変換してから使う。自然言語で数式・グラフ・PivotTable の作成を指示できる。

データ分析プロンプト集

データの要約・インサイト抽出
「このデータの主なトレンドと外れ値を教えて。3つの重要な洞察をまとめて」
💡 Copilot が自動でグラフや統計サマリーとともに回答してくれる。
数式の自動生成
「売上列と原価列から粗利率を計算する数式を E 列に追加して。% 表示で」
💡 「F 列の前月比を自動計算する XLOOKUP と IFERROR の組み合わせ数式を提案して」のような複雑な数式も対応。
条件付き書式の設定
「売上が前月比 -10% 以下の行を赤く、+20% 以上の行を緑でハイライトして」
ピボットテーブル & グラフ生成
「部門別・月別の売上集計ピボットテーブルを新シートに作成して。棒グラフも追加して」
データのフィルター・並び替え指示
「受注金額が100万円以上で、かつ納品日が今月中の行だけを表示して」
💡 Copilot は表示を変えた上で元に戻す方法も提示してくれる。

Python in Excel（プレミアム機能）

Microsoft 365 Personal/Family/Business 以上では Python in Excel が利用可能。 Copilot に「Python で〜分析して」と指示すると、pandas・matplotlib・seaborn を使った高度な分析コードを自動生成してセル内で実行する。
Python in Excel 活用例
「Python を使って、このデータの相関行列をヒートマップで可視化して」
💡 「予測モデルを作って来月の売上を予測して」のような機械学習タスクも可能。

PowerPoint Copilot 実践

プレゼン自動生成プロンプト集

ゼロからプレゼン生成
「新製品 [製品名] の営業提案プレゼンを10スライドで作って。アジェンダ・課題・解決策・デモ・料金・Q&Aの構成で、対象は IT 部門長」
💡 スライド枚数・構成・ターゲットを明示。社内テンプレートを先に適用してから生成すると書式が揃う。

「[提案書.docx] の内容をもとに、エグゼクティブサマリー用の5スライドを作って。各スライドに1つのキーメッセージとサポートデータを入れて」
💡 既存の Word 文書・PDF・Teams 会議メモからスライドを生成できる。
スライドの追加・改善
「3枚目のスライドに、競合との比較表を追加して。価格・機能・サポート対応の3軸で」
デザイン & レイアウト調整
「このスライドのテキストが多すぎる。重要ポイントを3点に絞り、残りはスピーカーノートに移して」
💡 Designer 機能（デザインアイデア）と組み合わせると見た目も一気に改善する。
発表練習支援（Presenter Coach）
「このプレゼンの発表原稿を日本語で書いて。各スライド2〜3分を想定して、自然な口語体で」

Teams Copilot 実践

Intelligent Recap（会議の自動要約）

Teams Premium / M365 Copilot のライセンスがあれば、会議終了後に自動で議事録・ToDoアクション・要約が生成される。 参加できなかった会議のキャッチアップに絶大な効果を発揮する。
会議後の振り返り（Meeting Recap）
「この会議でどんな決定がなされた？誰が何を担当することになった？」
💡 会議の「要約」タブで Copilot に追加質問できる。トランスクリプトがある会議のみ。
特定の参加者の発言を確認
「[名前] が予算について何を言っていた？タイムスタンプも教えて」
自分が参加していない会議のキャッチアップ
「昨日の製品ロードマップ会議で自分（[自分の名前]）に関係するアクションはあった？」
会議中のリアルタイム活用
「（会議中）今まで話し合われた内容を3点でまとめて」 / 「（会議中）この議題について意見が出ていない参加者は誰？」
💡 会議中に Teams チャットパネルの Copilot に質問できる（要トランスクリプト有効化）。

チャット・チャンネルでの活用

場面プロンプト例
長いスレッドのキャッチアップ「このチャンネルの今週の議論を要約して。未解決の質問もリストアップして」
返信文案の生成「この質問に対して、〇〇の観点から回答の文案を提案して」
重要メッセージの検索「〇〇プロジェクトについてのメッセージを先月分から探して」

OneNote / Loop / Copilot Pages 実践

OneNote

ノート要約・整理

「このノートブックの先月分を要約して。カテゴリ別に整理されたインデックスページを作って」。手書きメモの OCR テキスト化 + 構造化も得意。

Loop

リアルタイム共同作業

Loop コンポーネントをチャット・メール・会議に埋め込み、全員がリアルタイムで同じコンテンツを編集。Copilot が各コンポーネント内でコンテンツを生成・補完する。

Copilot Pages

AI 生成コンテンツの保存・共有

BizChat の回答を「ページに追加」でそのまま共有可能なドキュメントに変換。チームで同時編集しながら Copilot に追記させられる。会議後の議事録共有に最適。

Loop × Teams 連携パターン

会議後の共同アクションリスト作成
Intelligent Recap の ToDoアクション → 「Copilot Pages に保存」→ Teams チャットに共有 → 全員がリアルタイムで担当者・期限を記入
💡 メールでの議事録送付よりも完了率が高い（全員が同じ場所を更新するため）。
ブレインストーミングの構造化
「このブレインストーミングのメモを、テーマ別にグループ化して優先順位をつけて。実行可能なアクションとアイデアを分けて整理して」

Build 2026 アップデート

GA

Copilot Actions（自律タスク実行）

BizChat に「毎朝9時に昨日の未読メールを要約して Teams に投稿して」と指示するだけで繰り返しタスクを自律実行。Power Automate との統合で複雑なワークフローも自然言語で設定可能。

GA

Agent Mode in Microsoft 365

BizChat が複数ステップの目標を自律的に達成する「エージェントモード」が GA。「来週の役員会用に売上データを集めてスライドを作って関係者に共有して」を一気通貫で実行。

GA

Copilot Tuning（組織固有の微調整）

組織の文書・コミュニケーションスタイル・専門用語を学習した Fine-tuned Copilot を作成可能。品質基準・社内用語・文体を Copilot に反映させ、出力の一貫性を向上。

GA

Researcher & Analyst エージェント

深い調査・分析に特化した2つの専用エージェントが M365 Copilot に統合。Researcher は Web + 社内データの横断調査、Analyst は Python によるデータ分析を自律実行。

Preview

Copilot × SAP・Workday 統合

SAP・Workday・Dynamics 365 への接続が強化され、BizChat から直接 ERP・HRM のデータを参照・更新できるコネクタが Preview 提供開始。

Preview

Real-Time Audio Summarization in Teams

Teams 電話（PSTN 通話含む）のリアルタイム文字起こし + 要約が Preview。営業電話のフォローアップメール自動生成まで一貫して対応。

GA

Copilot in Excel — Python による高度分析

Copilot が Python in Excel のコードを自動生成して高度な統計分析・予測モデリングを実行する機能が GA。データサイエンスの知識なしに本格分析が可能に。

GA

Copilot Pages の全テナント展開

Copilot Pages が M365 Copilot ライセンス所持者全員に GA。BizChat の回答を即座にページ化してチームで共同編集する機能がデフォルトで利用可能に。
