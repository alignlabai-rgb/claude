Gemini Live — リアルタイム音声・映像 AI

Project Astra の能力を一般公開した Google のリアルタイム会話 AI。カメラで映したものを見ながら話しかけ、画面を共有しながら相談できる。割り込みも自然なリズムも人間との会話そのもの。

リアルタイム音声 カメラ共有 スクリーン共有 Project Astra 全プラン無料 iOS / Android Android XR 対応

1. Gemini Live とは — Project Astra の公開版

Gemini Live は Gemini アプリの「リアルタイム会話モード」です。テキストのやり取りでなく、声で話しかけ、音声で返ってくるインターフェース。さらに カメラや画面をリアルタイムで共有して視覚的な文脈を加えながら会話できます。

ベースとなる技術は Project Astra（Google DeepMind の研究プロジェクト）。「世界を見て、聞いて、記憶して、リアルタイムで対話できる普遍的 AI エージェント」という構想を実用化したもので、Gemini Live はその能力を iOS / Android アプリとして誰でも使えるようにしたものです。

無料で全機能利用可能: カメラ共有・スクリーン共有を含む Gemini Live のコア機能は、無料プランを含む全ユーザーが利用できます（2026年5月時点）。

2. リリース史 — Project Astra から Gemini Live へ

2024年5月 — Project Astra デモ（Google I/O 2024）

DeepMind が「世界初のリアルタイム・マルチモーダル AI エージェント」として Project Astra をデモ。カメラを向けたものを認識・記憶し、自然な会話で答える能力を披露。

2024年後半 — Gemini Live ベータ（Android）

Gemini アプリに「Live」モードとして統合。音声会話の基礎機能を Android で先行公開。AI Plus（旧 Gemini Advanced）ユーザー向け。

2025年5月20日 — カメラ・スクリーン共有・全ユーザー無料化（I/O 2025）

Google I/O 2025 で大型アップデート。カメラ共有・スクリーン共有を iOS / Android 全ユーザーに無料展開。Calendar・Keep・Tasks・Maps との統合も発表。

2026年〜 — Android XR（スマートグラス）統合

Android XR スマートグラスに Gemini Live + Project Astra が統合。常時映像・音声フィードからリアルタイムでコンテキストを取得し、レンズ越しの世界に情報をオーバーレイ。

3. 主要機能

基本

リアルタイム音声会話

  • ほぼゼロレイテンシで話しかけ・返答
  • 途中で割り込み可能（rambling したら中断できる）
  • 自然なリズム・間・トーンを維持
  • 複数の声のトーンを選択可能
  • 長い説明も音声で自然に聞ける
視覚

カメラ共有

  • スマートフォンのカメラをリアルタイムで Gemini に見せる
  • 「これは何？」「どう直す？」をカメラ越しに質問
  • 料理・植物・製品・文書・コードを映して質問
  • 前面・背面カメラ両対応
  • iOS / Android 全ユーザー対応
画面

スクリーン共有

  • スマートフォンの画面をリアルタイムで共有
  • アプリのバグ・設定画面・エラーを見ながら相談
  • コードレビューや UI フィードバックに活用
  • YouTube 動画・PDF・ドキュメントの内容について会話
  • iOS / Android 全ユーザー対応
拡張

コンテキスト・記憶

  • 大容量コンテキスト（YouTube 動画・PDF・画像を会話に持ち込み）
  • Google カレンダー・Keep・Tasks・Maps と連携した質問
  • 「明日の予定は？」「最寄りのカフェは？」をリアルタイムで
  • Project Astra の記憶システム（セッション間継続は実験的）
新

Android XR・スマートグラス

  • Google の Android XR スマートグラスに統合
  • 常時映像フィードで周囲を認識・コンテキスト保持
  • ハンズフリーで音声会話しながら情報をオーバーレイ
  • レンズ越しの物体・テキスト・人物をリアルタイム認識
言語

多言語・翻訳

  • 日本語を含む多言語でのリアルタイム会話
  • 言語学習のための会話練習に最適
  • 外国語の音声をリアルタイムで翻訳・説明
  • 異なる言語を混在させた会話も対応

4. プランと利用制限

プラン月額Gemini Live 利用主な制限

AI Pro $19.99 ◎ 全機能 + 高い上限 実質制限なし（通常利用）
AI Ultra $200 ◎ 最高上限・優先アクセス なし

📱 対応デバイス: iOS（iPhone）と Android スマートフォン・タブレット。2026年以降は Android XR スマートグラスでも利用可能に。ブラウザ版は AI Studio（開発者向け）経由で Live API として提供。

5. 活用シーン

学習

語学会話練習

英語・スペイン語・フランス語のネイティブ先生として利用。発音をリアルタイムに修正してもらい、自然な会話練習ができる。

DIY

カメラ越しのトラブルシューティング

壊れた電化製品・配管・家具をカメラで映しながら「これ何が問題？」と聞くと、見ながらアドバイスしてくれる。

料理

食材・料理の質問

冷蔵庫の中身をカメラで映して「これで何が作れる？」。料理中に手を止めずに声で次のステップを確認。

ビジネス

スクリーン共有でのデバッグ

エラー画面・コード・ログをスマホの画面で共有しながらリアルタイムに相談。ハンズフリーでトラブルシューティング。

移動中

通勤中の知識整理

ポッドキャストのように耳だけで AI と対話。本の内容・仕事の課題・アイデア整理を歩きながら声で展開する。

ショッピング

店頭での商品比較

店内で商品をカメラで映して「この2製品どちらがいい？」「レビューは？」をリアルタイムで確認。

旅行

観光地のリアルタイム解説

建物・看板・メニューをカメラで映すと、歴史・翻訳・おすすめをその場で音声解説。スマートグラスとの相性も抜群。

アクセシビリティ

視覚補助・読み上げ

書類・メニュー・標識をカメラで映すと内容を読み上げて説明。視覚障害者やシニアのサポートツールとして活用。
