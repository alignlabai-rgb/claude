🔴 Claude / Anthropic

更新Claude Code v2.1.208公開 — スクリーンリーダーモードを新搭載、vim二重キーリマップにも対応

Anthropicは7月14日にClaude Code v2.1.208をリリース。`claude --ax-screen-reader`や環境変数`CLAUDE_CODE_PROCESS_WRAPPER`設定で有効化できるプレーンテキスト表示の「スクリーンリーダーモード」をオプトインで追加した。あわせてvimインサートモードで`jj`など二重キーをEscapeにマップする`vimInsertModeRemaps`設定、フルスクリーン時の複数選択メニューのマウスクリック対応、バックグラウンドエージェントの信頼性・メモリリーク修正も実施している。

Source: Claude Code Changelog

🔴 OpenClaw / Hermes Agent

資金調達Hermes Agent開発元Nous Research、評価額15億ドルでの新規資金調達を協議中

TechCrunchが7月13日に報じたところでは、Hermes Agentを開発するNous Researchが評価額15億ドルでの新規調達ラウンドを協議中。Robot Venturesが主導し、USVなども参加する見込みで、少なくとも7,500万ドルを調達する計画という。7月1日には大型アップデート「v0.18.0 "The Judgment Release"」を公開しており、開発の勢いを追い風にした調達となる。

Source: TechCrunch

🟠 AIエージェント全般

強化Perplexity「Computer」、作業内容の記憶・モデル途中切替・Webサイト公開に対応

Perplexityは7月13日、エージェント機能「Computer」をアップデート。過去の作業内容を記憶して次回に引き継げるようになったほか、応答速度の向上、タスク実行中のモデル切り替え、生成したWebサイトの公開、非公開企業の調査機能などを追加した。

Source: Perplexity

🟠 中国系LLM

発表DeepSeek、V4正式版を7月中旬に投入予定と発表 — ピーク時間帯API課金を新導入

DeepSeekはプレビュー版として4月に公開した「V4」の正式版を7月中旬に投入すると発表。全モデル共通で100万トークンのコンテキスト長を標準搭載し、エージェントタスク・数学推論・コード生成をさらに強化するという。あわせて平日9-12時・14-18時のピーク時間帯は通常の2倍料金となる新課金体系を導入し、旧エイリアス`deepseek-chat`・`deepseek-reasoner`は7月24日15:59 UTCで廃止予定。

Source: TechNode

🟡 Gemini / Google AI

拡大Google Sheetsの「Fill with Gemini」、11言語追加で対応言語拡大 — 利用上限緩和は7月15日で終了

GoogleはGoogle Sheetsの自然言語プロンプト機能「Fill with Gemini」およびAI関数の対応言語に、標準中国語・オランダ語・マレー語・ヘブライ語・ポーランド語・トルコ語・チェコ語・インドネシア語・スウェーデン語・デンマーク語・ノルウェー語の11言語を追加した。あわせて7月15日まで実施していたWorkspace向け利用上限緩和のプロモーションが終了し、以降は通常のユーザー単位の利用上限が適用される。

Source: Google Workspace Updates
