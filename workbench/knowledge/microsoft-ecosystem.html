Microsoft AIを選ぶための地図

モデル名からではなく、成果物・データ・実行権限からサービスを選ぶ。Copilotという同じ語で異なる契約や実行基盤を混同しないための総覧。

最終更新：2026-10-13 / 公式一次資料確認。実環境の機能・契約検査は未実施。

まず「何を作り、どこで動かすか」を決める

MicrosoftのAIを一枚の製品ランキングとして読むと、同じ機能が何度も登場して混乱する。文書を整える利用者向けのCopilot、業務処理を組むPower Platform、エージェントを開発・運用するFoundry、推論の材料になるPhiは、同じ仕事の違う層だ。賢いモデルを選ぶ前に、編集対象の正本、誰の身元でアクセスするか、外部に作用する操作、レビューする人を決める。

名称も更新されている。旧Microsoft 365 CopilotはMicrosoft Copilot、旧Azure AI FoundryはMicrosoft Foundryと説明される。一方、ライセンス名や旧URLには旧名が残る。この記事では既存URLを維持し、商品名の変更を契約の自動変更と読まない。Copilotの名称と要件、Foundryの現行名称。

困りごと最初の入口決めるべき境界
既存の文書・表・会議から下書きを作るMicrosoft Copilot利用者の閲覧権限と、参照した版
受付、確認、承認、台帳更新を反復するPower Apps / Power Automate決定的な検証と副作用の実行条件
質問を理解し業務ツールを選ぶCopilot Studioharness、接続の身元、従量課金
コード・モデル・観測を自分で制御するMicrosoft Foundry / Agent Framework配置、評価、復旧、担当者
端末で小さなモデルを評価するPhi重みの版、推論実装、日本語品質
コード変更をPRへ育てるGitHub Copilot対象repo、テスト、マージ権限

この対応表は筆者の選択案。Power Platformの製品範囲は公式製品索引を参照。

三つの「Copilot」を分ける

個人Microsoftアカウントで使う消費者向けサービスと、Entraの職場・学校アカウントで使う企業向けサービスは、同じ画面の名前でも条件が異なる。職場版にはChat、アプリ内編集、組織データを使うライセンス付き体験などがある。公式比較はBasic/Premiumを区別している。チャットのアイコンがあるだけで、組織全体のメールやファイルを探索できるとは考えない。

GitHub Copilotは開発用の別サービスだ。またCopilot Studioの「GitHub Copilot harness」は、そのGitHubサービス自体ではない。共通技術の利用と顧客データの送信先を混同しない。Studioのharness定義。購入検討表にはブランド名ではなく、アカウント、製品、機能、対象環境、含まれる枠、別メーターを一行ずつ書く。

教材例：公開記事の情報を制作判断に使う

以下は未実行の設計例だ。公開の製品資料を読み、社内で使えそうな技術を提案する仕事では、まず出典・確認日・提供段階を人が読める短いノートにする。日々の速報をそのまま業務エージェントの命令へ変換しない。「使えるらしい」から「この環境で試せる」への移行には、対象ライセンスと機能の有効化、試験データ、費用上限が必要になる。

資料の下書きだけならCopilotで足りるかもしれない。反復する収集・検証・承認を管理するならPower Platformを検討する。複数のモデルで同じ試験を再現する必要が出てからFoundryやコードの出番になる。最初から全部を契約するのではなく、手作業で判定可能な最小工程を一つ作り、ボトルネックを測る。

失敗条件は、単なる誤答だけではない。正しい文章でも別テナントの条件だった、検索できるが採用権限はない、従量課金が試験中に発生した、といった不適合を記録する。評価は「採用可能な提案に到達した数」ではなく、根拠の再発見時間、差戻し理由、訂正負荷まで見る。

読み進め方と導入判断

利用者はCopilotの概説と実践ガイド、業務設計者はPower Platformの概説と設計ガイド、開発者はFoundryとAgent Frameworkへ進む。Office三記事はWordの事実保存、Excelの計算保存、PowerPointの意味保存という異なる評価を扱う。比較は一番長い機能一覧ではなく、自分の失敗を減らせるページから読む。

リージョン、tenant、リリースchannel、政府cloud、プランによって利用可否は異なる。本記事は公開一次資料の確認結果であり、読者の契約や管理画面を検査した報告ではない。価格や機能が表示されない場合は権限や提供条件を確認し、セキュリティ設定を迂回して使わない。
