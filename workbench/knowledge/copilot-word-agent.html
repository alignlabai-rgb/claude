エージェントモードとは — Plan/Research/Draft/Review サイクル

正式名称：2026年4月22日の GA 時に "Agent Mode" から "Edit with Copilot" に改称。Build 2026（5月19〜21日）でデフォルト機能となりました。本ガイドでは通称「エージェントモード」を使用します。2025年9月29日に「Vibe Working」構想として初発表、2026年11月に Word Online でプレビュー開始、2026年4月22日に GA。

4フェーズの自律ワークフロー

Phase 1

Plan

文書構成・アウトラインを設計。目的・読者・形式を整理して実行計画を提示。ユーザーが承認・修正できる。

Phase 2

Research

Microsoft Graph 経由でメール・会議メモ・ファイル・SharePoint を検索。アクセス権を尊重して関連情報を自動収集。

Phase 3

Draft

対象読者・トーンに合わせてコンテンツを生成。参照ファイルと Graph 情報を統合してドキュメントを起草。

Phase 4

Review

論理的整合性・品質を自己チェック後に出力。追跡変更で変更箇所を明示。ユーザーがレビュー・修正できる。

観点旧 Copilotエージェントモード（Edit with Copilot）
動作方式提案テキストを提示（ユーザーが挿入）ドキュメントを直接自律編集
ワークフロー1ステップの単発応答Plan→Research→Draft→Review の4フェーズ
確認質問なし（単方向）読者・トーン・フォーマット・範囲を逆質問
追跡変更なしWord レベル精度で変更を自動追跡・表示
コメント管理なしコメント追加・返信・解決を自律実行
文書要約300ページまで3,000ページまで対応
LLM 選択なしGPT-5.5 / Claude Opus 4.8 / Think Deeper 等から選択

有効化・アクセス方法

デスクトップ Word（Windows）

  1. Word ドキュメントを開く
  2. リボン「ホーム」→ 「Copilot」 ボタンをクリック（または文書余白の Copilot アイコン）
  3. 右側に Copilot ペインが開く（Build 2026 以降はデフォルトでエージェントモード）
  4. ペイン上部のモデルピッカーで LLM を選択
  5. 追跡変更・コメント管理機能はデスクトップ版先行（Web/Mac は順次対応予定）

Word Online（Web ブラウザ）

  1. OneDrive / SharePoint でファイルを開く
  2. 右上の 「Copilot」 ボタンをクリック
  3. エージェントモードは 2025年11月から利用可能
  4. 基本的なドラフト・編集機能は対応済み
  5. Word レベル追跡変更・コメント管理は「coming soon」（2026年6月時点）

モデル選択の手順

  1. Copilot ペインを開く
  2. ペイン右上のモデルセレクターのドロップダウンをクリック（デフォルトは「Auto」表示）
  3. Quick Response（速度優先）、Think Deeper（長時間推論）、Claude Opus 4.8、More（追加 GPT バージョン）から選択
  4. 選択はプロンプトごとに可能。いつでも切り替え可能。

04

コア機能詳解

起草

マルチステップ文書起草

プロンプト1文から4フェーズで完全なドキュメントを生成。読者・トーン・フォーマットを逆質問してから起草開始。中間結果を見て方向修正が可能。

編集

構成変更・セクション再編

文書全体の再構成（セクション順序変更・統合・分割）、見出し階層の変更、段落レベルの移動を自律実行。大量の手動作業を1プロンプトで完了。

変換

トーン・スタイル変換

「社内向けカジュアル」→「投資家向けフォーマル」、「技術者向け詳細」→「経営幹部向け要約」などオーディエンスに合わせた全文変換。

要約

大規模文書の要約

最大 3,000 ページの文書を要約可能（旧 Copilot の 10 倍）。複数ファイルの統合要約・エグゼクティブサマリー生成にも対応。

コメント

コメント管理

Copilot がコメントを追加・返信・解決できる。チームのコメントスレッドを読んでアクションリストを抽出する機能も。コメントは正確なテキスト箇所にアンカーされる。

レイアウト

文書レイアウト管理

ヘッダー・フッター・目次の挿入・更新、ページ番号・日付のフィールド追加、段組み・余白の設定変更をプロンプトで実行。

05

追跡変更 × Copilot — Word レベル精度

大幅な改善：エージェントモードの追跡変更はWord レベルの精度（旧 Copilot の段落レベルより細かい）で変更を記録します。Copilot が編集した箇所はすべて追跡変更として表示され、通常の変更承認/拒否ワークフローと完全に統合されています。

追跡変更の動作

  • Copilot の編集はデフォルトで追跡変更として表示
  • 事前に追跡変更を有効にする必要なし（Copilot インタフェースから直接有効化可能）
  • ドキュメントに既存の追跡変更がある場合も自動でトラッキング
  • すべての変更は完全に元に戻せる
  • 標準の承認/拒否ボタンで確認・適用または却下

承認フロー

  • Copilot が提案した変更を1つずつ承認または拒否
  • 「すべての変更を承認」で一括適用
  • 変更の前後を比較しながら確認可能
  • 追跡変更オフの場合は直接編集に切り替え
  • 変更履歴は文書の git 履歴のような役割を果たす
展開状況（2026年6月時点）：Word レベルの追跡変更機能はWindows デスクトップ版（Current Channel）で先行提供中。Word Online（Web版）と Mac 版は "coming soon" ステータス。

参照ドキュメント × グラウンディング

ファイル参照

最大 3 ファイルを参照

Copilot プロンプト欄の「/」を入力するか「ファイル参照」ボタンで OneDrive/SharePoint のファイルを検索して添付。Word・PowerPoint・Excel・PDF・TXT に対応。

Notebooks

Copilot Notebooks グラウンディング

Copilot Notebooks（最大 300 参照）を使ってスコープを絞ったグラウンディングが可能。Web URL（2026年5月〜）・OneNote・Copilot Pages も参照ソースとして追加可能。

Pages 連携

Copilot Pages → Word 変換

Copilot Pages（Loop ベースの永続的 AI ドキュメント）を Word 文書に変換できる。Pages は Notebooks の参照ソースとしても利用可能。

Graph

Microsoft Graph 自動グラウンディング

エージェントモードの Research フェーズで Graph 経由のメール・会議・ファイルを自動参照。「@メンション」不要で関連情報を自動収集。アクセス権は厳守。

参照ファイルの効果的な使い方

ユースケース参照ファイルの使い方
テンプレートに沿った文書生成既存のテンプレート Word ファイルを参照に追加して「このテンプレートの形式で〜を作成して」と指示
前回版との整合性確保前回バージョンの文書を参照に追加して「前回版と整合性を保ちながら更新して」と指示
複数資料の統合3つのリサーチ文書を参照に追加して「これらを統合した要約レポートを作成して」と指示
スタイル・ブランドの一貫性ブランドガイドライン PDF を参照に追加して「このガイドラインに準拠した文章に修正して」と指示

Legal Agent for Word（Frontier/US 限定）

提供状況（2026年6月時点）：Legal Agent は 米国テナント限定 / Frontier プログラム参加必須 / Windows デスクトップ版のみ のプレビュー機能です（2026年4月30日発表）。一般提供（GA）の日程は未発表。

Legal Agent の機能

法務

プレイブック駆動の契約レビュー

組織の法的スタンダード・承認済み言語・交渉ポジションを記載した「プレイブック」を基に、契約書を条項ごとにレビュー。プレイブックとの不一致箇所を自動検出・修正提案。

追跡変更

Tracked Changes での修正提案

提案された変更はすべて追跡変更として出力。各変更には変更理由を説明するインライン コメントが自動追加。弁護士が変更の根拠を即座に確認できる。

交渉履歴

既存追跡変更の保持

既存の追跡変更が含まれる文書（交渉中の契約書）を処理可能。過去の修正履歴を保持しながら新しい提案のみを追加。交渉の文脈が失われない。

Legal Agent のワークフロー

  1. プレイブック提供：組織の法的スタンダード・承認済み言語・交渉ポジションを記載したドキュメントを Copilot に提供
  2. プレイブック解析：Agent がプレイブックを構造化されたレビュー指示のシリーズに分解
  3. 条項ごとのレビュー：契約書の各条項をプレイブックと照合して不一致を特定
  4. 修正提案の出力：不一致箇所に追跡変更（赤線）とコメント（変更理由）を自動追加
  5. 弁護士によるレビュー：提案された変更を承認/拒否/修正。最終決定は人間が行う
免責事項：Legal Agent は法的アドバイスを提供するものではなく、資格を持つ法律の専門家の代替ではありません。すべての出力は必ず人間の弁護士がレビューしてください。利用可能条件：米国テナント / Frontier 参加 / M365 Copilot ライセンス / 管理者による Anthropic モデル有効化 / Windows デスクトップ版 Current Channel。

Work IQ — 自動グラウンディング

Work IQ は Microsoft が「Copilot と組織のエージェントをパーソナライズするインテリジェンス層」と定義するコンテキスト基盤です。Word エージェントモードの Research フェーズで自動的に機能します。

📧 メール・Teams コンテキスト

「プロジェクト A の提案書を作って」→ 関連するメールスレッド・Teams チャットから自動的にコンテキスト収集。@メンション不要で関連情報が自動グラウンドされる。

📅 会議・カレンダー情報

「先週の戦略会議の決定事項をまとめたメモを作って」→ Teams 会議の文字起こし・議事録から自動収集。会議の文脈を踏まえた起草が可能。

📁 SharePoint・ファイル

組織の SharePoint サイト・OneDrive のファイルを検索して関連コンテンツを自動参照。アクセス権を厳守（ユーザーが閲覧権限を持つファイルのみ）。

Work IQ のデータ範囲：平均的な Fortune 500 企業の Work IQ データフットプリントは 600+ テラバイト（Microsoft 内部データより）。これだけの組織データを Copilot がリアルタイムで参照・統合して文書生成品質を向上させます。Work IQ API は 2026年6月16日に GA。

上級活用シナリオ

法務

契約書ドラフト ← → レビュー サイクル

Copilot で契約書ドラフト生成（参照ファイル: テンプレート）→ 交渉を経て変更が追加 → Legal Agent（Frontier）でプレイブック照合・赤線提案 → 弁護士が最終承認。ドラフトから最終版まで一貫して Word 上で完結。

Cowork

Word + PowerPoint + Email の同時生成

Copilot Cowork（Frontier/GA 予定）を使って「戦略提案書（Word）・プレゼン（PowerPoint）・要約メール（Outlook）を同時生成」の1プロンプトで3つの成果物を一括作成。

Notebooks

研究レポートの自動合成

Copilot Notebooks に調査資料・Web ページ・会議メモ（最大 300 参照）を蓄積 → Word Agent が Notebooks コンテキストを使って構造化レポートを自動生成。リサーチから執筆まで一貫したワークフロー。

HR

人事ポリシー文書の継続更新

既存ポリシー文書を参照ファイルに指定 + 最新規制 PDF を追加 → 「前回版と整合性を保ちながら規制変更を反映して、追跡変更ですべての変更を表示して」の1プロンプトで更新。

Critique モード（Frontier）：高度なリサーチタスクでは「Critique」機能（GPT が起草し Claude がレビュー）と「Council」機能（複数モデルが並行生成し第3モデルが比較）も利用可能。研究ベンチマークで従来比 13.8% 向上を達成。

ライセンス・制限・注意点

項目詳細
必要ライセンスMicrosoft 365 Copilot アドオン（約 $30/ユーザー/月）、またはM365 Personal/Family/Premium。
追跡変更精度Word レベル精度はデスクトップ版 Windows 先行。Web/Mac は "coming soon"（2026年6月時点）。
Claude モデルIT 管理者による Anthropic サブプロセッサ有効化が必要。EU/EFTA/UK ではデフォルト無効。Anthropic モデルのデータ処理は EU データバウンダリ外で実行。
Legal Agent米国テナント / Frontier プログラム参加必須 / Windows デスクトップのみ / Anthropic モデル有効化必須。法的アドバイスではない。
参照ファイル最大 3 ファイル（OneDrive/SharePoint に保存されている必要あり）。ローカルファイルは直接参照不可。
Copilot Notebooks最大 300 参照でグラウンディング。Web URL 参照は 2026年5月〜。
政府クラウドモデル選択機能（Claude 等）は政府/主権クラウドテナントでは利用不可。
Cowork / Critiqueクロスアプリ生成（Cowork）・Critique/Council モードは Frontier プログラム先行。GA タイムラインは未発表。
重要：Copilot が生成・編集した文書の内容は必ず人間がレビューしてください。特に法的・財務的・医療的内容を含む文書は、専門家による最終確認を行ってください。追跡変更を活用して、AI の変更を明確に把握した上で承認することを推奨します。
