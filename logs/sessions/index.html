セッションログ一覧

このハブで実施した主要セッションの時系列ログ。ADR が「決断の記録」なのに対し、ここは「何をやったかの時系列記録」です。

大きな構造変更や 30 分以上の連続作業を含むセッションは、ここに YYYY-MM-DD.html 形式でログを残す運用です（並走プロトコル §7 で定めたメッセージボードの一つ）。

ログ一覧

  • 2026-05-26 ハブ運用カテゴリの本格強化（Phase 1-4） 14 ページ新設・5 ファイル改修。Onboarding / 並走 / Template / Style / Site Map / ADR / Risk / Done / セッションログ運用復活。

※ 2026-04-06 以降のセッションログは未記録のまま。git log で追跡可能だが時系列ログとしては欠落している。今後はここに集約していく。

セッションログを書くタイミング

  • 新規ページを3本以上作成・改修した
  • カテゴリ・フォルダ構造に手を入れた
  • 大きな調査・裏取り作業を実施した
  • ADR を新規追加した（ADR 記録だけでなく、その作業の時系列も残したい場合）
  • 1セッションが 30 分以上の連続作業になった

小さい修正（typo・リンク追加・1ファイル軽微編集）はセッションログ化せず、git log と next-actions 更新だけで十分。

セッションログのテンプレート

新規記録は既存ログ（2026-05-26.html）をコピーして、以下を更新:

  • <title> と <h1> の日付
  • meta-row のメタ情報（日付・主作業・関連 ADR・形式）
  • summary-tiles の数値
  • セッションの目的・実施内容・顕在化したこと・次のフォローアップ
  • commit ハッシュ

詳細は Page Template と Style Guide を参照。
