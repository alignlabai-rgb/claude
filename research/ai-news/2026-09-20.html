🟠 Grok / xAI

新モデルxAI、コーディング特化の新モデル「Grok 4.7」を公開

xAIは、Grok 4.6比でパラメータ数を約40%増の2.1兆に拡大した「Grok 4.7」を公開した。コンテキスト窓は50万トークン、テキスト・画像入力に対応し、長時間タスク向けの強化学習を追加した結果、コーディングベンチマーク「CursorBench 4.0」でGrok 4.6を上回るスコアを記録。一方でGDPvalなど一部指標ではClaude Fable 5.1やGPT-6 Astraに次ぐ2位にとどまる。価格はGrok 4.6と同水準。

Source: Decrypt / xAI

🟠 AIエージェント全般

GA公開Google、Agent Development Kit（ADK）for Kotlin 1.0を正式公開

GoogleはAIエージェント構築フレームワーク「ADK」のKotlin版をproduction-ready版として正式公開した。Python版・Java版と機能パリティを持ち、Android・JVMアプリ向けのオンデバイス／ハイブリッドAIエージェント開発に対応する。

Source: AI Agents Directory

新エージェントTypeSafe AI、超高速ブラウザ操作エージェント「Jev 1.13」を公開

TypeSafe AIの独自モデル「System One」を用いたブラウザ自動操作エージェント「Jev」が、プロトコル呼び出し回数を大幅に削減し約7秒でWeb操作タスクを完了できることを実証した。LLM Gatewayにも追加されている。

Source: AI Agents Directory / LLM Gateway

アップデートMicrosoft、Agent Framework v1.19.0を公開

Microsoftはエージェント開発フレームワーク「Microsoft Agent Framework」のv1.19.0をリリースした。ベクトルストア用プロバイダプロトコルを刷新し、MongoDB・Azure DocumentDBコネクタ（アルファ版）とAzure Cosmos DB NoSQL対応を追加。オーケストレーションと開発者向けUIも強化された。

Source: Microsoft Agent Framework Release Notes
