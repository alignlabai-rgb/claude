🔴 OpenClaw / Hermes Agent

アップデートOpenClaw、セキュリティ・認証情報保護を強化した v2026.7.33 を公開

OpenClawは9月18日、v2026.7.33をリリースした。コマンドパース処理の堅牢化、ブラウザのオリジンチェック強化、プラグインのGitインストール経路の保護、診断機能の拡充、サービス認証情報の取り扱い改善、Webhookログの強化など、セキュリティと認証情報保護を中心とした修正を含む。同日はエコシステム全体でも500件超のissue・PRが更新される活発さで、一方で2026.9.x系のアップデート移行やGatewayの起動時間に関する不具合報告も継続している。

Source: OpenClaw Release Notes / GitHub

🟠 GPT / OpenAI / Codex

新機能OpenAI、ChatGPTデスクトップ内蔵ブラウザにChrome拡張機能対応を追加

OpenAIは9月18日、ChatGPTデスクトップアプリの内蔵ブラウザにChrome拡張機能とChrome DevTools Protocolのサポートを追加した。1Passwordなどの拡張機能を別ウィンドウに切り替えずにインストール・ピン留めでき、ライブのブラウザセッションをChatGPTから直接操作できるようになる。Chrome・Edge・Brave・Vivaldiはサイドチャット表示にも対応するが、Operaは非対応。

Source: cryptobriefing.com / runtimewire.com

アップデートCodex、音声会話・エージェント向けタスク管理・Touch ID対応などを追加（v0.156.0-alpha系）

OpenAIのコーディングエージェントCodexは9月18日、v0.155.0を経てv0.156.0-alpha系を連続リリースした。実験的な音声会話機能、ライブの推論サマリー表示、エージェント向けタスク管理、対応Macでのタッチ ID認証、デーモン更新の設定可能化、Amazon Bedrockの認証情報サポートを追加。あわせてTUIのローカルセッションで推論サマリー非対応プロバイダーからのリクエスト拒否を防ぐ修正も行われた。

Source: OpenAI Codex Changelog / Releasebot

🟠 Grok / xAI

新モデルxAI、音声認識モデル「Grok Voice Transcribe 2.0」を公開——精度2倍で価格据え置き

xAIは9月18日、音声認識（speech-to-text）モデル「Grok Voice Transcribe 2.0」をリリースした。実世界データでの精度がv1.0比で約2倍に向上し、多言語対応・単語単位のタイムスタンプ・話者分離（diarization）・マルチチャンネル対応・ターン検出の精度改善を、価格は据え置きで実現した。

Source: x.ai / Releasebot

🟠 クリエイティブAI連携

新機能Adobe Firefly動画エディタ、背景除去ツール「Remove background」をベータ公開

Adobeは9月、Firefly動画エディタに被写体を保持したまま背景を除去できる「Remove background」機能をベータ追加した。選択したクリップ区間の最初のフレームで被写体を検出し、クリップ全体を通して一貫して背景を除去する仕組み。処理後のクリップはタイムライン上で置き換わり、MP4での書き出しや追加編集にも対応する。

Source: Adobe Firefly Help / ProVideo Coalition
