実用上の変更点

1. trackerの「current」列は日付を必須にする。 API alias / product release / weights / previewを明記し、別surfaceの名称を同一モデルだと推測しない。

2. 速報は候補検出に使い、公式発表で確定する。 X/GrokPulseなどの話題は価値あるsignalだが、噂・企業の自己評価・利用可能なAPI IDを同じ事実欄に混ぜない。

3. 「見つからない」はgapとして残す。 Baichuan、Yi、Phi、Tencent移行中のようなcatalog不確実性は、古いモデル名を最新と見なすより追跡対象として明示する。
