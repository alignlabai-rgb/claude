表紙を1枚つくる

03

使い回せるプロンプト6つ

そのままコピペして、空欄を埋めて投げる。3年使い倒せる土台プロンプト。

START

① 最初の一発目

真っ白から立ち上げる。役・目的・制約・形式を1セットで渡す。

あなたは [役割] です。
[何を] を [誰のために] 作ります。

# 前提
- 媒体: [例: 1920×1080 スライド]
- トーン: [例: 静か・力強い]
- 必須要素: [列挙]
- 避けたいこと: [列挙]

# お願い
artifactsで形にして。完成度7割でいいから速さ優先で。
# 出力フォーマット
HTML一枚 / 説明文は最後に2-3行。
VARIANTS

② 3案ふらせる

方向性に迷ったときは、最初から3案。比較して頭が整理される。

さっきの [要素] について、
方向性の違う3案を作って。

A案: [方向の特徴]（例: 静かな知性）
B案: [方向の特徴]（例: 祭りの熱気）
C案: [方向の特徴]（例: SF的・未来）

横並びの design canvas で見せて。
各案の [配色 / コピー / 構図] を変えて、
それ以外は同じ条件で。
REFINE

③ ピンポイント修正

全体を直すなと頼むのがコツ。狙いを絞ると、ちゃんと当たる。

下のうち、ここだけ直して：

・[要素A]: [どう変える]
・[要素B]: [どう変える]

それ以外は触らないで、差分が分かるようにして。
変更理由も1行ずつ添えて。
CRITIQUE

④ 厳しめにレビュー

作った後、いったん他人の目を借りる。ぬるい感想は要らないので役を変える。

あなたは口の悪いアートディレクターです。
このデザインを辛口で講評して。

観点:
- 読みやすさ / 視線誘導
- 余白とリズム
- 色のバランス
- 言葉の力（コピーの良し悪し）

各観点に「○ / × / 直すなら」の3行で答えて。
忖度はいらない。
REUSE

⑤ 派生・横展開

完成品を別フォーマットへ。同じ素材で何度も収穫する。

このデザインを下のフォーマットに展開して：

1. Instagram用 1:1 正方形
2. X(Twitter)用 16:9 OGP
3. メール署名用 横長バナー
4. 印刷用 A4縦

それぞれで「主役の要素」「捨てる要素」を決めてから作って。
全部 design canvas に並べて。
SYSTEM

⑥ 仕組みに昇格

1枚を作って終わりにしない。再利用できるシステムに育てる。

ここまでの装飾・色・タイポを、
最小のデザインシステムにまとめて。

# 欲しいもの
- 色トークン（用途名つき：bg, ink, accent, danger, ...）
- 書体ペア（見出し / 本文 / コード）
- 間隔スケール（8/16/24/...）
- ボタン3種（primary / ghost / danger）
- カード3種（plain / outlined / accent）

HTML + CSS variables の1ファイルで。
04

得意・不得意の見取り図

Claudeも万能ではない。「向いてないこと」を知ると、付き合い方が一気に楽になる。

◯得意なこと

CLAUDE CAN — まかせて速い領域
  • 構造的なデザインレイアウト・グリッド・余白計算・型のあるもの
  • コードで表現できるものHTML/CSS/SVG/インタラクション。プレビューしながら直せる
  • 言語化・命名・コピー色名・コンポーネント名・ボタン文言・サービス名候補
  • 第一稿の量産「3案ふらせる」「10個出して」で発散させる
  • 説明と図解抽象概念を、図と例え話と簡単な絵で同時に
  • 体系化・整理散らかったメモを、表や見出しに編み直す
  • 批評と推敲役を変えて辛口の目を借りる。文・図のレビューに強い

△苦手なこと

CLAUDE CAN'T — 人が手をかけるべき領域
  • 写実的なイラスト・写真SVGで「描く」のは複雑なものに弱い。写真合成も不可
  • ブランドの完全再現既存企業のUIをそっくりに真似することは避けるべき・避ける
  • ピクセル単位の微調整「あと2px右」のような厳密な位置決めは人の手が速い
  • 触覚・物理感の判断紙の手触り・印刷の厚みなど、現物でしか分からないこと
  • 最新トレンドの追従学習時点以降の新しい意匠は知らない。事例を渡そう
  • 独創性の責任Claudeは混ぜるのが上手。最後の「振り切り」は人が決める
05 / RHYTHM

デザインの往復、ひと呼吸の例。

あなた
「夏向けの新作キャンペーンLP、ヒーローだけまず3案見せて。波・線香花火・氷の3方向で。」
→
Claude
3案を並べて出力。 各案にコピー・配色・フォントの違いを添えて。
→
あなた
「2番（線香花火）で進めたい。コピーは“はじまりの夜”に。粒の色を金一色じゃなくて3色にして。」
→
Claude
指定どおりに修正。粒の色を黄・橙・赤の3色に変え、コピーを差し替え。差分の説明も添える。
