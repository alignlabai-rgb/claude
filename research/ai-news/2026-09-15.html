🔴 Claude / Anthropic

アップデートClaude Code、v2.1.271/v2.1.272を公開——リモートFast Modeやサブエージェント向け新オプション追加

Anthropicは9月14日前後にClaude Code v2.1.271・v2.1.272を公開した。v2.1.271ではリモートセッション（クラウド／セルフホストランナー）でのFast Mode対応、サブエージェントがCLAUDE.mdを読み込まないよう指定できる`omitClaudeMd`オプション、Bash/PowerShell/Monitorのコマンド単位`allowedDomains`設定など約100項目の変更を含む。v2.1.272は安定性改善のみの修正リリース。

Source: Anthropic Claude Code changelog

新製品Anthropic、金融アドバイザー向け「Claude for Financial Advisors」を発表

Anthropicは9月14日、BlackRock・Charles Schwab・Vanguard・Addepar・Envestnetなど資産運用・ウェルステック各社とのコネクタを備えた「Claude for Financial Advisors」を発表した。面談前準備・議事メモ作成・ポートフォリオのリバランス確認・コンプライアンスチェックなどのワークフロースキルを提供し、実行前に必ず人間の承認を要求する設計とSEC広告規則への自動照合機能を備えるという。

Source: Bloomberg / WealthManagement

🟠 GPT / OpenAI / Codex

アップデートOpenAI、Codexに大型アップデート——Vimモードのundo/redoやプラグインマーケットプレイスCLIを追加

OpenAIは9月14日、Codexの大型アップデートを公開した。Vimモードで`u`（undo）・Ctrl+R（redo）に対応し添付ファイルを含むドラフト全体を保持できるようになったほか、リモートのプラグインマーケットプレイスから一覧・インストール・削除が行えるプラグインCLI、TUI編集や再接続処理の改善、Plus/Teamユーザー向け利用量警告の早期表示などが追加された。

Source: OpenAI Codex changelog

🟠 Grok / xAI

エコシステムMicrosoft、CopilotにxAIの「Grok」を統合——Word・Excel・PowerPointで選択可能に

Microsoftは9月12日、Frontier Program参加者向けにWord・Excel・PowerPointのCopilotでOpenAI・Claudeに加えxAIのGrokモデルを選択できる機能を追加したと発表した。管理者が個別に有効化する必要があり、Grok選択時はデータがMicrosoft外のxAIサーバーで処理されるためEU・EFTA・英国では当面提供されない。サティア・ナデラCEOはX上で「Copilotのモデル選択肢がさらに広がった。Grokを歓迎する」と投稿した。

Source: Microsoft Copilot Blog / Neowin

🟡 業界動向・インフラ

業界動向Cloudflare、広告掲載サイトで「混合用途」AIクローラーのデフォルトブロックを本日開始

Cloudflareは9月15日、検索インデックス収集とAI学習・エージェント用データ収集を兼ねる「混合用途」クローラーについて、広告が掲載されているページでデフォルトでブロックする新方針を発効させた。対象は新規顧客・既存顧客の新規サイト・既存の無料プランサイトで、サイト運営者は設定変更で許可も可能。既存の「Pay Per Crawl」マーケットプレイスも「Pay Per Use」モデルへ移行する。

Source: TechCrunch / Cloudflare Blog
