Claude Design 運用ルール（ADR-009）

このフォルダは Claude Design からの新規出力を受け入れる正式な置き場です。仕組み上 Claude Design は直接既存フォルダに書き込めないため、ユーザーがここに置く → 次回セッションで Claude が整理・統合する、というワークフローを採用します。

3 ステップワークフロー:
  1. 制作: ユーザーが Claude Design に依頼。出力は手元の Claude Design 環境に生成される
  2. 投入: ユーザーが生成物を creator-system/Claude_Design/ 配下に配置（軽量版だけで OK）
  3. 整理: 次回 Claude セッションで、ここに新着があるか確認 → このページに索引追加 → 既存パイプラインへの統合提案

軽量版 vs standalone 版の扱い

種類サイズ目安リポへの扱い
通常版（軽量）30-80 KBcommit する。編集・差分追跡対象
standalone 版（重い）15-28 MB.gitignore で除外。配布が必要なら都度ローカルで再生成

詳細は ADR-009 参照。

新規追加時のチェックリスト

新しい Claude Design 出力をここに置いた時、次回セッションで以下を確認:

  • ☐ ファイル名はネーミング規則「Claudeで○○する」「Claudeと○○する」「Claudeとはたらく」に沿っているか
  • ☐ standalone 版を誤って commit していないか（.gitignore 効いているか確認）
  • ☐ このページの「素材ドキュメント一覧」に索引追加
  • ☐ 既存パイプライン（video / manga / evaluation / monetization / spec）への対応マッピング
  • ☐ Site Map の Creator System セクションに追記
  • ☐ 必要なら anti-patterns や用語集に内容を反映
