資料レビュー支援 — DDの作業と判断を分ける

合成データで抽出・照合・欠損検知を設計し、専門的な採否をAIへ丸投げしません。

旧情報は固定旧版の全文へ分離しています。以下の例・試験案は未実行の教材です。

この章が扱う範囲

Due Diligenceの資料整理では、同一の値が複数資料に現れ、対象期間・単位・定義・版がずれることがあります。AIは抽出候補と差異の一覧を作る補助として評価できますが、法的適合、企業価値、取引の採否を自動確定するものではありません。本稿は法律・投資上の助言や特定取引の検討ではなく、人工データの検査方法です。

秘密のM&A資料や顧客契約を教材に使いません。公開可能な合成表、人工の取引名、実在しない条項番号だけを入力にし、データ境界のownerが許可した環境での試験を候補にします。接続可能という理由だけで未公開資料をproviderへ送らないでください。

三つの層を分ける

資料抽出は、原文のどの箇所に何があるかを記録します。照合は、同じ定義・期間・単位の値を比較します。専門判断は、差異が意思決定に何を意味するかをownerが判断します。AIが自然に書いた説明を、原文にある事実と混ぜないことが基本です。

Codeはファイルを読む・編集する・処理する環境であり、資料閲覧の資格や専門判断の権限を自動で与えません。Claude Code Overview。MCP経由の情報にも同じ区別を適用し、結果と出典IDを保存します。

未実行例：合成売上表を照合する

架空の会社Aの年次表、月次表、説明文を人工的に作ります。年次表は千円単位、月次表は円単位、説明文は異なる期間を含めます。出力は資料ID、対象期間、値、単位、定義、抽出箇所、変換式、照合結果です。単位を揃えず一致・不一致を判定しない条件を付けます。

正解となる計算は決定的な処理で用意し、AIの計算説明を正解にしません。欠損、重複、負数、端数、年度のずれを反例にします。不一致の検出は会社の不正や取引中止を意味せず、確認すべき箇所をownerへ返す材料です。

未実行例：人工条項を比較する

架空の二つの文書に、通知期限と対象条件の違いを作ります。AIへの依頼は、条項番号と原文、異なる表現、確認が必要な点を一覧にすることです。「この契約は有効」「この条項は法令違反」といった判断を完成条件にしません。実在の契約や個人名は含めません。

評価は引用の正確さ、否定や例外の保持、表の読みやすさです。期限の一部分だけを取り出して条件を落とす反例を入れます。資料の版が違う場合も単純な矛盾とせず、どの版を比較したかを明記して、必要な専門家の確認へ残します。

抽出のtraceを残す

出力の各行を元資料の箇所へ結び、原文、抽出値、筆者の解釈を別fieldにします。sourceが不足した行は未確認として残し、AIに穴埋めさせません。PDFの画像やOCRが必要な場合、その認識結果も原本そのものと区別します。

APIで実装するなら、schema、tool結果、失敗処理を検査します。Messages API。中断や空の取得結果で通常の結論が生成されることを防ぎ、機械的な抽出の合格と内容ownerの受入を分けます。

機密と権限を実行環境へ残す

入力データの閲覧、処理、保存、公開は別の許可です。promptの禁止文だけでは強制的な隔離にならないため、permissionや接続scopeを点検します。Permissions。本稿のfixtureを実データへ置換する判断は、そのデータと環境のownerが行います。

reportへ内部のsource path、host名、credential、個人情報を載せないようにします。後から確認できることと公開できることは違います。合成例なら方法を共有しやすく、実案件の証拠は適切な非公開の保管へ残す構成が可能です。

採用の評価は自動化率ではない

評価は抽出誤り、単位違い、条件落ち、未確認の隠蔽、専門家の訂正時間です。全資料をAIへ投げた割合やreportのページ数は価値ではありません。見落としを減らし、確認すべき問いが分かることを重視します。

小標本の成功を全業種や全契約へ一般化しません。適用できる文書形式と除外、必要な検証者、未検証の入力を残します。完成物は判断を支える材料であり、取引や法務の最終決定者をAIへ置き換えるものではありません。

数字が揃っていても結論を急がない

教材では、単位や期間が合っている数字に対し、定義だけが違うケースを加えます。たとえば『顧客数』が契約社数なのか利用者数なのかが不明なら、差分を計算できても比較可能とは限りません。抽出結果には数値とともに定義、対象期間、資料位置、不明点を残します。

この方法が練習するのは資料の照合と未確認事項の整理です。事業の魅力、契約の適法性、買収価格の妥当性は別の専門判断であり、合成の数表から推奨する対象ではありません。読み手が資料に戻れること、疑問点を狭く質問できることを教材の受入条件にします。
