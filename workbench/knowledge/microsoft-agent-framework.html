🏗️ Microsoft Agent Framework（MAF）とは: AutoGen（会話型マルチエージェント）と Semantic Kernel（プロダクション向け AI オーケストレーション）を統合した、Microsoft 公式のエンタープライズ向けエージェント開発基盤。2026年4月に v1.0 が GA リリースされ、Microsoft Build 2026（5月19〜21日）で「Agentic OS としての Windows」ビジョンと共に全面刷新が発表された。

🧱 統合の背景

AutoGen は Microsoft Research が2023年に発表した会話型マルチエージェントフレームワーク。Semantic Kernel（SK）は Azure OpenAI 向けプロダクション SDKとして並行開発されていた。両プロジェクトは長らく独立していたが、2025年後半から統合作業が始まり、2026年4月の MAF v1.0 で完全に統一。

  • AutoGen v0.4 のランタイムを MAF のコアに採用
  • Semantic Kernel のプラグイン・メモリシステムを継承
  • 新インターフェース: AgentRuntime + AgentChat

🌐 エコシステムの位置づけ

MAF は Microsoft の Agentic AI 戦略の中心に位置し、Azure AI Foundry / Copilot Studio / Power Platform と深く統合する。

  • Azure AI Foundry: ホスト型エージェントのデプロイ先
  • Copilot Studio: ノーコード UX のバックエンド
  • Power Automate: ビジネスフロー自動化との接続
  • Microsoft 365 Copilot: Teams/Word/Excel 連携エージェント
  • Windows: OS レベルの Computer Use 実行環境

🔄 AgentRuntime

MAF のコアエンジン。エージェントのライフサイクル管理・メッセージルーティング・状態管理を担当。AutoGen v0.4 の非同期ランタイムを基盤に、SK のプラグインシステムを統合。

  • SingleThreadedAgentRuntime: ローカル開発・テスト用
  • WorkerAgentRuntime: 分散マルチプロセス実行
  • GrpcAgentRuntime: gRPC 経由クロスホスト実行
  • メッセージは型安全（Pydantic モデル）

💬 AgentChat API

高レベルの会話型マルチエージェント API。複雑な Runtime API を抽象化し、直感的なコードでマルチエージェント会話を実装できる。

  • AssistantAgent: ツール呼び出し対応汎用エージェント
  • UserProxyAgent: ヒューマンインザループ用
  • RoundRobinGroupChat: 順番に発言
  • SelectorGroupChat: LLM が次の発言者を選択
  • 終了条件: MaxTurns / TextMentionTermination など

🧩 コアコンポーネント詳解

🔧 Agent Harness

エージェントの「箱庭」。ツール・メモリ・セキュリティポリシーを 1 つの設定で宣言的に定義し、エージェントに注入する。

AgentHarness(
  tools=[web_search, code_exec, file_io],
  memory=AzureCosmosMemory(),
  policy=ContentSafetyPolicy(),
  max_tokens=8192,
)
  • ツール: MCP サーバー / カスタム関数 / OpenAPI 自動解析
  • メモリ: Azure Cosmos DB / Redis / インメモリ
  • ポリシー: Azure AI Content Safety 統合

☁️ Hosted Agents

エージェントを Azure 上でサーバーレスにホスト。デプロイ・スケーリング・監視を自動化。

  • Azure Container Apps ベース（自動スケール 0→N）
  • Azure AI Foundry からワンクリックデプロイ
  • エンドポイント自動生成（REST + A2A 対応）
  • Azure Monitor / Application Insights 統合
  • マルチリージョン対応（v1.1 プレビュー）

🖥️ CodeAct Runtime

エージェントが Python コードを動的生成・実行するサンドボックス環境。ReAct の「ツール呼び出し」より高い表現力。

  • Azure Container Instances でセキュア実行
  • 各実行は独立したサンドボックス（コード漏洩なし）
  • pandas / numpy / matplotlib 等の科学計算ライブラリ利用可
  • 実行結果（テキスト + 画像）をエージェントにフィードバック
  • タイムアウト・メモリ上限・ネットワーク制限を設定可

🧠 Semantic Kernel プラグイン

SK のプラグインシステムが MAF に統合。既存の SK コードを MAF エージェントのツールとして再利用可能。

  • プラグイン = 関数の集合（OpenAI Tool Format 準拠）
  • OpenAPI スペックから自動生成: KernelPlugin.from_openapi()
  • MCP サーバーから自動生成: KernelPlugin.from_mcp()
  • Semantic Function（プロンプトテンプレート）も継承

🔀 マルチエージェントパターン

MAF は5種類のオーケストレーションパターンを標準提供する。

🔗

Sequential

エージェント A → B → C の直列実行。前のエージェントの出力が次の入力になる。パイプライン処理に最適。

🌐

Concurrent

複数エージェントを並列起動。扇形（fan-out）でサブタスクを分散し、結果を集約（fan-in）。大規模調査・並列生成に最適。

🤝

Handoff

エージェントが「担当外」と判断した場合に別エージェントに転送。カスタマーサポートの部署振り分け等に最適。

💬

Group Chat

複数エージェントが同一スレッドで議論。SelectorGroupChat なら LLM が次の発言者を決定。コードレビュー・多角的分析に最適。

🔵

Magentic-One

汎用マルチエージェント実装。Orchestrator + FileSurfer + WebSurfer + Coder + ComputerTerminal の5エージェント構成。AutoBench II 最高スコア。

⚡ Magentic-One 詳細

Microsoft Research が設計した汎用マルチエージェントシステム。複雑な実世界タスクをエージェントチームで解決する。

5エージェントの役割:

  • Orchestrator: タスク分解・エージェント割り当て・進捗追跡
  • WebSurfer: ブラウザ操作・Web 検索・スクレイピング
  • FileSurfer: ファイル読み取り・PDF/Office 解析
  • Coder: コード生成・デバッグ・テスト実行
  • ComputerTerminal: シェル実行・システム操作

ベンチマーク結果（2026年6月）:

  • GAIA Benchmark Level 1: 72.3%
  • GAIA Benchmark Level 2: 51.8%
  • WebArena: 44.2%
  • AssistantBench: 38.7%
  • SWE-Bench（コード）: 45.1%（単体エージェントとして）

🔗 MCP + A2A プロトコル統合

🔧 MCP（Model Context Protocol）

Anthropic が設計したエージェント↔ツール標準プロトコル。MAF では KernelPlugin.from_mcp() で MCP サーバーをワンライン統合。

from autogen_ext.tools.mcp import MCPToolAdapter
from autogen_agentchat.agents import AssistantAgent

# MCP サーバーを自動接続
tools = await MCPToolAdapter.from_server(
    server_url="http://localhost:8000/mcp"
)

agent = AssistantAgent(
    name="researcher",
    model_client=model_client,
    tools=tools,
)
  • 5,000+ コミュニティ MCP サーバーを即利用
  • stdio / HTTP+SSE 両モード対応
  • ツール仕様を自動解析して JSON Schema 生成

🌐 A2A（Agent-to-Agent Protocol）

Google が主導する Agent ↔ Agent 通信標準。MAF は A2A v1.0 に完全対応。エージェントを A2A エンドポイントとして公開し、他フレームワークと相互接続できる。

from autogen_ext.interop.a2a import A2AServer

# MAF エージェントを A2A で公開
server = A2AServer(
    agent=my_agent,
    agent_card=AgentCard(
        name="Research Agent",
        capabilities={"streaming": True},
        authentication={"schemes": ["Bearer"]},
    )
)
await server.start(port=8080)
  • Agent Card を /.well-known/agent-card.json で自動公開
  • Salesforce / SAP / Google エージェントと相互接続
  • ストリーミング（SSE）+ Webhook 両対応
🔑 MAF が A2A + MCP 両対応の意味: MCP でツール（データベース、API、ファイル）を呼び出し、A2A で他ベンダーのエージェントと連携できる。これにより MAF エージェントは Microsoft エコシステムを超え、Google/Salesforce/SAP のエージェントと協業する「相互運用可能なエンタープライズ AI インフラ」になる。

🪟 Windows Agent Framework（WAF）

Microsoft Build 2026 主要発表: Satya Nadella 基調講演で「Windows is the new agentic operating system」と宣言。WAF v1.0 GA が同日発表された。

🖥️ WAF とは

Windows / Windows 365 / Azure Arc 上でエージェントが OS を直接操作できるようにするフレームワーク。UI Automation API・Win32・UWP・WinUI3・Web ブラウザを統一的に操作。

  • Computer Use: マウス・キーボード・スクリーン読み取り
  • App Control: Win32/UWP/PWA を起動・操作・閉じる
  • File System: NTFS ファイル操作（権限付き）
  • Windows Search: コンテキスト認識検索統合
  • Recall Integration: Windows Recall の AI 記憶活用

☁️ Windows 365 + Azure Arc

クラウド PC 上でエージェントを実行。物理デバイスを必要とせず、スケーラブルな「仮想デスクトップ操作エージェント」を構築できる。

  • Windows 365 Agentic: 仮想 Windows 環境でのエージェント実行（1セッション = 1 Cloud PC）
  • Azure Arc: ハイブリッド環境（オンプレ + クラウド）での一元管理
  • セキュリティ: Azure AD 認証 + Intune ポリシー準拠
  • 監査ログ: 全操作を Microsoft Purview に記録

WAF 実装例 — Excel 自動化エージェント

from autogen_ext.tools.windows import WindowsComputerTool
from autogen_agentchat.agents import AssistantAgent

# Windows Computer Use ツールを初期化
computer = WindowsComputerTool(
    screenshot_interval=0.5,
    click_delay=0.1,
    sandbox=True,  # Azure Container Instances でサンドボックス実行
)

excel_agent = AssistantAgent(
    name="excel_operator",
    model_client=azure_openai_client,
    tools=[computer],
    system_message="""
    あなたは Excel 操作の専門エージェントです。
    Computer Use ツールを使って実際の Excel アプリを操作します。
    """
)

# タスク: 売上データを集計してグラフ作成
result = await excel_agent.run(
    task="売上データ.xlsx を開いて月別集計表を作成し、棒グラフを追加してください"
)
⚠️ WAF セキュリティ設計原則: エージェントは最小権限原則に基づき動作。実行前に「実行する操作の一覧」をユーザーに提示し承認を取る「Human-in-the-Loop ゲート」がデフォルトで有効。Purview への監査ログ記録は Azure Government / FedRAMP 環境では必須。

💻 コード実装例

基本: AssistantAgent + ツール使用（Python）

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.messages import TextMessage
from autogen_ext.models.openai import AzureOpenAIChatCompletionClient
from autogen_ext.tools.mcp import MCPToolAdapter

async def main():
    # Azure OpenAI クライアント
    model_client = AzureOpenAIChatCompletionClient(
        azure_deployment="gpt-4o",
        api_version="2025-01-01-preview",
        azure_endpoint="https://YOUR-ENDPOINT.openai.azure.com/",
        # Managed Identity 推奨（API Key 不要）
    )

    # MCP サーバーからツールを自動取得
    tools = await MCPToolAdapter.from_server("http://localhost:8000/mcp")

    agent = AssistantAgent(
        name="research_agent",
        model_client=model_client,
        tools=tools,
        system_message="あなたは調査専門エージェントです。",
    )

    response = await agent.on_messages(
        [TextMessage(content="MAF v1.0 の主要機能を調べてください", source="user")],
        cancellation_token=None,
    )
    print(response.chat_message.content)

asyncio.run(main())

マルチエージェント: グループチャット（コードレビュー）

from autogen_agentchat.teams import SelectorGroupChat
from autogen_agentchat.conditions import TextMentionTermination

# 3エージェント定義
coder = AssistantAgent(
    name="coder", model_client=model_client,
    system_message="Pythonコードを書く専門家です。コーディングタスクを担当します。"
)
reviewer = AssistantAgent(
    name="code_reviewer", model_client=model_client,
    system_message="コードレビューの専門家です。セキュリティ・可読性・パフォーマンスをチェックします。"
)
tester = AssistantAgent(
    name="tester", model_client=model_client, tools=[code_exec_tool],
    system_message="テストエンジニアです。コードを実行してバグを発見します。"
)

# APPROVE という言葉で終了
termination = TextMentionTermination("APPROVE")

# LLM が次の発言者を選択するグループチャット
team = SelectorGroupChat(
    participants=[coder, reviewer, tester],
    model_client=model_client,
    termination_condition=termination,
)

result = await team.run(
    task="非同期 Web スクレイパーを実装し、コードレビューとテストを完了してください"
)
print(result.messages[-1].content)

C# / .NET 実装例

using Microsoft.AgentFramework;
using Microsoft.AgentFramework.Agents;
using Microsoft.AgentFramework.Teams;
using Microsoft.SemanticKernel;

// Semantic Kernel と MAF を統合
var kernel = Kernel.CreateBuilder()
    .AddAzureOpenAIChatCompletion("gpt-4o", endpoint, credential)
    .Build();

// MAF エージェントに SK プラグインを注入
var agent = new AssistantAgent("assistant")
{
    ModelClient = kernel.GetRequiredService<IChatCompletionService>(),
    Tools = kernel.Plugins.SelectMany(p => p.GetFunctionsMetadata()),
    SystemMessage = "あなたは Azure 専門のエージェントです。"
};

// Handoff パターン: 専門エージェントに転送
var orchestrator = new HandoffOrchestrator([
    ("Azure support", azureAgent),
    ("Billing", billingAgent),
    ("Security", securityAgent),
]);

var result = await orchestrator.RunAsync("Azure OpenAI のクォータを増やしたい");

インストール

# Python（推奨: 3.11+）
pip install autogen-agentchat autogen-ext[azure,mcp,a2a]

# .NET 8+
dotnet add package Microsoft.AgentFramework
dotnet add package Microsoft.AgentFramework.Azure
dotnet add package Microsoft.AgentFramework.MCP

5分で動かす — 最小実装

import asyncio, os
from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.messages import TextMessage
from autogen_ext.models.openai import OpenAIChatCompletionClient

async def main():
    client = OpenAIChatCompletionClient(
        model="gpt-4o",
        api_key=os.environ["OPENAI_API_KEY"]
    )
    agent = AssistantAgent("assistant", model_client=client)
    resp = await agent.on_messages(
        [TextMessage(content="MAFとは何ですか？", source="user")],
        cancellation_token=None
    )
    print(resp.chat_message.content)

asyncio.run(main())
