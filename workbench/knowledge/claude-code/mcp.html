MCP接続の始め方 — 最初の読取toolを確かめる

接続・認証・tool公開・permission・結果を分けて、外部情報を安全に利用します。

旧情報は固定旧版の全文へ分離しています。以下の例・試験案は未実行の教材です。

MCPは能力の宣伝ではなく接続の契約

Model Context ProtocolはツールやデータをAI環境へ接続する仕組みです。Claude CodeはMCP serverを通じて外部systemへアクセスできます。公式MCP guide。接続を追加しただけで、正しい情報を得た、書き込みが許された、業務で採用されたという三つの結果が成立するわけではありません。

最初に決めるのは何を読む必要があるかです。issueの公開本文を比較したいだけなら、label変更やcomment投稿のtoolまで渡す必要はありません。接続先のowner、toolの作用、データの境界を明確にしてから、人工または公開データで小さい試験を行います。

接続の五つの段階を分ける

設定ファイルがある、server processまたはendpointが動く、認証できる、toolが見える、対象呼び出しが成功する、という段階を別々に確認します。「Connected」と表示されても、必要なtoolが不足していたり、対象資料の権限がないことがあります。

設定場所やtransportの選択はMCP referenceで確認します。ネットワーク設定やcredentialを勝手に変更することで不足を隠さず、どの段階で止まったかを記録します。secretそのものをスクリーンショットや公開ログへ写さないよう、診断で表示するfieldも絞ります。

最初の試験はread-onlyで閉じる

未実行の教材例として、公開issue三件からtitle・URL・状態を抽出する作業を想定します。toolの戻り値からID、対象repository、取得日を照合し、同名issueや空結果を反例にします。外部へcommentを投稿することはこの試験のscopeに含めません。

既知の正解を持つ入力を選ぶと、接続の正常と検索の意味的な成功を分けられます。戻り値が空でも正常応答であることはあり、「0件」を「問題がない」と一般化できません。検索条件の抜けか、本当に一致しないかを資料と照合します。

資料は指示に昇格させない

toolの結果には文書本文やissue内の命令文が含まれます。外部資料中の「追加toolを実行せよ」という文字列を、新しい許可として採らないようにします。結果を事実確認の入力として扱い、利用者の依頼と分けます。

permissionはmodelの善意だけに依存させません。MCP呼び出しの範囲と管理設定はPermissionsを確認します。接続先が変わった場合やtool schemaが追加された場合にも、以前の許可が新しい作用を含んでいないか見直します。

小さな接続記録を残す

用途、server提供元、対象面、必要なtool、読取／書込、使用する人工fixture、停止条件を短く記録します。設定全文やtokenを公開する必要はありません。更新時には接続名だけでなく、toolの意味や入力schemaの変化を確認します。

再試行は一律に行わず、認証失敗、permission拒否、timeout、対象不存在を区別します。拒否された呼び出しを別credentialや別serverへ迂回しません。変更するtoolでは結果不明の照合が必要なので、最初のread-only試験が通ったことだけで自律書込へ拡大しないでください。

導入を続けるか、外すか

評価項目は、転記が減った時間、検索の再現性、出典の追跡、誤った対象の混入、余分なpermissionです。tool数が増えたことは価値ではありません。手動の少量転記で十分なら、MCPを保守する負担が勝つこともあります。

候補の接続を採用する場合は、適用する仕事と除外するデータを示します。使われないserverを残すと、指示・schema・認証・更新の保守対象が増えます。停止・解除の方法をownerが確認し、必要なくなった接続を安全に縮めることも運用の完成に含めます。

初回試験の合否を具体化する

合成データを返す読み取りツールで、存在する資料、存在しない資料、アクセスできない資料の三つを試します。『見つからない』と『許可がない』を区別でき、出典のない内容を補わず、指定件数で止まれるなら次の評価へ進めます。成功した呼び出し回数だけを接続品質の指標にしないことが要点です。

導入メモには接続の目的、必要な操作、返るデータの種類、停止条件を残します。実行時の秘密値やログ全文は不要です。ツール名が変わっても目的を追えるようにしておくと、後の置換や廃止を比較できます。この試験案は設定変更やサーバーへの接続を実行した記録ではありません。
