🔴 Claude / Anthropic

更新Claude Code 2.1.207：Auto ModeがBedrock・Vertex AI・Foundryでオプトイン不要に

Claude CodeがVersion 2.1.207にアップデート。これまでオプトインが必要だった自律実行の「Auto Mode」がAmazon Bedrock・Google Vertex AI・Microsoft Foundry経由でも標準有効化され、設定から無効化も可能になった。長いリスト・テーブル・コードブロックのストリーミング中にターミナルがフリーズする不具合や、システム生成の更新通知をプロンプトインジェクションと誤検知する不具合も修正された。

Source: Claude Code Changelog (GitHub)

拡大Claude、Microsoft 365への書き込み機能を全プランに展開 — メール送信・予定表操作・OneDrive/SharePointファイル編集に対応

AnthropicはMicrosoft 365コネクタの「書き込みツール」をFree・Pro・Max・Team・Enterprise全プランに拡大。組織管理者が有効化すると、Claudeがメールの下書き・送信・整理、予定表の作成・変更・削除、OneDrive/SharePoint上のファイル作成・更新を代行できるようになる。送信メールにはエージェント起因を示すヘッダーが自動付与され、添付ファイル付きメッセージは処理対象外とする安全策も講じられている。

Source: Claude Help Center, UC Today

🟠 中国系LLM

拡大Moonshot AI「Kimi K2.7 Code」、GitHub Copilot Business・Enterpriseプランでも利用可能に

7月初旬にCopilot Pro/Pro+/Max向けに提供開始されたオープンウェイトのエージェント型コーディングモデル「Kimi K2.7 Code」が、7月7日付でCopilot Business・Enterpriseプランにも展開された。MoEアーキテクチャ・1兆パラメータ・256Kコンテキストで、前世代K2.6比で推論トークンを30%削減しつつコーディングベンチマークで大幅な性能向上を実現している。

Source: GitHub Changelog

新モデルMiniMax、オープンウェイト「M3」を公開 — 推論とエージェント機能を統合、1Mトークンコンテキスト・Opus比出力単価20分の1

MiniMaxが新モデル「M3」を公開。428BパラメータのMoE構成（アクティブ23B）に新開発の疎注意機構「MiniMax Sparse Attention」を採用し、最大100万トークンのコンテキスト窓とネイティブなマルチモーダル対応を実現した。SWE-Bench Proで59.0%を記録し、Opus 4.8比で出力トークン単価が約20分の1という価格優位性も打ち出している。

Source: MarkTechPost, MiniMax

🟡 音楽生成AI

新機能Suno、歌詞の一貫性を保つ「Lyricist」・自然言語での歌詞編集など制作機能を追加

AI音楽生成のSunoが7月9日、楽曲制作を強化する新機能群を公開。過去の歌詞例を登録して作風を保持できる「Lyricist」、会話形式で歌詞を直接編集できる自然言語編集、バリエーション生成、フルスクリーンエディタ、曲構成ラベル表示、自動保存などが追加され、より実務的な作曲ワークフローに対応した。

Source: Suno Release Notes
