四半期ルーティン

リンクチェッカー

全 HTML ページの内部リンク切れを自動検出する。スクリプト: tools/link-checker.py。所要時間: 約 1〜2 分。

最終更新: 2026-05-31 | 実施頻度: 四半期に 1 回 / 大きな構造変更後

基本的な実行方法

1

Hub ルートへ移動

cd /path/to/claude # git リポジトリのルート
2

標準チェック（ターミナル出力）

python3 tools/link-checker.py

全 HTML ファイルをスキャンし、切れているリンクをターミナルに表示する。

3

HTML レポートを生成（推奨）

python3 tools/link-checker.py --html

logs/link-check-YYYY-MM-DD.html に見やすいレポートを出力する。ブラウザで開いて確認できる。

4

切れリンクを修正してコミット

# 切れリンクを修正後: git add -A git commit -m "Fix broken links — $(date +%Y-%m-%d)" git push

オプション一覧

オプション効果推奨場面
--htmllogs/link-check-DATE.html を生成定期チェック・記録保存
--jsonJSON 形式で結果を stdout に出力CI / 自動化パイプライン
--external外部 URL（http/https）もチェック年次の全リンク確認
[root]チェック対象ルートを指定（デフォルト: .）特定カテゴリのみ確認

実行例

# creator-system のみチェック python3 tools/link-checker.py creator-system # 外部URLも含めた完全チェック + HTMLレポート python3 tools/link-checker.py --html --external # JSON 出力（CI 用） python3 tools/link-checker.py --json 2>/dev/null | jq '.broken | length'

Claude への依頼テンプレート

# スマホから送る場合の指示文 「link-checker.py を実行して切れているリンクを修正してください。 手順: 1. python3 tools/link-checker.py --html を実行 2. 切れリンクを確認して修正 3. 変更をコミット・プッシュ」
ポイント: Claude に実行させる場合は --html オプションを指定するとレポートが logs/ に保存されて次回参照しやすい。

出力の読み方と対処方針

🔴 切れているリンク

ファイルが存在しないリンク。対処法:

  • ページが移動した → リンクを新しいパスに更新
  • ページを削除した → リンクを削除 or 最も近いページへ差し替え
  • 誤字 → リンクを修正

🟡 警告

ルート外に解決されるリンク（CDN 等）。基本的に無視してよい。ローカルの相対パスが誤っている場合のみ修正が必要。

削除より退避を優先: ページを削除する前に ADR に記録し、内部リンクをアーカイブページへ更新する。詳細は operating-principles.html 参照。

スクリプトの仕組み

  • 対象: リポジトリ内の全 .html ファイル（.git/・node_modules/ を除く）
  • チェック対象リンク: href=・src=・action= 属性（javascript:・mailto:・data: は除外）
  • 外部 URL: デフォルトはスキップ（--external で有効化）
  • アンカー: 同一ページ内リンク（#section）はスキップ
  • ディレクトリリンク: href="foo/" は foo/index.html の存在確認にフォールバック
  • 出力: ターミナル（常時）+ HTML レポート（--html 時）+ JSON（--json 時）
