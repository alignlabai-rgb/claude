2. Power Automate + AI Builder — 最重要製品の全機能解説

Power Automate は Power Platform の 自動化エンジン です。クラウドフロー・デスクトップフロー（RPA）・プロセスマイニングの3軸で構成され、2026年の Release Wave 1 では AI エージェントによるフロー自律生成・自己修復（Self-Healing） 機能が追加されました。

フローの種類
クラウドフロー

クラウドサービス連携

  • API ベースのクラウド間自動化
  • トリガー: メール受信・フォーム送信・ファイル変更・スケジュール等
  • 1,000+ コネクタ（Salesforce・SAP・ServiceNow・Slack・Gmail）
  • Copilot Studio Agent から呼び出すフローとして利用
  • 条件分岐・ループ・並列実行・エラーハンドリング対応
デスクトップフロー（RPA）

レガシーシステム自動化

  • Power Automate Desktop で PC 操作を録画・実行
  • SAP GUI・レガシー基幹システム・Excel 操作を自動化
  • 有人（Attended）/ 無人（Unattended）両対応
  • 2026年: AI エージェントがフロー異常を検知し自己修復
  • Process $150/bot/month でボット実行
プロセスマイニング

業務プロセス可視化

  • システムログからプロセスを自動抽出・可視化
  • Object-Centric Process Mining（OCPM）が 2026 年 GA
  • 一つのイベントが複数オブジェクト（受注・請求書・配送）に属する構造を分析
  • ボトルネック・非効率工程を自動検出
  • 改善案を AI が提案
Copilot でフロー自然言語生成

フロー設計画面の Copilot チャット欄に業務要件を自然言語で入力するだけで、完全なクラウドフローが自動生成されます。「When X happens, do Y」 形式で書くと精度が高まります。

自然言語プロンプト例:
  • 「メールで PDF 添付の請求書が届いたら、AI Builder で金額・取引先を抽出して SharePoint に保存し、上長に Teams 承認通知を送って」
  • 「毎週月曜 9:00 に Salesforce から先週の商談データを取得し Power BI データセットを更新して」
  • 「フォームが送信されたら Dataverse に登録し、5万円以上なら部長に、10万円以上なら役員に承認フローを回して」

Copilot はプロンプトから意図を解釈し、必要なコネクタへの接続を自動セットアップし、アクションのパラメータも自動入力します。フロー生成後も「このアクションを差し替えて」「Teams ではなくメールで通知して」と追加チャットで修正できます。

// Power Automate フロー（JSON 定義の概念例）
{
  "trigger": {
    "type": "When a new email arrives",
    "filter": "hasAttachment eq true AND subject contains '請求書'"
  },
  "actions": [
    {
      "name": "AI Builder - 請求書を処理する",
      "model": "prebuilt-invoice-processing",
      "input": "@triggerOutputs()?['body/attachments'][0]"
    },
    {
      "name": "Dataverse - 行を追加する",
      "table": "cr_invoices",
      "fields": {
        "vendor": "@outputs('AI_Builder')?['vendorName']",
        "amount": "@outputs('AI_Builder')?['totalAmount']",
        "invoiceDate": "@outputs('AI_Builder')?['invoiceDate']"
      }
    },
    {
      "name": "Teams - 承認を開始する",
      "assignTo": "manager@contoso.com",
      "title": "請求書承認: @{outputs('AI_Builder')?['vendorName']}"
    }
  ]
}

3. Power Apps + Copilot — 自然言語でアプリ生成

自然言語アプリ生成のプロンプト例:
  • 「在庫管理アプリを作って。品目・数量・保管場所・最終更新日を管理したい」

→ Copilot が Dataverse テーブル・関係性・カラム型・ビジネスルール・サンプルデータを自動設計し、画面・ナビゲーション・ギャラリー・編集フォームを生成します。

4. Power BI + Copilot — データを語らせる AI アナリスト

Power BI Copilot は レポート作成・DAX 数式生成・自然言語によるデータ質問・ナラティブ要約の4領域で AI を提供します。2026年時点で企業展開済みのチームでは「DAX 作成だけで週2〜3時間の削減」が報告されています。

DAX 生成

数式を自然言語で作成

  • 「先月比成長率を計算して」→ 構文的に正しい DAX を即生成
  • フィルターコンテキストを自動で考慮
  • 時系列インテリジェンス関数（SAMEPERIODLASTYEAR 等）を適切に適用
  • 生成した数式の論理説明も自動付与
  • 非エンジニアが複雑なメジャーを定義可能に
Narrative Summaries

データを文章で自動解説

  • レポートページ全体・特定ページ・個別ビジュアルを要約
  • トレンド・外れ値・異常・主要ドライバーを平文で説明
  • フィルター・スライサー操作に連動して動的に更新
  • 経営向けスライドのナラティブを自動作成
  • 月次 / 週次レポートの所見コメントを Copilot が執筆
Q&A / Copilot チャット

グラフに自然言語で質問

  • 「東京の先月の売上は？」→ 数値をピンポイント回答
  • 曖昧な質問に対して AI が意図を確認・補完
  • 回答のソースビジュアルを参照として提示
  • フィールド名を正確に知らなくても業務文脈で解釈
  • BI の非技術者への民主化を実現
異常検知・スマートナラティブ

異常を自動フラグ

  • 時系列データの外れ値を自動検出・アラート
  • スマートナラティブ: ビジュアルにテキスト解説を自動追加
  • Key Influencers ビジュアル: 指標に影響する要因を AI が特定
  • Decomposition Tree: 指標をドリルダウン分析

Microsoft Fabric との統合（2026年）: Power BI Premium は Microsoft Fabric の一部として位置づけられ、OneLake（統合データレイク）上のデータを直接 Power BI レポートで参照できます。Copilot は Fabric のセマンティックモデルを理解した上で DAX・レポート・要約を生成します。

-- Copilot が生成した DAX 例（「前年同月比成長率」）
YoY Growth Rate =
VAR CurrentPeriodSales = [Total Sales]
VAR PriorYearSales =
    CALCULATE(
        [Total Sales],
        SAMEPERIODLASTYEAR('Date'[Date])
    )
RETURN
    IF(
        PriorYearSales = 0 || ISBLANK(PriorYearSales),
        BLANK(),
        DIVIDE(CurrentPeriodSales - PriorYearSales, PriorYearSales)
    )

8. 業種別・部署別 実例 12選

製造業 / 現場

設備点検フォームの完全自動化

現場作業員が Power Apps モバイルアプリで点検写真を撮影。AI Builder の Object Detection が異常を即判定し、異常検知時は Power Automate が自動で修繕依頼を作成・担当者へ Teams 通知。報告書作成時間が 45分 → 5分、異常の見落とし率がゼロに。

法務 / 契約

契約書自動抽出・リスクレビュー

取引先から届く PDF 契約書を AI Builder GPT-4o Prompt で主要条項・期日・金額を自動抽出し Dataverse に登録。異常条項は弁護士へ自動エスカレーション。初回レビュー時間が 2時間 → 20分、月間50件以上の契約処理を2名で対応可能に。

HR / 採用

採用フロー一気通貫自動化

Power Pages で外部向け応募フォームを構築。応募データが自動で Dataverse に登録され、Power Automate が書類選考・面接調整・合否通知・入社手続きまで自動ルーティング。採用事務工数が 60% 削減、担当者は応募者対応に集中できるように。

営業担当が Teams の商談チャンネルでメモを書くと、Power Automate が AI Builder で要点を抽出し Salesforce の商談レコードを自動更新。次のアクションも AI が提案し、ToDoリストに自動追加。CRM 入力工数が週 3時間 → 0.5時間。

問い合わせ自動分類・エスカレーション

メール・フォームで届く顧客問い合わせを AI Builder GPT Prompt が製品種別・緊急度・感情スコアで自動分類。緊急 / 怒り案件は即エスカレーション、通常案件は担当者キューへ自動振り分け。初回応答時間が平均 4時間 → 30分。

医療 / クリニック

患者フォーム処理のデジタル化

12. はじめ方 — 最短ルート

Step 1

無料トライアルで試す

  • Microsoft 365 アカウントがあれば Power Automate・Power Apps の基本機能は即利用可能
  • make.powerautomate.com でフロー作成開始
  • make.powerapps.com でアプリ作成開始
  • AI Builder 30日間トライアルあり
Step 2

Copilot でフロー生成

  • Power Automate を開いて「作成」→「Copilot で作成」を選択
  • 「メールで請求書が届いたら承認フローを走らせて」と入力
  • 生成されたフローを確認・微調整して保存
  • まず小さな業務で成功体験を作る
Step 3

AI Builder を組み込む

  • フローに「AI Builder — 請求書を処理する」アクションを追加
  • 事前構築モデルはトレーニング不要で即利用
  • カスタムモデルは 5〜20枚のサンプルで学習開始
  • GPT Prompt で要約・分類・翻訳を追加
Step 4

Power Apps でアプリ化

  • Copilot に「在庫管理アプリを作って」と入力
  • 生成された Dataverse テーブルとアプリを確認
  • モバイルで動作確認 → 組織内に共有
  • Power BI でデータを可視化して経営ダッシュボードへ

学習リソース: Microsoft Learn（learn.microsoft.com/power-platform）の Power Platform ラーニングパスが無料で充実しています。また Power Platform Community（community.powerplatform.com）では実際のユースケース・テンプレート・Q&A が活発に共有されています。
