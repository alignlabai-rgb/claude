IMPORTANT BOUNDARY

動画をローカル保存した ≠ ローカル推論した

MiniMaxのCLI・MCP・desktop clientから生成を開始し、出力がMacへ保存されても、remote APIを呼んでいれば推論本体はローカルではありません。ローカル推論を名乗るには、weights、inference process、network状態、hardware envelope、runtime receiptを同時に確認します。

2026-07-31 RELEASE

MiniMax H3 — omni-modal generation

  • text・image・video・audio contextを受け、複数mediaを生成するgeneral-purpose omni-modal model。
  • videoはnative stereo audio、最大2K、最大15秒と公式releaseに記載。
  • 公式はopen modelとしていますが、具体的なlicense・weights・runtime条件は対象artifactごとに確認します。

MiniMax M3 — LLM

API CATALOG

M2.7 / M2.5 — text API

  • API overviewはM2.7、M2.7-highspeed、M2.5系列をtext generation modelとして掲載。
  • catalog上のcontextは204,800。M3の1Mと同じ設定を流用しません。
  • OpenAI-compatible / Anthropic-compatible surfaceは便利ですが、tool schemaとserver-side toolsの同等性を仮定しません。

VIDEO FAMILY

Hailuo 2.3 — video API family

  • API overviewはMiniMax-Hailuo-2.3とFastを動画生成familyとして掲載。H3公開後もAPI catalog上の別surfaceです。
  • M3というLLMのopen weightsは、Hailuo video modelのlocal weightsを意味しません。
  • text-to-video / image-to-videoは非同期task API。file downloadはinference locationの証明になりません。
