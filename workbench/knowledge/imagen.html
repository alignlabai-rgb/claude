2. Imagen 4 の主要機能

フォトリアリズム

人物・風景・物体の質感と光源表現が Imagen 3 比で大幅向上。プロ写真品質の出力が可能になり、商業撮影の代替として活用が広がっている。

テキスト描写

画像内に鮮明で読みやすいテキストを描写。ポスター・バナー・ブランドロゴを含む制作物に最適。Imagen 3 の最大の弱点を克服した改善点。

SynthID 透かし

全出力に知覚不可能な電子透かしを自動付与。AI 生成コンテンツの追跡・認証に対応。ダウンロード・加工後も透かしが保持される。

多言語プロンプト

英語・日本語・中国語（簡/繁）・ヒンディー語・韓国語・ポルトガル語・スペイン語の8言語に対応。日本語でそのまま指示可能。

Flow Ingredients 連携

Imagen 4 Ultra で生成したキャラクター画像を Flow の Ingredients 機能に登録。Veo 3.1 で複数ショットを生成する際に一貫した外見を維持できる。

Google Workspace 統合

Google Docs・Slides・Vids に直接統合。アプリを切り替えずに文書内で画像を生成・挿入。法人ユーザーは Workspace プランに含まれる形で利用可能。

3. Whisk — 2026年4月30日 サービス終了 → Flow に統合

🚨 Whisk は 2026年4月30日をもってシャットダウンされました。 全機能は Google Flow に統合済みです。既存のWhisk ライブラリは移行期間（〜4/30）を過ぎると自動削除されました。新規の Whisk 利用はできません。

統合の経緯: 2026年2月25日に Google が Flow・Whisk・ImageFX の統合を発表。Flow が唯一の統合クリエイティブスタジオとして、Whisk の画像リミックス機能・ImageFX（Nano Banana）の画像生成機能を取り込みました。

Whisk が持っていた機能

  • 「被写体」「シーン」「スタイル」3枚の参照画像を入力して新画像を生成
  • テキストプロンプト不要の直感的リミックス
  • コンセプトアート・スタイル転送に活用
  • labs.google.com/whisk でアクセス可能だった

Flow で代替する方法

  • Flow の「Ingredients（素材）」機能で参照画像をアップロード
  • Subject / Style 参照として画像を指定してから生成
  • ただし Whisk の3パネル UI（被写体/シーン/スタイル同時指定）は廃止
  • 詳細は flow.html を参照

⚠️ 旧 Whisk の「Subject / Scene / Style 同時指定」という専用ワークフローは Flow には移植されていません。Flow での参照画像指定は可能ですが、Whisk 固有の3パネル体験は失われました。

5. 実践ワークフロー & Python コード例

① YouTube サムネイル量産パイプライン

Gemini Pro でサムネイルコピーを10案生成 → Imagen 4 Fast でビジュアル案を並列生成（1枚0.02ドル × 10 = 0.2ドル）→ 最良案を Imagen 4 Standard でブラッシュアップ → ImageFX で最終調整。所要コスト1ドル以下、所要時間15分以内。

② キャラクター素材 → Flow 動画化パイプライン

Gemini でキャラクター設定からプロンプト生成 → Imagen 4 Ultra でキャラクターシート生成（$0.06）→ Flow の Ingredients に登録 → Veo 3.1 Fast で複数ショットを生成（20 credits/本）→ Scenebuilder でタイムライン編集。詳細は flow.html。

③ Vertex AI Python SDK — バッチ画像生成

# pip install google-cloud-aiplatform
import vertexai
from vertexai.vision_models import ImageGenerationModel

vertexai.init(project="YOUR_PROJECT_ID", location="us-central1")

# Fast (量産): imagen-4.0-fast-generate-001
# Standard:    imagen-4.0-generate-001
# Ultra:        imagen-4.0-ultra-generate-001
model = ImageGenerationModel.from_pretrained("imagen-4.0-fast-generate-001")

response = model.generate_images(
    prompt="A sleek product photo of wireless earbuds on a marble surface, "
           "studio lighting, white background, 8K quality",
    number_of_images=4,
    aspect_ratio="1:1",       # "1:1" / "16:9" / "9:16" / "4:3" / "3:4"
    safety_filter_level="block_some",
    person_generation="allow_adult",
)

for i, img in enumerate(response.images):
    img.save(f"output_{i}.png")
    print(f"Saved output_{i}.png")

④ Gemini API (google-generativeai) 経由

# pip install google-generativeai
import google.generativeai as genai
from google.generativeai import types

genai.configure(api_key="YOUR_API_KEY")

response = genai.generate_images(
    model="imagen-4.0-generate-001",
    prompt="Minimalist Japanese cafe interior, warm afternoon light, "
           "film photography style, 35mm, bokeh",
    config=types.GenerateImagesConfig(
        number_of_images=2,
        aspect_ratio="16:9",
        output_mime_type="image/jpeg",
    ),
)

for i, img in enumerate(response.generated_images):
    with open(f"cafe_{i}.jpg", "wb") as f:
        f.write(img.image.image_bytes)
    print(f"Saved cafe_{i}.jpg")

8. プロンプトガイド

Imagen 4 は英語プロンプトで最高精度を発揮するが、日本語でも高品質な出力が可能。以下の5要素フレームワークを意識する。

要素説明英語例
① 被写体何が/誰が写っているかA Japanese woman in her 30s sitting in a cafe
② スタイル画風・媒体・時代感cinematic still, film grain, 35mm photography
③ 照明光源・時間帯・雰囲気natural window light, golden hour, soft shadows
④ 構図画角・視点・フォーカスbust shot, rule of thirds, shallow depth of field
⑤ 品質修飾解像度・制作クレジット8K, ultra-detailed, award-winning photography
❌ 避けるべき✅ 推奨
「きれいな画像を作って」「商品写真, 白背景, スタジオ照明, 8K, product photography, minimalist」
「人を描いて」「30代アジア系男性, ビジネスカジュアル, オフィス, 自然光, portrait, Sony A7IV」
テキスト無指定画像内テキストはダブルクォートで囲む: "SALE 50% OFF"
長い文章形式コンマ区切りのキーワード形式が安定して効果的

💡 日本語プロンプトのコツ: 感情・雰囲気・シチュエーションは日本語で直接指示しても機能する。ただしスタイル指定（「映画的」→ cinematic / 「水彩画風」→ watercolor style）は英語のほうが精度が高い傾向。

9. Google エコシステムとの連携

🎬 Imagen 4 → Flow パイプライン: Imagen 4 Ultra でキャラクター/素材画像を生成 → Flow の Ingredients 機能に登録 → Veo 3.1 で一貫したキャラクターが登場する動画を生成。静止画から映像まで一気通貫の Google 制作スタック。詳細は flow.html と veo.html。

🛠 AI Studio → Vertex AI 移行フロー: Google AI Studio で無料プロトタイプ → コードエクスポート → Vertex AI で本番スケール。Imagen 4 はこのフローをそのまま使える。詳細は ai-studio.html。

🚨 Whisk は 2026/04/30 終了・Flow に統合: 旧 Whisk の参照画像リミックス機能は Flow の Ingredients 機能で代替可能。詳細は flow.html を参照。
