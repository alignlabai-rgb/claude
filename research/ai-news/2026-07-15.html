🔴 Claude / Anthropic

延長Claude Fable 5、無料アクセスを7月19日まで再延長 — 今週2度目の措置

AnthropicはPro・Max・Team等の加入者向けに、Claude Fable 5を追加費用なしで利用できる期間を7月19日まで再延長すると発表した。7月7日の一週間限定プロモーションに続く今週2度目の延長で、OpenAIの新モデル投入への対応とみられている。7月20日以降は入力$10／出力$50（100万トークンあたり）の従量課金クレジット制に移行する予定で、容量が許し次第サブスクへの復帰を目指すとしている。

Source: Forbes, Dataconomy

🔴 OpenClaw / Hermes Agent

更新OpenClaw、v2026.7.1-beta.6を7月13日リリース — セキュリティ境界強化とClaude Sonnet 5・GPT-5.6対応

OpenClawがベータ版v2026.7.1-beta.6を公開。会話形式のオンボーディング、Gatewayルーティング・クォータ強化、Control UI刷新に加え、トランスクリプト・サンドボックスバインド・MCP stdio・Codex HTTPアクセスなど広範囲でセキュリティ境界を強化した。新規セットアップのデフォルトモデルをGPT-5.6とし、Claude Sonnet 5・Mythos 5、Meta Muse Spark 1.1、新ルーター「ClawRouter」にも対応している。

Source: OpenClaw Release Notes

🟠 GPT / OpenAI / Codex

新機能OpenAI、GPT-5.6搭載の「ChatGPT Work」を提供開始 — Plus/Pro/Businessは5時間利用上限を一時撤廃

OpenAIはチーム内の各種ツールを横断して情報をまとめる新機能「ChatGPT Work」をGPT-5.6ベースで公開し、デスクトップ版から順次展開を開始した。あわせてPlus・Pro・Business向けの5時間ごとの利用上限を一時的に撤廃し、週間上限のみとする措置も実施。Codexアプリでは、Webサイトやダッシュボード、簡易アプリを作成・公開できる新機能「Sites」のプレビュー提供も始まった。

Source: OpenAI Release Notes

🟠 Grok / xAI

強化xAI「Grok Build」、利用量・コスト管理機能とAPIキーセッション向けVoiceモードを追加

xAIが開発者向けツール「Grok Build」を7月12日にアップデートし、利用量・コストの詳細トラッキング、APIキーセッションでのVoiceモード、トランスクリプト編集・スクロールバックの改善、エージェント・MCP連携の安定化を実施した。7月8日投入の新モデル「Grok 4.5」に続く開発者体験の強化となる。

Source: xAI Release Notes

🟠 中国系LLM

規制対応ByteDance「Doubao」・Alibaba「Qwen」、7月15日付でAIコンパニオン機能を停止

中国のAI擬人化対話サービスに関する新規制に対応し、ByteDanceは看板アプリ「Doubao」のカスタムAIペルソナ作成機能を7月15日に停止する。Alibabaも「Qwen」の人間らしい対話エージェント・ユーザー作成エージェント機能を段階的に停止し、7月15日には関連サービス全体をオフラインにする。Doubaoは設定・履歴への読み取り専用アクセスを10月15日まで維持するが、Qwen側は代替の移行策を示していない。

Source: Bloomberg, SCMP, TechTimes
