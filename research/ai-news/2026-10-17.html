Claude CodeClaude Code 2.1.302：fork subagents が既定で有効、auto mode 分類器のモデルを指定可能に

CLAUDE_CODE_AUTO_MODE_MODEL でクライアント側 auto mode 分類器のモデルを選べる（サーバー側 auto mode は変わらない）。fork subagents は claude -p・Agent SDK・デスクトップアプリ・VS Code で既定オン（CLAUDE_CODE_FORK_SUBAGENT=0 で無効化）。デスクトップ／VS Code ではメイン会話の subagent が常にバックグラウンド実行になる。サードパーティプロバイダ上で権限モード未指定の claude -p／Agent SDK は default で開始する（telemetry 無効または新規インストールを除く）。128 MB 超の画像は Read ツールが拒否。Windows の exFAT/FAT32 書き込み修正、多数プラグイン時の起動高速化、クラウドセッションの routine ページに「実行されなかった理由」バナーを追加。自動化パイプラインで subagent の挙動が変わるため、既存スクリプトの確認が必要。GitHub 上のリリース日は10/16、10/16号には未掲載だったため報道日の本日に掲載（ノートは一部切れており、全項目は未確認）。
