🔴 Claude Code / API

更新Claude Code v2.1.292：Agentツールに effort パラメータ、プラグイン導入に --marketplace を追加

`claude plugin install` に `--marketplace ` を追加し、Agentツールで推論の努力度（effort）を指定可能に。529エラー時のリトライ間隔を延ばす `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` も追加。セキュリティ修正として、PreToolUseフックと自動モードがUNCネットワークパスのファイル読み取りで権限確認を迂回する問題を修正。`NO_PROXY` が無視される問題や、128文字超のMCPツール名で全リクエストが失敗する問題も修正された。

Source: GitHub anthropics/claude-code releases（2026-10-06）

更新Claude Code v2.1.291：クラウドセッションの権限プロンプト回答欠落を修正

v2.1.290で入った退行により、クラウドセッションで権限プロンプトへの回答が落ちる問題を修正。v2.1.288由来の「終了時にセッション末尾のメッセージが失われる」退行も修正。Routinesなどクラウド実行を使う運用では更新推奨。

Source: GitHub anthropics/claude-code releases（2026-10-06）

APIClaude Models API に server_tools 能力情報が追加

`GET /v1/models` と `GET /v1/models/{model_id}` が `capabilities.server_tools` を返し、各モデルがWeb検索・コード実行ツールに対応するかを判別できるようになった。前日には `capabilities.thinking.types.disabled`（thinking無効化の可否）も追加されており、モデル切替時の互換チェックをコードで自動化しやすくなる。

Source: Claude Platform Release Notes（2026-10-06）
