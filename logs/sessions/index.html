セッションログを書くタイミング

  • 新規ページを3本以上作成・改修した
  • カテゴリ・フォルダ構造に手を入れた
  • 大きな調査・裏取り作業を実施した
  • ADR を新規追加した（ADR 記録だけでなく、その作業の時系列も残したい場合）
  • 1セッションが 30 分以上の連続作業になった

小さい修正（typo・リンク追加・1ファイル軽微編集）はセッションログ化せず、git log と next-actions 更新だけで十分。

セッションログのテンプレート

新規記録は既存ログ（2026-05-26.html）をコピーして、以下を更新:

  • <title> と <h1> の日付
  • meta-row のメタ情報（日付・主作業・関連 ADR・形式）
  • summary-tiles の数値
  • セッションの目的・実施内容・顕在化したこと・次のフォローアップ
  • commit ハッシュ

詳細は Page Template と Style Guide を参照。
