Workspace Agents の意味 — Custom GPT との違い

Workspace Agents は Custom GPT の単純な改良ではなく、戦略上の置き換えです。 Custom GPT は「個人ユーザーが作るボット」でしたが、Workspace Agents は 組織の権限・データ・コンピューティング枠を共有する Codex ベースのエージェントです。

① Codex を中核に置く

コーディング・コンピューター操作・ツール連携が「文字応答」と並列で扱える。

② 組織共有・管理

権限ガバナンス・実行ログ・評価がプラットフォームに組み込まれている。Frontier の延長線上。

③ SaaS への直接接続

Slack / Salesforce / その他主要 SaaS にプラグイン可能。Anthropic の MCP コネクター戦略と並走。

2026/5/6 からクレジット課金に移行し、無料期間は終了。商用本格運用フェーズに入りました。

Codex の動き — 「コーディング以外もできる万能エージェント」へ

Codex は2026年に入り、コーディング限定のツールから「ほぼすべてのタスク対応の万能エージェント」に拡張されました。

  • 機能拡張：コーディング + コンピューター操作 + 日常ツール連携 + 画像生成 + 設定記憶 + 継続タスク実行
  • 規模：週間アクティブユーザーが 4M 超を突破（GPT-5.5 リリース後に倍増）
  • 分配：iOS / Android アプリ統合（5/15）、AWS Bedrock ネイティブ対応（5/10）、Dell PowerEdge オンプレ（5/19）
  • 性能：GPT-5.3-Codex-Spark + Cerebras で 1,000 トークン/秒
  • UI：Goal Mode 正式化（5/25）、macOS Appshots でフルスクリーンアプリ取込

Claude Code が「CLI 中心 + Managed Agents」だとすると、Codex は「マルチサーフェス（Mac / Mobile / Cloud / IDE 拡張）の単一エージェント」というアプローチ。

注意点とリスク

  • Apple との Siri 提携破綻（5/15報道）：OpenAI が法的措置を準備中。Apple が独自 AI を優先したことが対立の核心とされる。今後 Atlas / ChatGPT iOS の戦略にも影響する可能性。
  • 計算リソース逼迫：CFO Sarah Friar が「$1,220億調達後も追加資金調達を検討」と Bloomberg に明言（5/15）。Anthropic の SpaceX Colossus 1（月 $1.25B）と同じ計算インフラ調達競争にいる。
  • モデル世代交代の速度：GPT-5.3 → 5.4 → 5.5 → 5.5 Pro → 5.6（予定）と月次ペース。アプリ統合側はバージョン依存の挙動差を意識する必要がある。
  • Sora 撤退の含意：消費者向け動画生成は OpenAI の戦略外に。動画生成を業務利用する場合は Runway / Kling / Veo へ移行検討。
  • Custom GPT 移行：Custom GPT は段階的に Workspace Agents への置き換えが進む見込み。既存 Custom GPT 資産の棚卸しが必要。
