最優先Claude Code v2.1.148 — Bash exit code 127 リグレッション緊急修正

v2.1.147 で Bash ツールが全コマンドに exit code 127 を返す重大なリグレッションが発生し、v2.1.148 で緊急修正。同バージョンで Windows Terminal ストリーミング中のフル画面フリッカー、バックグラウンドジョブの worktree が NTFS ジャンクション経由でメインリポジトリに侵入する問題も同時修正。タイプ入力がスキルやカスタムスラッシュコマンドのみのセッションでバックグラウンドセッションが拒否されるバグも解消された。

ソース: Claude Code Changelog / releasebot.io

最優先Claude Code 新機能 — /feedback 強化・背景エージェント権限継承・ANTHROPIC_WORKSPACE_ID 追加

/feedback コマンドが直近 24 時間または 7 日間の過去セッション情報を含めて送信可能になり、複数セッションをまたぐ問題の報告精度が向上。/bg または ←← で起動したバックグラウンドエージェントが、起動元セッションの権限モードを継承するよう変更（従来はデフォルトにリセットされていた）。ワークロードアイデンティティフェデレーション向けに ANTHROPIC_WORKSPACE_ID 環境変数も追加された。

ソース: code.claude.com/docs/changelog

高優先Cloudflare — グローバル LLM 推論インフラ新設、入出力分離アーキテクチャで低遅延を実現

Cloudflare がグローバルネットワーク上に LLM 推論専用インフラを発表。入力処理（プリフィル）と出力生成（デコード）を別々のシステムで実行する分離アーキテクチャにより、それぞれの処理を最適化されたハードウェアで並列実行できる。エージェントワークフローやストリーミング推論での低遅延化が見込まれ、Cloudflare Workers AI との統合が進む。
