計測スクリプト（再現用）

⚠️ 2026-07-05 版で os.path.getmtime ベースから git log ベースに切替。リモート実行環境ではコンテナ再クローンのたびに全ファイルの mtime が現在時刻にリセットされ、旧スクリプトは常に days_old=0 を返す不具合があったため。

import subprocess, time, os
from collections import defaultdict

# 全コミットを新しい順に舐め、各ファイルが最初に登場した時刻 = 最終更新時刻
out = subprocess.run(['git','-c','core.quotepath=false','log','--format=C:%ct','--name-only'],
                      capture_output=True, text=True).stdout
current_ts, first_seen = None, {}
for line in out.split('\n'):
    if line.startswith('C:'):
        current_ts = int(line[2:])
    elif line.strip():
        first_seen.setdefault(line.strip(), current_ts)

now = time.time()
cats = defaultdict(list)
for root, dirs, files in os.walk('.'):
    if '.git' in root or 'node_modules' in root: continue
    for f in files:
        if not f.endswith('.html'): continue
        path = os.path.join(root, f).replace(os.sep, '/').lstrip('./')
        cat = path.split('/')[0] if '/' in path else '(root)'
        with open(path, encoding='utf-8', errors='ignore') as fh:
            lines = sum(1 for _ in fh)
        ts = first_seen.get(path)
        days_old = (now - ts) / 86400 if ts else None
        cats[cat].append((path, lines, days_old))

for c, files in sorted(cats.items()):
    total = sum(f[1] for f in files)
    ages = [f[2] for f in files if f[2] is not None]
    print(f"{c:<20}{len(files):>6}p {total:>7}lines  avg={sum(ages)/len(ages):.1f}d")

これを logs/hub-stats.py として置き、四半期ごとに実行 → このページを手動更新する想定。将来的には GitHub Actions で自動化できる。
