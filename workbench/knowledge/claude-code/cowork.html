Claude Cowork — cloudの継続とローカル接続の境界

文書仕事を任せる際の入力・保存・確認を、現在の提供面から考えます。

旧情報は固定旧版の全文へ分離しています。以下の例・試験案は未実行の教材です。

10月の変更を旧desktop像から切り離す

公式案内では、2026-10-06以降のPro/Max新規Cowork taskはcloudで実行され、以前に端末で始めたtaskはそのまま継続します。「Only on your computer」の選択はこれらのplanの新規taskでは戻せません。現在の利用案内。旧記事のmacOS限定・常時端末内実行という説明を現在へ持ち越しません。

Coworkは知識作業を行う製品の面です。Codeのdevelopment session、Messages API、自作agentとは異なります。同じモデル系列が使われても、ファイルの処理場所、UI、保存、接続、請求条件が同一になるとは限りません。

cloudで続くことと、端末に届くこと

cloud sessionは端末を閉じても仕事を続けられますが、ローカルfolderやbrowserへのアクセスにはDesktop appのbridge条件があります。接続したfolderに限られ、端末側appが開いていること等が必要です。Local file accessの注記。端末がofflineでも全資料へ届くという意味ではありません。

未実行の教材例では、cloud上にある公開資料をまとめる工程と、接続したfolderの人工CSVを読む工程を分けます。途中で端末が閉じられた場合、後者が不足したと分かる出力を求めます。必要な情報がないまま推測で表を完成させるのは失敗です。

データの処理場所を把握する

公式architectureは、cloudでagent loopとcode executionを動かし、端末内ファイルを開いた場合もserverで処理すると説明します。Cowork architecture。ファイルの原本が端末に残ることと、処理内容が端末外へ出ないことは違います。

一般記事から自分の組織の契約適合や機密区分を確定できません。公開資料、人工fixture、共有してよい資料という入力を先に分け、契約と権限の判断はownerが行います。接続がtechnicalに可能なことを、未公開情報を利用してよい証拠にしません。

未実行例：人工売上表から説明資料を作る

例では架空の商品名と売上を持つCSVを用意します。求める出力は、単位、対象期間、合計、差異、出典のfile名を明示した短い説明資料です。元CSVを上書きせず、新しい候補を作り、計算値を別の決定的な処理でも照合します。実際の顧客や契約、秘密の売上は使いません。

反例には欠損値、同じ月の重複、通貨違い、負数、列名の曖昧さを入れます。図が綺麗でも合計が違う資料は合格にしません。未確認の前提を脚注へ隠すのでなく、利用者が判断できる位置に示します。資料制作の成功と、業務上の採用は別に扱います。

長いtaskを確認可能にする

依頼では、入力、途中確認の粒度、実行してよい操作、完成条件を示します。「全部いい感じに」は資料解釈と外部作用の範囲を曖昧にします。情報の整理とメール送信を一つにせず、まず下書きや候補で止める方が、内容を確認しやすくなります。

作業中は、toolの結果、欠けた入力、判断した仮説、作ったfileを区別します。通知が来たことは仕事が完成したことではありません。完成時には元データと成果、計算、引用、表示の検査を照合し、未実行の検査を成功実績として記述しません。

選ぶための評価

Coworkの候補評価では、手作業の転記が減るか、完成資料を読みたくなるか、訂正量、データ境界、失敗が分かるかを確認します。Codeが向く再現可能なpipelineやAPIが向くアプリ連携と比べ、UIの便利さだけで選ばないようにします。

Team/Enterpriseのcloud提供にはbeta・組織設定等の条件があると公式案内に記載されています。Planごとのarchitecture案内。読者の実際のplan、enabled状態、保存要件は未確認です。試験結果を一般の全利用者に保証せず、条件が変われば再評価します。

接続条件を落とした教材

合成の表整理を、必要なファイルが全部揃った状態と、ローカル側の接続が使えない状態で別々に設計します。後者ではクラウドが動き続けることだけを理由に、手元のファイルを読めたと報告してはいけません。利用できた資料だけで部分結果を作るか、不足を示して停止するかを先に決めます。

成果の評価では整理後の表だけでなく、未読ファイル、解釈が分かれた列、変換した単位を確認します。一般資料を扱うからといって秘密情報を無条件で渡してよいわけではありません。資料の提供可否を先に判断し、教材では固有名詞も数値も合成して、操作と内容の検証を分離します。
