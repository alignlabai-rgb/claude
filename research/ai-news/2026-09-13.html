🔴 Claude / Anthropic

アップデートClaude Code v2.1.270公開、v2.1.269のBash権限プロンプト不具合を修正

Anthropicは9月12日、Claude Code v2.1.270を公開。前バージョンv2.1.269で発生していた、セッションを長時間継続していると読み取り専用のgitコマンドまで実行許可を求めてしまうリグレッションを修正した。1件の修正に絞った迅速なパッチリリースとなっている。

Source: Claude Code Changelog

🔴 OpenClaw / Hermes Agent

破壊的変更OpenClaw v2026.9.4公開、プラグイン/スキル探索を追加しNode 24.16+/26.1+を必須化

OpenClawは9月11日、v2026.9.4を公開。導入済みプラグイン・スキルを一覧・検索できる「discovery」機能、スキル習得の過程を可視化する「visible skill learning」、クラウドワーカー制御、GPT Image 2.5対応、ターミナル上での質問応答UIなどを追加した。一方でNodeランタイム要件を引き上げ、Node 24.16.0以降または26.1.0以降が必須に。Node 22・25系、および旧24/26系ビルドはサポート対象外となった。

Source: OpenClaw GitHub Releases

🟠 Grok / xAI

アップデートxAI「Grok Build」v1.0.25公開、ワークフロー一時停止機能やペイジャー全文表示を追加

xAIはコーディングエージェントツール「Grok Build」のv1.0.25を公開。バックグラウンド実行中の`/workflow`を一時停止・停止できる機能、ページャーでのbashコマンド出力を省略せず全文表示する機能、音声入力のカーソル位置への直接挿入、Vimモードでのターン間ジャンプなどを追加し、開発者体験を細かく改善した。

Source: xAI Grok Build Changelog

🟠 クリエイティブAI連携

新機能Runway、Adobe Premiere Pro/After Effects向けプラグインを公開しAleph 2をタイムライン編集に統合

Runwayは9月8日、Premiere ProとAfter Effects内のパネルからRunwayの全モデルラインナップを直接呼び出せる「Plugins for Adobe」を公開。映像編集モデル「Aleph 2」を使い、タイムライン上の素材をテキストプロンプトでそのまま再スタイリングできるようになり、既存の編集ワークフローに生成AIを組み込みやすくなった。

Source: Runway

🟡 ビジネス・M&A × AI

新製品Salesforce、業務特化の名前付きAIエージェント7体「Agentforce」を投入

Salesforceは9月11日、Dreamforceを前に、営業・カスタマーサポート・EC・IT/HR・サプライチェーン向けに設計した名前付きAIエージェント7体（Casey・Paige・Carter・Hunter・Marshall・Piper・Fin）を発表。既存のCustomer 360データ基盤上で、企業ごとの権限・セキュリティ設定内で稼働する。6体は提供開始済みで、週〜月単位で目標を追い続ける新ランタイムを使うアウトバウンド営業エージェント「Hunter」のみ試験提供中。

Source: Salesforce
