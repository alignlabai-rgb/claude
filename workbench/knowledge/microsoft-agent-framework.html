Microsoft Agent Framework：agentを工程として設計する

Semantic KernelやAutoGenの後継として、agent・workflow・session・middlewareを使い分ける。多人数の会話ではなく、再現と失敗制御のためのコード基盤を理解する。

最終更新：2026-10-13 / 公式一次資料確認。実環境の機能・契約検査は未実施。

単体agentとworkflowの違いから始める

Microsoft Agent Frameworkはモデルclient、tools、session、memory用context provider、middleware、workflow等を扱うframeworkだ。公式overviewはSemantic KernelとAutoGenの後継として説明し、agentと明示的なworkflowを区別する。工程を通常の関数で書けるなら、すべてをagentの自由判断へ置き換える必要はない。

公開repoにはPython/.NETの実装やworkflow pattern、telemetry、checkpoint等がある。Go版は公式overviewでpublic previewとされ、機能の差が明記される。公式repository。言語を変えても完全に同じAPI・成熟度になると断定しない。記事中の設計は教材であり、providerを呼び出した試験結果ではない。

四層を分けると、モデル交換が容易になる

層担当すること任せないこと
モデルclient推論の入出力、対応形式業務の採否
agent情報の解釈とtool候補の選択無検証の外部作用
workflow状態、工程順、停止、受渡し欠けた根拠の創作
tool adapter入力検証、許可、作用と結果会話から暗黙の権限拡大

これは筆者の設計分解だ。workflowは関数やagentを明示した経路で結ぶための仕組みになる。workflow概念。複数agentの意見を集めても、正解や独立監査が自動的に生まれるわけではない。別の入力や評価責任がなければ、同じ誤りを多人数で反復するだけになり得る。

教材例：公開資料を提案カードへ変える

収集済みの公開資料を読み、主張候補を抽出し、出典と条件を検証し、活用案を作る工程を考える。最初から四agentを作るのではなく、通常関数で資料identityと日付を検査し、曖昧な文章の解釈だけagentへ渡す。根拠が揃わない候補は保留へ行く。活用案の生成と導入決定は別のstateにする。

固定した入力 → 形式/時点検査 → 主張候補
  → 根拠照合 → 提案draft → 独立review
矛盾 / 出典不足 / 不適合 → HOLD
review対象が変わる → 前のreviewを失効し再確認

カードには入力版、主張、適用条件、残る不明、候補の担当を付ける。提案のrecipient候補を正式な作業命令としない。review後に本文が変わったら、そのreviewを変更後へ流用しない。こうした状態制御はmodelの文章力とは別の工程だ。

middlewareは検査点であり、万能の防壁ではない

middlewareはagentの処理をinterceptし、入力・出力・function callの確認等を組み込める。公式middleware概説。筆者の案では許可されたtool名、入力schema、用途、予算上限を実行前に検査する。ただしmiddlewareを経由しない操作や、adapter側の広すぎるcredentialがあれば、上流の確認だけで安全は成立しない。

loggingも目的を限定する。全文traceがあればdebugしやすい反面、資料や秘密が記録へ複製される。必要なID、状態、拒否理由、計測だけにできないかを検討する。情報の保持範囲と誰が閲覧できるかを決める。観測の多さを品質の証明にしない。

restartできても、外部作用を巻き戻せるとは限らない

checkpointやsessionは処理の継続を助けるが、送信したメールや作成した外部recordは別の状態だ。教材ではtool実行直後のtimeoutとrestartを試験し、同じ業務キーが既に存在するか照合してから再実行する。checkpointがあるだけでexactly-onceを宣言しない。相手APIのidempotencyとreceiptの条件まで必要になる。

採用判断では、normal入力だけでなく、schema違反、資料中の誘導、tool拒否、result不明、停止後再開を含める。framework更新時はdependency版とtestを固定し、旧実装が動かなくなった理由をmodelの性能変化と混同しない。previewの機能と本番依存を分け、少ない部品で必要な制御を閉じるのが有効な出発点になる。
