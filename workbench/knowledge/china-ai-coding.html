中国系 AI コーディングツール

Alibaba・ByteDance・Baidu・Huawei・Zhipu AIが開発する、Claude Code / Codexと同等のエージェント型AIコーディング支援ツール。国産LLMを基盤に急速に進化している。

2024– エージェント化加速
OSS 一部オープンソース
VS Code 主要対応IDE
🟠

通义灵码 Tongyi Lingma

Alibaba（阿里巴巴）製。Qwen系LLMを基盤とするコーディングエージェント。VS Code / JetBrains対応。コード補完・レビュー・テスト生成・CLIエージェントモードを持ち、Claude Code相当のターミナル操作が可能。

  • 開発元：Alibaba Cloud
  • 基盤モデル：Qwen2.5-Coder
  • IDE：VS Code、JetBrains、Cloud IDE
  • エージェントモード：あり（ターミナル操作・マルチステップ）
  • 価格：無料プランあり／Alibaba Cloud連携
Agentic VS Code JetBrains CLI Qwen
🟣

Trae by ByteDance

ByteDance（抖音親会社）製のCursor対抗AI IDE。Doubao系モデルを搭載し、AIチャット・インラインEdit・エージェントモードを統合。無料で提供されCursor代替として急速に普及。

  • 開発元：ByteDance
  • 基盤モデル：Doubao / Claude（外部モデル選択可）
  • 形態：スタンドアロンIDE（VS Codeベース）
  • エージェントモード：Builder（複数ファイル編集）
  • 価格：無料（2025年現在）
Cursor代替 スタンドアロンIDE 無料 Doubao
🔵

豆包 MarsCode by ByteDance

ByteDanceの別プロダクト。クラウドIDE + VS Codeプラグインの二本立て。コード補完・バグ修正・ユニットテスト生成が中心。Traeとは異なりプラグイン型で既存環境に統合しやすい。

  • 開発元：ByteDance
  • 基盤モデル：Doubao-1.5-pro
  • 形態：VS Codeプラグイン + クラウドIDE
  • 対応言語：100+
  • 価格：無料プランあり
プラグイン型 クラウドIDE VS Code Doubao
🔷

文心快码 Baidu Comate

Baidu（百度）製。ERNIE（文心）系LLMを基盤とするコーディングアシスタント。コード補完・生成・ドキュメント自動生成が主機能。企業向けにオンプレ展開も可能。

  • 開発元：Baidu
  • 基盤モデル：ERNIE Code
  • IDE：VS Code、JetBrains、Eclipse
  • 企業向けオンプレ：対応
  • 価格：無料プランあり
エンタープライズ オンプレ対応 VS Code ERNIE
🟤

CodeGeeX by Zhipu AI

清華大学発のZhipu AI（智谱AI）製。オープンソースのコーディングモデルCodeGeeXをベースにしたIDE拡張。GitHub Copilot代替として研究・開発コミュニティで人気。モデル自体もHugging Faceで公開。

  • 開発元：Zhipu AI / 清華大学
  • 基盤モデル：CodeGeeX4-All-9B（OSS）
  • IDE：VS Code、JetBrains
  • オープンソース：モデル公開あり
  • 価格：無料
オープンソース VS Code JetBrains GLM
🔴

CodeArts Snap by Huawei

Huawei（華為）のDevOpsプラットフォーム「CodeArts」に統合されたAIコーディング支援。Pangu（盤古）モデルを活用。エンタープライズ向けセキュリティ・コンプライアンス重視の設計。

  • 開発元：Huawei Cloud
  • 基盤モデル：Pangu（盤古）Code
  • 形態：Huawei CodeArtsプラットフォーム統合
  • 対象：大企業・政府系
  • 価格：Huawei Cloud契約ベース
エンタープライズ 政府系対応 Pangu DevOps統合

Claude Code / Codex との位置づけ

共通点

  • VS Code / JetBrains等の主要IDEに対応
  • コード補完・生成・レビュー・テスト生成
  • 自然言語による指示でコードを変更
  • マルチファイル編集（エージェントモード）
  • ターミナル / シェル操作（一部ツール）

主な違い

  • 基盤モデルが国産LLM（Qwen / Doubao / ERNIE等）
  • 中国語コードコメント・ドキュメントに強い
  • データが中国サーバー処理（グローバル企業は注意）
  • GitHub Copilot / Claude Code比でエージェント深度はまだ発展途上
  • 一部はオンプレ展開が可能（Comate / CodeArts）
⚠ データ主権・利用規約の確認を
中国企業製ツールはデータが中国サーバーで処理される場合があります。グローバルプロジェクトや機密コードに使用する場合は、各サービスのデータポリシーと自社のコンプライアンス要件を必ず確認してください。Comate・CodeArts はオンプレミス展開オプションを提供しています。
