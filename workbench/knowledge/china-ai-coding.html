主要ツールの導入手順

通义灵码（Tongyi Lingma）

1

VS Code 拡張機能を検索

Extensions（Cmd+Shift+X）で「Tongyi Lingma」または「Alibaba」と検索

2

Alibaba Cloudアカウントでサインイン

無料アカウント登録後、拡張機能からログイン

3

エージェントモードを有効化

設定 → Lingma Agent Mode をオン。Quest Betaは別途申請が必要

ext install Alibaba-Cloud.tongyi-lingma

Trae（スタンドアロン）

1

trae.ai からダウンロード

macOS / Windows 対応。VS CodeのExtensions・設定は自動インポート可能

2

モデルを選択

Claude 3.7 Sonnet / GPT-4o / DeepSeek R1 から選択（無料枠あり）

3

Builder / SOLO モードを使う

チャットパネル上部でモード切替。SOLOは自律的にプランニング〜実装〜テストを実行

CodeGeeX（OSS・ローカル実行も可）

1

VS Code 拡張をインストール

「CodeGeeX」で検索 → Zhipu AI 製のものを選択

2

サインインまたはローカルモード選択

Z.ai アカウントでクラウド利用 or ローカルモデル（9B）をダウンロードして完全オフライン実行可

3

インタラクションモードを理解する

Stealth / Interactive / Translation / Prompt の4モードを使い分け

ext install aminer.codegeex

「Baidu Comate」または「文心快码」で検索してインストール

comate.baidu.com でアカウント作成後、拡張機能から認証

データセキュリティ・コンプライアンス

利用前に確認すべきこと

リスクの整理

  • データ処理場所：クラウド版はコードが中国サーバーに送信される。機密コード・特許・未公開製品には注意。
  • 利用規約の確認：送信したコードが学習データに使われるかを各社ポリシーで確認。
  • 企業コンプライアンス：SOC2・GDPR・ISO27001などの認証取得状況を確認。
  • 輸出規制：米国の輸出規制（EAR）対象プロジェクトには使用不可の場合あり。

リスク低減策

  • オンプレ展開：Comate・CodeArts・CodeGeeXはオンプレ対応。コードが外部に出ない。
  • ローカルモデル実行：CodeGeeX4の9Bモデルをローカルで動かせばデータ送信なし。
  • OSSコードのみ使用：公開予定のOSSプロジェクトなら機密性の問題が小さい。
  • 機密・社内コードは分離：学習・プロトタイプ用途に限定し、本番コードには別ツールを使う運用も有効。
⚠ グローバル企業 本番コード・IP・未発表製品への使用は法務・セキュリティ部門の承認を得てから。
✅ OSSプロジェクト 公開コードへの使用はほぼ問題なし。無料で強力なコーディング支援が得られる。
✅ オンプレ構築 Comate・CodeGeeX・CodeArtsはオンプレ対応。完全ローカルで最高水準のセキュリティ。
