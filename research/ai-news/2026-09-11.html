🔴 Claude / Anthropic

脅威レポートAnthropic、Claudeがイラン・ロシア・中国・イエメンの兵器開発に悪用されたと公表

Anthropicは9月11日、脅威インテリジェンスチームの報告として、2025年12月〜2026年8月に検知した悪用事例を公表。イエメンの武装勢力が誘導ロケットや射程2,000km超の多段弾道ミサイル、極超音速滑空体の開発にClaudeを「人間のソフトウェアエンジニアの代わり」として利用したほか、ロシアの自律型特攻ドローン群開発、中国関連ネットワークによるカトリック枢機卿やチベット仏教指導者等への監視情報収集、イランによる影響工作など計7分野の悪用を確認。いずれも最新のFable/Mythos系列ではなくHaiku・Sonnet・Opusが使われたとしている。

Source: Anthropic / Bloomberg

アップデートClaude Code v2.1.268公開、gatewayの価格連携とmaxEffortLevel設定を追加

Anthropicは9月10日、Claude Codeのバージョン2.1.268を公開。gateway.yamlに設定した料金がサインイン済みクライアントのmanaged設定にも反映され/costと使用量表示が一致するようになったほか、プロバイダ横断でeffortレベル上限を指定できる「maxEffortLevel」設定、プロンプト文言を毎回再生成する「--system-prompt-snapshot off」オプションを追加。応答を返さないサーバーへのWebFetchが無限にハングする不具合も修正した。

Source: Anthropic Claude Code changelog

新機能Claude Enterprise向け「Smart Reports」がベータ公開

Anthropicは、チームのClaude利用状況を分析し、完了したタスク・コスト・作業が滞りやすい箇所・共有スキル化すべき反復パターンをレポートする「Smart Reports」をEnterpriseプラン向けにベータ提供開始。組織内でのClaude活用の可視化と定着を狙う機能。

Source: Anthropic

🟠 GPT / OpenAI / Codex

アップデートCodex CLIがGPT-6 Astra対応・試験的worktreeセッションを追加

OpenAIはCodex CLIを更新し、モデルピッカーとAmazon Bedrockカタログに「GPT-6-Astra」を追加。新規/フォークしたセッション用に独立した作業ツリーを作れる試験的な`--worktree`/`/worktree`、作業を止めずにインラインで質問に回答できる機能、Windowsでのバックグラウンドサーバー共有などを追加した。MCP OAuthフローやセッション再開、承認まわりの安定性も改善している。

Source: OpenAI Codex changelog

🟠 AIエージェント全般

新モデルSakana AIが「Fugu Ultra v2」「Fugu Max」公開、Fable/GPT-6 Astra不使用でフロンティア級性能主張

Sakana AIは9月11日、複数モデルを動的に協調・オーケストレーションする「1モデルとして提供されるマルチエージェントシステム」Fuguの新版「Fugu Ultra v2」と低コスト版「Fugu Max」を公開。Chartography・DeepSWEなど8ベンチマーク中5項目で最高・同率最高スコアを記録したとし、Claude Fable 5/5.1・GPT-6 Astraを内部エージェントプールに一切含めずにこの性能を達成した点を強調している。価格は入力100万トークンあたり5ドルから。

Source: Sakana AI / VentureBeat

🟡 Gemini / Google AI

新機能Google、GeminiのGoogle Sheets対応をAndroidに拡大・セル上限を2,000万に倍増

Googleは9月10日、Google Sheetsのセル数上限を最大1,000万から最大2,000万へ段階的に拡大開始。同時にAndroid版Google SheetsにGeminiを統合し、データ分析・質問応答・グラフ生成を提案プロンプト付きで外出先から行えるようにした。管理コンソール側でもGemini Notebookの外部共有を細かく制御できる設定を追加している。

Source: Google Workspace Updates
