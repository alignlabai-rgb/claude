🔴 Claude / Anthropic

アップデートClaude Code v2.1.263公開、CLIの安定性向上とクラッシュ低減の保守修正

9月6日公開のv2.1.263は「CLIバグ修正と信頼性向上」を主眼とした保守リリースで、コマンド実行時のクラッシュ低減と操作安定性の改善が中心。新機能追加はなく、9月4日公開のv2.1.261（/skill-doctor追加・インライン出力上限拡大）に続く定例パッチという位置づけ。

Source: Claude Code Changelog

新機能Developer Platformに「会話途中のツール変更」ベータ追加、プロンプトキャッシュを保持したまま切替可能に

複数のClaudeモデルで、会話のターン間にツールを追加・削除してもプロンプトキャッシュを保持できる「Mid-conversation tool changes」がベータ提供開始。長時間稼働するエージェントが実行中に利用ツールを動的に切り替える際、キャッシュ再構築によるコスト増・遅延を避けられるようになる。

Source: Claude Platform Docs

🟠 GPT / OpenAI / Codex

アップデートCodex CLI v0.153.3/v0.153.4公開、GPT-6 Astraのモデルピッカー表示とBedrock対応を修正

モデルピッカーでGPT-6 Astraが選択肢として表示されない不具合を修正し、モデル未指定時のバンドル既定モデルにAstraを設定した。あわせてAmazon Bedrock（Mantle/RuntimeのグローバルおよびUSルート）のモデルピッカーにもGPT-6 Astraを追加し、非同期の確認質問がテキストのみ対応であることを認識できるようガイダンスも修正した。

Source: Codex CLI Changelog
