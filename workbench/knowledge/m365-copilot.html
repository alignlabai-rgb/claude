1. Microsoft 365 Copilot とは

Microsoft 365 Copilot は、Word・Excel・PowerPoint・Outlook・Teams・OneNote・Loop など Microsoft 365 の全アプリに AI を統合したエンタープライズ向けサービスです。OpenAI の大規模言語モデル（GPT-5.5 Instant など）と Microsoft Graph を組み合わせ、ユーザー自身のメール・会議・ファイル・チャットを文脈として AI に提供します。

Microsoft Graph との接続: Copilot は Microsoft Graph API を通じてユーザーのメール・カレンダー・Teams チャット・SharePoint ドキュメント・OneDrive ファイルを横断参照します。これにより「先週の○○プロジェクトの資料を元に提案書を書いて」といったリクエストが可能になります。

セキュリティ境界（自分のデータのみ）: Copilot がアクセスできるのは、ユーザーがアクセス権を持つデータのみです。組織の権限・秘密保持ラベル・コンプライアンスルールはすべて維持されます。プロンプト・レスポンス・参照データは Microsoft の AI 基盤モデルの学習に使用されません（GDPR / EU データ境界にも対応）。

Work IQ（2025年 Ignite 発表）: Copilot の「知性レイヤー」として登場した Work IQ は、デジタルワークスペースのシグナル（メール・ファイル・チャット・会議）を継続解析し、組織のワークフローを学習します。Copilot がユーザーの仕事スタイルを把握し、より的確なコンテキストを提供することでアシスト精度が向上します。

Agent Mode 一般公開（2026年4月）: Word・Excel・PowerPoint での Agent Mode が GA になりました。Copilot が単一プロンプトで多段階の作業（調査 → 作成 → 修正）を自律実行できるようになり、従来の「一問一答」から「仕事の代行」に進化しました。

2026年5月 最新モデル選択

M365 Copilot はモデル選択機能を提供しており、以下のモデルが利用可能です:

  • OpenAI GPT-5.5 Instant — 日常業務向けの高品質レスポンス。画像分析・STEM 問題に強く、簡潔で無駄のない回答
  • Anthropic Claude Opus 4.8 — 複雑な多段階タスク向け。文書作成・データ分析・プレゼン生成での強力なツール選択と指示遵守
  • Microsoft 独自モデル — 各アプリに特化した処理（リアルタイム会議文字起こし等）

3. アプリ別 Copilot 機能詳細

📄 Word Copilot

文書作成 Agent Mode GA
  • Draft（下書き生成）: 「〜について3ページの提案書を作って」と指示するだけでアウトライン・本文を自動生成。PDF や既存ファイルをグラウンドとして使用可能
  • Rewrite（書き換え）: 選択した段落のトーン変更（フォーマル/カジュアル）・長さ調整・言い換えを即時実行
  • Summarize（要約）: 長文レポート・契約書・マニュアルを1クリックで要約。文書の「何が重要か」を即把握
  • 他ドキュメント参照: Microsoft Graph 経由でメール・Teams チャット・過去の Word ファイルを参照した文書生成が可能（「先月の議事録を元に今月の報告書を書いて」）
  • Legal Agent（法務特化）: 契約書レビュー・赤線編集・交渉ポイント抽出を構造化ワークフローで処理。変更提案は「変更履歴」として表示
  • 引用付き回答: Web コンテンツや Work IQ ソースから情報を取得した場合、自動的に引用元を表示して検証を容易に
  • Agent Mode: 複数のステップ（調査→構成→執筆→校正）を単一プロンプトで自律実行
ユースケース: 営業チームが複数の提案書テンプレートと過去メールを元に、顧客ごとにカスタマイズされた提案書を5分以内に生成。従来の半日作業が大幅短縮。

📊 Excel Copilot

データ分析 Python 統合 Agent Mode GA
  • 自然言語でデータ分析: 「この売上データから月次トレンドを分析して」と入力するだけで集計・グラフ・インサイトを自動生成
  • Python 統合（Copilot in Excel with Python）: 自然言語から Python コードを生成し、高度な統計分析・機械学習モデル適用・予測分析を実行（Anaconda との提携）
  • 数式生成: 「売上が先月比10%以上増加した行をハイライトする条件付き書式を作って」と指示するだけで複雑な数式・書式を生成
  • 予測列: 既存データのパターンから将来値を予測する新しい列を追加。在庫・売上・需要予測に活用
  • グラフ自動生成: データを選択して「このデータに最適なグラフを作って」と指示すると、グラフタイプ選択・軸設定・色付けを自動実行
  • 多段階編集（Agent Mode）: ローカルファイル（Windows/Mac）でも複数ステップの編集を単一プロンプトで自律実行
  • Work IQ 自動コンテキスト: Excel 編集時に関連メール・会議・チャット・ファイルを自動収集し、より正確な多段階編集を支援
ユースケース: 経理チームが月次決算データを Excel に貼り付け、「部門別コスト比較と前期比グラフを作成して」と指示するだけで分析レポートが完成。Python 統合により統計的異常値も自動検出。

📊 PowerPoint Copilot

プレゼン生成 Narrative Builder Agent Mode GA
  • Narrative Builder: テーマや要件を入力して Copilot と対話しながら構成を練り、数分でプレゼン初稿を共同作成。PDF・Word 文書をグラウンドとして活用可能
  • ブランドテンプレートから生成: 組織のブランドガイドラインに沿ったスライドを自動生成。フォント・色・レイアウトを統一
  • スタイル統一（2026年新機能）: 全スライドのフォント・フォントサイズ・箇条書きスタイルを一括統一。M&A 後の資料整理などに効果的
  • スライド要約: 長い資料から「エグゼクティブサマリー1枚」を自動生成。経営層向けのサマリーデックを即作成
  • 話者ノート自動生成: 各スライドの内容から、発表者が使いやすい詳細な話者ノートを自動作成
  • AI 画像生成統合: OpenAI 最新画像生成モデル（DALL-E ベース）を使ってスライド内の画像をその場で生成。プロンプト精度と視覚的品質が 2026年に大幅向上
  • Agent Mode: 「この Word 文書から15枚のプレゼンを作り、各スライドに関連画像を入れて」を一度に実行
ユースケース: コンサルタントが100ページの調査レポート（PDF）を元に、クライアント向け15枚のエグゼクティブデックを30分で作成。ブランドテンプレートが自動適用され、デザイン調整不要。

📧 Outlook Copilot

メール管理 Agentic Calendar
  • スレッド要約: 長い返信チェーンを1クリックでサマリー。「誰が何を決めたか」「次のアクションは何か」を瞬時に把握
  • 返信案生成（Draft with Copilot）: メール内容を踏まえた返信案を自動生成。トーン調整（フォーマル・カジュアル）や長さ変更も可能
  • 受信箱 AI 分析（2025〜2026）: Copilot Chat が受信箱全体・カレンダー・会議データを横断分析。「今週対応が必要なメールは？」「未回答の重要メールは？」を自然言語で問い合わせ
  • 優先メール判定: AI が重要度・緊急度を判断してメールをスコアリング。見逃しリスクを低減
  • Meeting Insights: 会議前に関連メール・過去の議事録・参加者情報を自動収集してブリーフィングを作成
  • AI コーチング: 送信前にメールのトーン・明瞭さ・インクルーシブ言語をチェックして改善提案
  • Agentic スケジューリング: 「来週中に○○さんと1時間の打ち合わせを設定して」と指示するだけで空き時間を探して招待を送信
ユースケース: 毎朝 200件以上のメールを受け取る部門長が、Copilot の受信箱分析で「今日対応必須の10件」だけをピックアップ。返信案を採用・微修正するだけで対応時間を60%短縮。

👥 Teams Copilot

Intelligent Recap Facilitator Agent 多言語対応
  • Intelligent Recap（会議後サマリー）: 録音・文字起こし・PPT データを使い、会議の決定事項・アクションアイテム・キーポイントを自動生成。参加者タイムラインで誰がいつ何を言ったかも確認可能

  • アクションアイテム自動抽出: 会議から TODO・担当者・期限を自動抽出。Planner やメールへの連携も可能
  • Facilitator Meeting Agent: 招待状・チャットからアジェンダトピックを抽出し、会議中のディスカッションを追跡。会議の進行を AI がサポート
  • 録音なしサマリー（2026年6月 GA 予定）: 録音・文字起こしを保存せずに、ライブコンテキストからのみ AI サマリーを生成。プライバシーに配慮した新モード
  • Video Recap（2026年4〜5月）: AI が生成した動画版サマリー。キーポイントと関連クリップをナレーション付きで組み合わせた数分のダイジェスト
  • Copilot in Teams Chat: チャット・チャンネルでも Copilot Chat が利用可能。SharePoint サイト・リストを参照したプロンプトにも対応
  • 多言語 Audio Recap: 英語に加えて日本語・中国語・フランス語・ドイツ語・イタリア語・ポルトガル語・スペイン語の音声サマリーに対応

4. Copilot Chat（旧 Bing Chat Enterprise）

Copilot Chat（旧称: Bing Chat Enterprise）は、M365 Copilot ライセンスに含まれるチャット型 AI インターフェースです。2025年末から無料版（フリーミアム）も提供開始され、利用の幅が広がっています。

Web グラウンディング

  • 最新のWeb情報をリアルタイムで参照
  • 情報ソースの引用を明示
  • ChatGPT・Perplexity に近い体験を企業環境で
  • データは企業外部に漏洩しない設計（Enterprise Data Protection）

社内データ参照（Work モード）

  • メール・カレンダー・ファイル・Teams を横断検索
  • 「先月○○プロジェクトで決まったことは？」をそのまま質問
  • SharePoint リスト・サイトを "/" で参照指定
  • Work IQ により関連コンテキストを自動提供

アプリ横断アクセス

  • Word・Excel・PowerPoint エージェントをチャットから呼び出し
  • 「この Excel ファイルを分析して」と添付・参照が可能
  • Teams チャット・チャンネル・会議でも利用可能
  • Outlook の受信箱全体を対象に問い合わせ

CarPlay & モバイル対応（2026年5月）

  • Apple CarPlay 対応: 車内でハンズフリーで Copilot Chat を利用
  • iOS/Android アプリのチャット UI を刷新（テキスト書式・引用表示）
  • 音声でプロンプト入力・回答聴取が可能

Copilot Chat の無料版（2025年末〜）: M365 Copilot ライセンスなしでも一部機能を無料で試用可能。ただし社内データ参照（Work モード）や Word/Excel/PowerPoint エージェントへのフルアクセスは有料ライセンスが必要。

7. 日本向け注意点・取得方法

日本での提供状況

  • M365 Copilot は日本でも正式提供済み（2024年1月 GA）
  • 住友商事が日本初の M365 Copilot 早期アクセス参加企業（2023年9月）
  • 多言語 Audio Recap に日本語が対応（2026年）
  • OneNote・Word・Excel・PowerPoint・Outlook・Teams すべて日本語 UI で利用可能

日本円 価格目安（2026年5月）

  • Copilot Business: ¥2,698/user/月（税抜）
  • Business Basic: ¥899/user/月〜
  • Business Standard: ¥1,874/user/月〜
  • Business Premium: ¥3,298/user/月〜
  • Enterprise 向けは CSP/EA パートナーへ要見積もり

ライセンス取得方法

  • Microsoft 直販: Microsoft 365 管理センターから追加
  • CSP（クラウドソリューションプロバイダー）: NTT データ・SoftBank・KDDI 等の認定代理店
  • Enterprise Agreement（EA）: 大企業向け3年契約。ボリュームディスカウント交渉可能
  • Microsoft FastTrack: 500席以上の導入時に無料の導入支援

Enterprise vs Business の選び方

  • Business（〜300席）: シンプルな管理・中小企業向け。E3/E5 の高度なコンプライアンス機能は不要な場合に適切
  • Enterprise（E3/E5）: Purview・Intune・Defender との統合が必要な大企業・規制業界向け。E5 は高度な eDiscovery・DLP も含む
  • 判断基準: 従業員数300名超 または 高度なコンプライアンス要件があれば Enterprise を検討

日本語対応の注意点: 一部の新機能（Legal Agent・Video Recap 等）は英語での提供が先行し、日本語展開まで数週間〜数ヶ月遅れる場合があります。最新の日本語対応状況は Microsoft Tech Community Blog（日本語版）または Microsoft Learn リリースノートを参照してください。

2026年7月の価格改定に注意: Microsoft は 2026年7月1日から商用 M365 ライセンスの価格改定を予定しています。導入・更新を検討中の企業は、改定前のロック価格キャンペーン（Microsoft が提供中）を活用することを推奨します。
