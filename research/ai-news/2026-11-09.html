🔴 Claude / Anthropic

AnthropicClaude Fable 5.2 / Claude Mythos 5.2 を発表（11/9）：入力$8・出力$40/MTokへ値下げ、1M context、fast modeも同時提供

Anthropicの発表ページとClaude Platform release notesで確認。API IDは claude-fable-5-2 と claude-mythos-5-2。両者は同じ基盤モデルで、Fableはサイバー・生物分野のセーフガード付きで一般提供、Mythosは検証プログラム（Cyber Verification Program等）を通過した組織のみ。1M token context、最大出力128k、adaptive thinkingは常時オン。価格は入力$8／出力$40 per MTok（Fable 5.1 / Mythos 5.1は$10／$50）。Fable 5.2はClaude API、Claude Platform on AWS、Amazon Bedrock、Google Cloud（Anthropic managed／Google managed）、Microsoft Foundryで提供。fast modeは speed: "fast"（beta header不要）で出力最大2.5倍速、$16／$80 per MTok。以下は提供者側の説明・数値で独立測定ではない：5.1比で出力が最大30%高速、安全分類器によるブロックが約55%減、FrontierSWE v2 69.9%（Opus 5.5は62.3%）、Humanity's Last Exam（tools有）74.2%（同67.7%）。Claude appsとClaude CodeではMedium effortが既定。Pro・標準Teamシートでは週次上限の最大50%までFableを利用可能と記載。

Source: Anthropic（2026-11-09）／Claude Platform release notes

Claude APIFable 5.2 / Mythos 5.2 への移行で400エラーになる条件：prefix check全アカウント適用、旧computer useツール、advisorの組み合わせ

Claude Platform release notes（11/9）で確認。①prefix checkがアカウントの作成時期に関係なく全アカウントに適用される。system・tools・過去メッセージを編集したうえで後続ターンのthinking blockを送り返すと400。②computer useは computer_toolset_20260801 のみ対応。旧 computer_20251124 を宣言したリクエストはAmazon Bedrock以外で400。③advisor tool（beta）では、Fable 5.2 / Mythos 5.2 をexecutorにする場合advisorも同2モデルのいずれかに限られる（逆に、どのexecutorもFable 5.2をadvisorにできる）。④会話を他モデルへ切り替えると5.2が生成したthinking blockはAPI側で破棄される（リクエスト自体は成功）。thinking blockは生成したアカウントまたは連携アカウントでのみ有効。⑤30日のデータ保持が必須で、Anthropicの明示的な許可がない限りzero data retentionでは使えない。プロンプトや履歴を途中で書き換えるハーネスは、切替前に移行ガイドの該当節を確認する必要がある。

🔴 Claude Code

Claude CodeClaude Code v2.1.321（11/9）：Fable 5.2を既定のFableモデルに、sandbox外実行・deny rule回避などの権限まわりを修正

GitHub Releasesで確認（一覧は「Read more」で省略あり）。Claude Fable 5.2（claude-fable-5-2）を新しい既定のFableモデルとして追加（1M context、$8/$40 per MTok、cache read $0.20/MTok）。claude remote-control に --settings <file>（変更は再起動後に反映）。修正：MCP OAuthがサーバーのリダイレクト時にrefresh tokenを別ホストへ送っていた問題、読み取り専用のBashコマンドが確認なしでsandbox外で実行された問題、ディレクトリへの cp／mv がdeny ruleと保護ファイルの確認を回避していた問題、fast modeがrate limit時に数分リトライし続ける問題（同一モデルの標準速度を先に試すよう変更）、NFSでtranscript行を失った claude -p が終了コード0で終わる問題（1に変更）。権限・sandboxの修正を含むため、deny ruleに依存した運用では更新の優先度が高い。

🔴 Hermes Agent

Hermes AgentHermes Agent v0.23.1（リリースノート日付11/9）：プラグインカタログの上限を2 MiB→16 MiBに引き上げ

GitHub Releasesで確認（GitHub上の公開時刻は11/10 01:42、リリースノート本文の日付は11/9）。v0.23.0以降の約618 PRをまとめたパッチ。主因の修正は、カタログのサイズ上限超過により hermes plugins install が黙って同梱カタログへフォールバックし、新しいプラグインや削除が反映されていなかった問題（PR #151860）。v0.23.0以前のインストールは更新するまでフォールバックのまま。プラグインを追加・更新している環境はv0.23.1へ上げないと最新カタログを見られない。
