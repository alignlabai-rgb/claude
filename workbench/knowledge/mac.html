よくあるシーン

操作フローで理解する

アプリをまとめて閉じたい
▶
  • Cmd + Tabでアプリ一覧 → 対象を選択。
  • Cmd + Qでアプリ終了。ウィンドウだけ閉じるならCmd + W。
  • タブやウィンドウを一気に閉じるならOption + Cmd + W。
ファイルを切り取り移動したい
▶
  • Cmd + Cでコピー。
  • 移動先でCmd + Option + V → 実質「切り取り+貼り付け」。
  • 親フォルダへ戻る: Cmd + ↑。
スクショを撮り分けたい
▶
  • 範囲: Cmd + Shift + 4。
  • UI付きメニュー/録画: Cmd + Shift + 5（保存先も変更可）。
  • 全画面: Cmd + Shift + 3。
強制終了したい
▶
  • Option + Cmd + Escで強制終了ダイアログ。
  • 重い場合はSpotlight (CmdSpace) →「アクティビティモニタ」。
ファイルのパスをコピーしたい
▶
  • Finderでファイルを選択 → Option を押しながら右クリック → 「"〇〇"のパス名をコピー」。
  • またはターミナルにファイルをドラッグ＆ドロップするとパスが自動入力される。
  • Finder下部のパスバーは Option + Cmd + P で表示。
日本語入力で困ったとき
▶
  • 英数↔かな切替：英数キー（スペース左）/ かなキー（スペース右）。
  • 入力中に変換候補が出ない → スペースで候補を展開。
  • 変換をキャンセルして確定し直す → Escape または Cmd + Z。
  • 入力ソースを切り替えたい → Ctrl + Space または メニューバーの🌐アイコン。
スクショをクリップボードに入れたい（貼り付け用）
▶
  • 通常のスクショはデスクトップにファイルとして保存される。
  • Ctrl を追加するとクリップボードにコピーされる。例: Ctrl + Cmd + Shift + 4（範囲選択→クリップボード）。
  • その後 Cmd + V でSlackやNotionなどに直接貼り付けられる。
ウィンドウを隠したい / 最小化したい（違いは？）
▶
  • Cmd + H：ウィンドウを「隠す」。Dock上にも出ない。Cmd + Tab で戻れる。
  • Cmd + M：Dockに最小化。Cmd + Tab では戻れない（Dockから直接クリックが必要）。
  • 全ウィンドウを隠す：Option + Cmd + H（他のアプリのウィンドウを全部隠して集中できる）。
Quick Look でファイルをすばやく確認したい
▶
  • Finderでファイルを選択 → Space を押すだけでプレビューが開く。
  • 画像・PDF・動画・テキスト・HTMLなどほぼすべてに対応。
  • もう一度 Space または Escape で閉じる。アプリを起動する必要がない。
  • 矢印キーで次のファイルに移動しながらプレビューできる。
トラックパッドと配列

ジェスチャとキーの違い

  • 右クリック: 2本指クリック（またはControl + クリック）。
  • Mission Control: 3本指上スワイプ。デスクトップ切替は3本指左右。
  • デスクトップ表示: 親指+3本指を広げるジェスチャ。
  • Commandはスペースキーの左右、OptionはAlt相当、Controlは右クリック補助。
  • Deleteはバックスペース。Forward Deleteは Fn + Delete。

「CmdをCtrlの代わりに押す」クセをつけると一気に慣れます。

Finder

ファイル操作の基本

  • 開く: Enter（Return）。名前変更もEnterで編集モード。
  • 新規フォルダ: Shift + Cmd + N。
  • パスをコピー: Control + クリック → 情報をコピー、またはTerminalにドラッグ。
  • サイドバー非表示/表示: Option + Cmd + S。
  • 隠しファイル表示: Cmd + Shift + .
ウィンドウ

並べて・切り替えて使う

  • アプリ切替: Cmd + Tab。同一アプリ内のウィンドウ巡回は Cmd + `。
  • フルスクリーン: Ctrl + Cmd + F または緑ボタン。
  • 左右分割: 緑ボタン長押しでSplit View。
  • デスクトップ切替: Ctrl + → / ← または3本指左右。
  • Dock表示/非表示: Cmd + Option + D。
ブラウザ

タブ操作

  • 新規タブ: Cmd + T。タブを閉じる: Cmd + W。
  • 閉じたタブを戻す: Shift + Cmd + T。
  • ページ内検索: Cmd + F。
  • プライベート/シークレット: Cmd + Shift + N。
  • アドレスバーへ: Cmd + L。

トラックパッド ジェスチャ

指の本数で覚える

  • 1本指：通常のカーソル移動・クリック・ドラッグ。
  • 2本指タップ：右クリックメニューを表示。
  • 2本指スクロール：上下左右にスクロール（自然なスクロール = コンテンツが指に追従）。
  • 2本指ピンチ：ズームイン / アウト（画像・PDFなど）。
  • 2本指スワイプ（左右）：ブラウザの戻る / 進む。
  • 3本指スワイプ（上）：Mission Control（全ウィンドウ一覧）。
  • 3本指スワイプ（左右）：仮想デスクトップ（Space）を切替。
  • 4本指ピンチ（つまむ）：Launchpad（アプリ一覧）を表示。
  • 4本指を広げる：デスクトップを表示（ウィンドウが全部退く）。
  • 4本指スワイプ（左右）：仮想デスクトップ切替（3本指と同様）。

設定変更は システム設定 → トラックパッド から。「自然なスクロール」をオフにするとWindowsと同じ方向になる。

  • タップでクリック：設定でオンにすると物理クリック不要に。
  • 強めのクリック（感圧）：単語の辞書検索、リンクプレビューなどに使える。
  • 3本指ドラッグ：設定でオンにするとウィンドウをドラッグ移動できる。

マウスを使う場合、Magic Mouseは2本指スクロールのみ対応。

Spotlight 完全活用

Cmd + Space で何でもできる

SpotlightはWindowsの「検索」より高機能。アプリ起動・ファイル検索・計算・単位換算・辞書・Web検索まで1つの入力欄でこなせる。

使い方の例

  • 「saf」と入力 → Safari を起動（アプリ名の一部でOK）
  • 「1500 * 1.1」と入力 → 即計算（1650と表示）
  • 「100 USD in JPY」→ ドル円換算をその場で表示
  • 「100 km in miles」→ 単位換算
  • 「明日のカレンダー」→ カレンダーイベントを表示
  • ファイル名の一部→ 一致するファイルを即検索
  • 「define: ephemeral」→ 英単語の辞書定義
  • Cmd + B（Spotlight上で）→ ブラウザでWeb検索

Spotlight を使いこなすコツ

  • アプリを探すときは Dock や Launchpad より圧倒的に速い。
  • アクティビティモニタ・ターミナル・システム設定などもSpotlightから一発起動。
  • 検索結果で Cmd + Enter → Finderでファイルの場所を開く。
  • 検索結果で Cmd + I → ファイルの詳細情報を確認。
  • 検索対象のカスタマイズ：システム設定 → Siri と Spotlight → 検索カテゴリ。
Mac 固有の概念

Windows にない仕組みを理解する

🍎 メニューバー（画面上部）

画面最上部のバーは常にアクティブなアプリのメニューを表示する。Windowsと違い、各ウィンドウに付いていない。右側の時計・Wi-Fi・音量アイコンエリアを「メニューバーエクストラ」と呼ぶ。
Option + クリックするとより詳細なオプションが出るアイコンもある（Wi-Fiなど）。

🚢 Dock

画面下部（または左右）のアプリランチャー。●（点）が付いているアプリは起動中。Windowsのタスクバーに近いが「最小化したウィンドウ」もここに入る。
右端のスタック（フォルダ）はDockから直接ファイルにアクセスできる便利エリア。

🗂 Mission Control

Ctrl + ↑ または3本指上スワイプで起動。全ウィンドウを鳥瞰できる。上部に仮想デスクトップ（Spaces）が並び、「＋」で追加できる。アプリを別のSpaceにドラッグして整理できる。

📁 Finder

Windowsのエクスプローラー相当。重要な違い：
• ファイルを「切り取り」できない（コピー → Cmd+Option+V で移動）
• Enter でリネーム（開くには Cmd+O）
• タブ機能あり（Cmd+T）
• カラムビュー（Cmd+3）がフォルダ階層を把握しやすい

🔴🟡🟢 ウィンドウボタン

左上の3つのボタン。
🔴 赤：ウィンドウを閉じる（アプリは終了しない）
🟡 黄：Dockに最小化（Cmd+Mと同じ）
🟢 緑：フルスクリーン / Split View
アプリの完全終了は Cmd + Q。赤ボタンだけでは終わらない。

🌡 アクティビティモニタ

WindowsのタスクマネージャーにあたるツールでCPU・メモリ・ディスク使用率が見られる。
起動：Spotlightで「アクティビティモニタ」と入力が最速。重いプロセスを選択して「✕」ボタンで強制終了可能。

Option キーの特殊文字

Option を押しながら入力する記号一覧

MacのOptionキーは記号・特殊文字の入力に使える。Windowsでは「文字コード+Alt」や変換が必要だった記号が一発で入力できる。

キー組み合わせ 出力文字 用途

Option + 3#US配列での # （JIS配列は Shift+3）
Option + 8•中黒（ブレット）
Option + ;…省略記号（三点リーダー）
Option + -–半角ダッシュ（en dash）
Option + Shift + -—全角ダッシュ（em dash）

全記号を調べるには

  • Spotlightで「キーボードビューア」と検索 → オンにするとキーを押すたびに記号が見える。
  • システム設定 → キーボード → 「キーボードビューアを表示」をオン。
  • Optionを押しながらキーボードビューアを見ると全記号が一覧できる。

絵文字・記号の別の方法

  • Ctrl + Cmd + Space → 絵文字 & 記号ピッカーが開く。検索欄から日本語でも探せる。
ホットコーナー & システム設定

画面の角にアクションを割り当てる

ホットコーナーとは、マウスカーソルを画面の四隅に移動するだけでアクションを起動できる機能。Windowsにはない便利機能。

設定方法

  • システム設定 → デスクトップと Dock → ホットコーナー（一番下）。
  • 四隅それぞれに「Mission Control」「デスクトップ」「Launchpad」「スクリーンセーバー」「画面をロック」などを設定できる。
  • Option を押しながらコーナーに触れる設定にすると誤爆しにくい。

よく使うシステム設定の場所

  • 外観：ダークモード / ライトモード切替。
  • キーボード → ショートカット：すべてのショートカットを確認・変更できる。
  • トラックパッド：ジェスチャのオン/オフ、速度調整。
  • ディスプレイ：解像度・輝度・Night Shift（ブルーライト軽減）。
  • 一般 → ソフトウェアアップデート：macOSのアップデート確認。
  • プライバシーとセキュリティ：アプリへのアクセス権限管理。
