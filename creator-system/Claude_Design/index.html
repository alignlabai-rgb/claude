Studio Notes 書架

Claude Design（Anthropic Labs 製、2026-04-17 GA）で制作している 「Claude をどう創作に編み込むか」の連続出版型ノートシリーズの書架です。 Creator System の素材源かつ、Claude を制作に活用する際の実例集として運用します。

現状は VOL.1（完結・5章）＋ VOL.2（進行中・3/5章）の構成。 VOL.1 が「始め方」、VOL.2 が「続け方・広げ方」を扱い、各章ごとにテーマカラーを変えた zine ライクな造本になっています。 本ノートは公開しても問題ない方法論として、Claude Hub 側で運用しています。

来週の作業メモ（2026-06-01 以降）

Claude Design の usage limit が 6/1（月） にリセットされる。リセット後、以下の順番で進める。

① VOL.2 P.04「Claudeで100本」生成

ユーザーが Claude Design に投げるプロンプト（Claude 側で準備）:

VOL.2 CH.04「Claudeで100本」、いきます。
テーマカラーは yellow 寄り（辞典・蓄積・厚み）にして、
視覚モチーフは付箋／カード／インデックスに振ります。

収録方針:
- 100 の具体ユースケースを 辞典的に列挙
- VOL.1 / VOL.2 P.01〜P.03 で扱った領域から横断的に拾う
- 1ユースケース = タイトル + 30〜60字の説明 + 推奨プロンプト1行
- 10カテゴリ × 10ケース、または 5カテゴリ × 20ケース のグリッド設計
- 巻末に「自分の100本リストを作るテンプレ」

② VOL.2 P.05「Claudeで続ける」生成

VOL.2 締めの章。プロンプト案:

VOL.2 CH.05「Claudeで続ける」、いきます。
テーマカラーは purple 寄り（持続・蓄積・年輪）にして、
視覚モチーフは年表／積層／灯台 に振ります。

収録方針:
- 連載・1冊の本・長期プロジェクトの「走らせ方」
- 1日のリズム → 1週間のリズム → 1ヶ月 → 1年の入れ子構造
- 続かない原因（飽き・成果不明・燃え尽き）と Claude での処方
- 実例3-4本（連載ブログ / 1冊の本 / 動画チャンネル / 業務日誌）
- 「ALIGNLAB NOTE — VOL.2」明記の締め
- VOL.1 P.05 と並列に置ける「反省ではなく持続」の対の章

③ VOL.2 完結後の作業

  • この書架の VOL.2 セクションを「完結 ✅ 5/5 章」に更新
  • 新規 2 章を Site Map（foundations/site-map.html）に追記
  • Site Changelog（logs/site-changelog.html）に v1.4 リリースとして記録

④ VOL.3 方向性検討（Claude 主導）

VOL.1 = 始め方、VOL.2 = 拡げ方 を踏まえた次の軸。Claude が3案を提示してユーザーが選定する想定:

  • 案 A「Claudeで磨く」 — 深掘り・改稿・推敲。1作品の質を上げる巻
  • 案 B「Claudeで挑む」 — 未踏領域・実験・新ジャンル開拓
  • 案 C「Claudeで遺す」 — 長期資産化・ライブラリ化・継承

他案: 「Claudeで稼ぐ」「Claudeで集める」「Claudeで対話する（VOL.1 P.04 拡張）」など。VOL.2 完結時に再検討。

Claude Design 運用ルール（ADR-009）

このフォルダは Claude Design の出力を受け入れる正式な置き場。Claude Design は直接既存フォルダに書き込めないため、ユーザーがここに置く → 次回 Claude セッションで整理・統合のワークフロー。

3 ステップワークフロー

  1. 制作: ユーザーが Claude Design に依頼。出力は手元の Claude Design 環境に生成
  2. 投入: ユーザーが軽量版だけをこのフォルダに配置（standalone 版は不要、.gitignore で除外済）
  3. 整理: 次回 Claude セッションでこの書架に章を追加 → ステータス更新 → Site Map と Changelog に反映

軽量版 vs standalone 版

種類サイズ目安リポへの扱い
通常版（軽量）30-80 KBcommit する。編集・差分追跡対象
standalone 版（重い）15-28 MB.gitignore で除外。配布が必要なら都度ローカルで再生成
