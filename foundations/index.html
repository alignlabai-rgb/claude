Foundations

このハブの目的・設計思想・運用原則・インスタンス間の協調プロトコルをまとめるカテゴリです。新しい Claude インスタンスはここから読み始めてください。

なぜ Foundations が必要か

このリポジトリは複数の Claude インスタンスが非同期で更新します。インスタンスはセッションが終わると記憶を失うため、「なぜこの構造なのか」「何を達成しようとしているのか」をファイルとして残しておかなければ、毎回ゼロから判断することになります。

Foundations はその「意図の記録」です。コードやコンテンツではなく、判断の根拠を置く場所です。

必読ドキュメント

必読

CLAUDE.md

リポジトリの目的・フォルダ規則・編集方針。すべてのインスタンスが最初に読むべきファイル。

必読

Agent Protocol

インスタンスが来たときの最初の5ステップ、共有記憶の構造、よい変更・避けるべき変更のガイド。

背景

ALIGN_Lab 道しるべ

非公開の別レポへのポインタ。役割分担と、AI セッションが必要時にローカル参照するワークフローを記述（ADR-010）。

原則

運用原則

各原則の「なぜ」まで記録。インスタンス間の協調原則・判断に迷ったときのフローも含む。

セッション運用のプロトコル

新しいセッションが入った瞬間と、並走を検出した瞬間に使うべきページ。作業を始める前と並走に遭遇した時に確認する。

手順

Onboarding Checklist

新セッションの最初の 10 分を標準化。Phase A（git 確認）→ Phase B（必読チェック）→ Phase C（過去の判断確認）の3段階。状況別フロー付き。

手順

並走プロトコル

マルチインスタンス運用の標準。検出・ブランチ命名・コンフリクト解消・コミュニケーション方法を網羅。並走前提の Claude / Codex 運用を支える基盤。

運用に耐えるためのリファレンス

セッションを跨いだ運用で「なぜそうした？」「これは何？」「同じ失敗を繰り返してないか？」に答えるためのページ群です。大きな変更をする前後に確認するのが想定運用。

参照

用語集（Glossary）

Claw Stack / OpenClaw / Cowork / Mythos / MCP / Antigravity 等のハブ固有用語をまとめた辞書。新セッション初期に有効。

参照

決定ログ（ADR）

「なぜそう決めたか」の軽量 ADR。LLM Hub 別建て・カテゴリ再編・Industry Trends 新設など 8 件記録。

学習

アンチパターン集

Claude / Codex に任せて失敗した例・救った例を蓄積。AP-001〜006・RP-001〜004 を記録。

ページ作成の標準化（Phase 2）

新規ページを作る時のテンプレート・スタイル・索引。複数セッションで品質ブレなく書き続けるための土台。

テンプレ

Page Template

Light / Rich 2系統の boilerplate と主要コンポーネント（timeline・stat・ADR・タグ等）をコピペ用に集約。

ルール

Style Guide

文体・色パレット・バッジ運用・ファイル命名・日付書式・強調表現の使い分けなど 13 章で統一ルール。

索引

Site Map

全 158 ページをカテゴリ別＋用途別で索引。トップカードから辿れないページもここから直接アクセス可能。

品質基準とライフサイクル（Phase 3-4）

ページを「完成」と判定する基準、そして「古くなった後どう扱うか」の処理ルール。

基準

Definition of Done

構造要件・内容品質・動線・スタイル準拠・カテゴリ別追加要件を整理。コピペ用のクイックチェックリスト付き。

運用

Archive Policy

古いコンテンツの 4 段階ライフサイクル（Active / Stable / Archived / Retired）。カテゴリ別の運用パターンと、物理削除のチェックリスト。
