AI とクリエイティブワーク

映像・漫画・音楽・文章——全領域でAIは「道具」から「共同制作者」へ変わりつつある。2026年4月、Anthropic は Claude Design と Adobe/Blender/Ableton 公式 MCP コネクターを公開し、クリエイティブへ本格参入した。このページでは実際のプロンプト例・具体シナリオで使い方を解説する。

最終更新: 2026-05-03

2026年4月 — 押さえておくべき2つの新機能

NEW 4/17

Claude Design（Anthropic Labs）

プロンプトからスライド・LP・プロトタイプをライブHTMLで生成。静止画ではなくクリッカブルな動くUIが出力される。Figmaに渡す前の方向性確認・非デザイナーの試作に最適。

できること： デザインシステムの自動適用、音声・インラインコメントで細部を調整、チームリンクで即共有

実際の指示例：

「ALIGN_Lab の新サービス発表用スライド5枚。ダークトーン、ミニマル。読者は30代クリエイター。内容: [概要を3行で貼り付け]」 「このLPのCTAボタン色を変えて。ヒーローセクションにアニメーションを追加して」
NEW 4/28

クリエイティブ MCP コネクター 9本

Claude から直接プロのクリエイティブツールを操作できる公式コネクター群。Claude Code + MCP の組み合わせで「自然言語 → ソフトウェア操作」が実現する。

主要コネクター： Adobe（Photoshop/Illustrator/Premiere/Lightroom/Firefly）、Blender、Ableton、Affinity by Canva、Autodesk Fusion

実際の指示例：

【Adobe MCP】「選択中の全レイヤーをPNGで書き出し。ファイル名は"レイヤー名_20260503"形式で」 【Blender MCP】「シーン内の全オブジェクトにメタリックマテリアルを一括適用して」 【Ableton MCP】「このプロジェクトのBPMを110→120に変えて。全クリップに適用」

制作領域別 AI ツール早見表（2026年5月）

領域主なツールClaude との使い分け
テキスト・脚本 Claude（Sonnet/Opus）、ChatGPT Claude は長文・日本語の自然さが強い。構成→草稿→批評まで一貫して使える
ビジュアル設計 Claude Design、Figma AI Claude Design は「試作の入口」。プロの最終仕上げはFigmaで行う
画像生成 Midjourney、DALL-E 3、Stable Diffusion Claude にプロンプトを生成させてから画像ツールに貼ると精度が上がる
映像・動画 Sora、Veo（Google）、Runway ML Claude で脚本・絵コンテを作り、映像ツールに渡す分業が効率的
音楽・音声 Suno/Udio（音楽）、ElevenLabs（声）、Ableton MCP Ableton MCP でDAWを Claude から直接操作。ElevenLabs は多言語ナレーションに強い
Adobe・3D・自動化 Adobe MCP、Blender MCP、Claude Code バッチ処理・パイプライン構築は Claude Code が最も得意。MCP でソフト直操作が可能に

主要活用パターン — 実際のプロンプト付き

構成・脚本

アイデアを構造に落とす

漠然としたビジョンを章立て・場面構成・素材リストに変換する。ゼロ生成より人間のアイデアを整理・強化する用途で光る。

「このビジョンでYouTubeショート（60秒）を作る。ターゲットは30代クリエイター。構成を3パターン提案して。それぞれの冒頭5秒のフックも書いて」
批評・ブラッシュアップ

完成物を Claude にレビューさせる

人間が見落としやすい「視聴者目線の違和感」をAIに出させる。完成度の最終チェックに有効。

「このスクリプト（↓貼り付け）、視聴者が離脱しそな箇所を3つ指摘して。理由と改善案も。ターゲットは初見の20代」 「このデザイン案、ALIGN_Lab のブランドトーンと合ってるか？違和感があれば具体的に教えて」
NEW

Claude Design でプロトタイプを作る

「こんな感じのスライドを」と指示するだけでライブHTMLが出る。チームに送って即フィードバックを得られる。

「ALIGN_Lab の活動紹介スライド4枚。①ビジョン ②制作実績 ③メンバー ④CTA。ダーク・ミニマル、英語タイトル+日本語本文」
画像生成補助

Midjourney プロンプトを Claude に作らせる

スタイル・構図・雰囲気の言語化が苦手なときに有効。Claude に「英語のMidjourney用プロンプト」として依頼する。

「このキャラクター設定（↓）でMidjourney用プロンプトを3パターン作って。スタイル: cinematic dark anime。--ar 16:9 付きで」
NEW MCP

Adobe・Blender を Claude から操作

MCP コネクター接続後、Claude Code から自然言語でソフトを操作。繰り返し作業の自動化に特に強い。

【Photoshop】「/images フォルダの全JPGをリサイズ（1920×1080）してweb用に書き出し。ファイル名に_webを追加」 【Premiere】「このタイムラインの無音部分（0.5秒以上）を全部カットして。BGMトラックは除外」
自動化

制作パイプラインを組む

Claude Code + Routines で定型作業を自動化。「毎朝リサイズ→SNS投稿」まで設定できる。

「完成動画を /export に置いたら自動で: ①1080p/720p/shorts にエンコード ②サムネ生成 ③YouTubeにアップ準備。スクリプトを書いて」

実例シナリオ — ALIGN_Lab が YouTube コンテンツを1日で仕上げる

以下は Claude Design + Adobe MCP + Claude Code を組み合わせた制作1日分の流れ。各ステップに実際のプロンプトを添える。

1

コンセプトと意図を言語化する（人間の仕事）

「何を作るか」「誰に何を伝えたいか」をまず人間が決める。AIに渡す前の最重要ステップ。

2

Claude で構成案・スクリプトを作る

「ALIGN_Labが今月リリースしたサービスXを紹介するYouTube動画（3分）のスクリプト。視聴者は20代のクリエイター。冒頭で問い、中盤で実演、末尾でCTA。3パターン構成案を出してから最良を選んでスクリプト化して」
3

Claude Design でサムネイル・スライドを試作

「上のスクリプトに合うYouTubeサムネイル案をHTML/CSSで3パターン。比率16:9。インパクトある見出し+顔写真スペース確保。ダークトーン」

出力されたライブHTMLをチームに共有して即フィードバックを取る。

4

Adobe MCP で既存素材を一括加工

【Photoshop MCP】「/assets/raw にある全PNGのサイズを1920×1080にトリム。余白はブランドカラー（#0b1220）で埋めて/assets/processed に保存」 【Premiere MCP】「スクリプト（↑）をもとに字幕トラックを自動生成して。フォントはNoto Sans JP Bold、下部中央」
5

Claude でスクリプト最終批評

「このスクリプト（↓）の問題点を3つ。①論理の飛躍 ②視聴者が置いてかれるポイント ③CTAの弱さ。それぞれ1〜2行の改善案も」

人間が最終編集・選択を行う。ここが最も重要な人間の役割。

6

Claude Code + Routines で公開自動化

「/final/video.mp4 が更新されたら: ①720p/1080p にエンコード ②サムネPNGをリサイズ ③YouTube Data API で予約投稿（翌朝9:00 JST）。スクリプトを書いて」

使う上で押さえておくこと

「生成した素材 ≠ 自分の作品」

AIが生成したものをそのまま出すだけでは個性が消える。自分の判断・編集・意図が入って初めて自分の作品になる。AI は大量に作れるが、選ぶ審美眼は人間が持つ。

著作権と商業利用

画像生成AIの学習データ問題は2026年現在も決着していない。商業利用は各ツールの利用規約を都度確認すること。Claude 自身の出力については Anthropic AUP を参照。
