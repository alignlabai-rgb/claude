Claude CodeUltracode Mode 追加 — xhigh でワークフロー自動選択

Claude Code のエフォートメニューに新設定「ultracode」が追加。xhigh レベルを設定しつつ、タスクの複雑度に応じてダイナミックワークフロー（マルチエージェント並走）を Claude が自動判断・起動する。コードベース全体のバグハントや大規模マイグレーション（フレームワーク入れ替え・数千ファイル規模の API 廃止対応）で特に有効とされる。

GrokBuild 0.1 API パブリックベータ公開 — コーディング専用エージェントモデル

xAI が grok-build-0.1 を API でパブリックベータ公開。コーディング専用エージェントモデルで、256K トークンコンテキスト・画像入力（UI モックアップやエラースクリーンショット読み取り）に対応。リファクタリング・ツール呼び出し・継続ループを自律実行する。価格は $1/M（入力）・$2/M（出力）。SuperGrok/X Premium+ 加入者は Kilo IDE/CLI から即利用可能。
