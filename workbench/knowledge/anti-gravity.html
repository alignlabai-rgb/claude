2. Desktop IDE — マルチエージェント・オーケストレーション

Antigravity Desktop は「エージェントの Mission Control」として機能する。複数のサブエージェントを並列で動かしながらタスクを分割・実行・統合する。

並列実行

マルチエージェント並列

  • 複数エージェントを同時に起動・管理
  • フロントエンド担当・バックエンド担当・テスト担当を同時進行
  • 各エージェントの進捗を一画面で俯瞰
  • エージェント間の成果物を自動連携
自動化

スケジュールタスク

  • バックグラウンドで定期実行するタスクを設定
  • 「毎朝 PR レビューを実行」などの定期自動化
  • テスト・ビルド・デプロイの自律サイクル
  • 退勤後も Antigravity が作業を継続
音声

ネイティブ音声コマンド

  • マイクから直接コーディング指示
  • 「このクラスにバリデーションを追加して」と話しかける
  • コーディング中のハンズフリー操作
  • Gemini Live と同じ音声処理エンジン

🔗 Google AI Studio・Android・Firebase との統合: Antigravity Desktop は AI Studio でプロトタイプしたエージェントを取り込んだり、Android アプリや Firebase バックエンドの構築も同一環境でシームレスに行える。

3. Antigravity CLI — ターミナル完結の高速エージェント

前世代の Gemini CLI から移行した新 CLI は Go 言語で書き直され、高速・軽量に生まれ変わった。ターミナルから離れずにエージェントを即起動できる。

📌 移行情報: Gemini CLI は Antigravity CLI に統合された。既存の Gemini CLI ユーザーは移行ガイドに従って更新する。コマンド互換性は基本的に維持されている。

# インストール (Mac/Linux)
curl -sSL https://antigravity.google/install.sh | bash

# バージョン確認
antigravity --version

# 基本的なタスク実行
antigravity "このリポジトリに unit test を追加して"

# コンテキストを指定して実行
antigravity --context ./src "API エンドポイントのバリデーションが不足している。修正して"

# 非対話モードでバッチ実行
antigravity --non-interactive "README.md を日本語に翻訳して output_ja.md に保存して"

# 特定モデルを指定
antigravity --model gemini-3.1-pro "アーキテクチャレビューをして"

# プロジェクト設定ファイルで挙動をカスタマイズ
# ANTIGRAVITY.md を作業ディレクトリに置くと自動読み込み

Gemini CLI との違い

  • Go 製で起動・応答が大幅高速化
  • マルチエージェント連携が CLI からも可能
  • Managed Agents API との統合
  • ANTIGRAVITY.md による設定ファイル対応

CLI のベストユースケース

  • CI/CD パイプラインへの AI 統合
  • スクリプトからエージェントを呼び出す
  • SSH 接続のリモートサーバーで実行
  • GUI が不要な軽量タスク

4. Antigravity SDK — カスタムエージェントの構築

SDK は Antigravity の内部エージェント基盤をプログラム的に利用するための構築ブロックを提供する。Google が自社製品で使っているエージェント基盤と同じものにアクセスできる。

# pip install antigravity-sdk
from antigravity import Agent, Task, SubAgent

# カスタムエージェントの定義
class CodeReviewAgent(Agent):
    name = "code-reviewer"
    description = "PR の差分をレビューし、問題点と改善案をリストアップする"
    model = "gemini-3.5-flash"

    async def run(self, context: dict) -> str:
        diff = context["diff"]
        result = await self.generate(
            f"以下の差分をレビューして。セキュリティ・パフォーマンス・可読性の観点で:\n\n{diff}"
        )
        return result

# マルチエージェントパイプラインの構築
pipeline = [
    SubAgent("frontend-agent", task="Next.js コンポーネントを実装する"),
    SubAgent("backend-agent", task="API エンドポイントを実装する"),
    SubAgent("test-agent", task="両者のテストを書く", depends_on=["frontend-agent", "backend-agent"]),
    SubAgent("review-agent", task="コード全体をレビューする", depends_on=["test-agent"]),
]

# 実行（並列実行可能なものは自動並列化）
result = await Agent.run_pipeline(
    pipeline,
    context={"spec": open("spec.md").read()},
)

SDK の主な機能

  • カスタムツール（関数呼び出し）の定義
  • メモリ・セッション管理
  • 並列サブエージェントのオーケストレーション
  • Google Cloud サービスとのネイティブ統合
  • 独自インフラ（オンプレ・他クラウド）へのデプロイ対応

独自ホスティング

  • Google Cloud (Vertex AI + Cloud Run) に最適化
  • AWS / Azure でも動作可能
  • オンプレミス / エアギャップ環境でも利用可能
  • Gemma 4 ローカルをバックエンドとして接続可能

5. Managed Agents API — Gemini API から直接呼び出す

Managed Agents は Gemini API の新機能。chat completion を呼ぶのと同じシンプルな API 呼び出し1つで、Linux サンドボックス付きの推論+ツール実行エージェントをスピンアップできる。

# Managed Agents API（Gemini API の拡張）
import google.generativeai as genai

genai.configure(api_key="YOUR_API_KEY")

# エージェントを呼び出す — chat completion と同じインターフェース
agent = genai.ManagedAgent(
    model="gemini-3.5-flash",
    tools=["code_execution", "web_search", "file_system"],
    sandbox=True,            # Linux サンドボックス内で実行
)

# 複雑なタスクを1回の呼び出しで実行
result = agent.run(
    "以下のデータを分析して可視化してください: " + csv_data,
    max_steps=10,
)

print(result.final_answer)
print(result.artifacts)      # 生成されたファイル（グラフ等）
print(result.steps)          # 実行ステップのトレース

🚀 ポイント: Managed Agents は「推論 + ツール呼び出し + コード実行 + Linux サンドボックス」を1 API コールで提供する。従来はすべてを自前で構築する必要があったものを Google がマネージドで提供する形。

機能従来（自前構築）Managed Agents
ツール実行環境自前でサンドボックス構築◎ 自動でセキュアな Linux サンドボックス
マルチステップ推論ReAct ループを自前実装◎ API が自動で繰り返し実行
コード実行Docker コンテナ管理が必要◎ 組み込み済み
スケーリングインフラを自分で管理◎ Google が自動スケール

7. 最新の驚くべき実例 12選

フルスタック開発

2スプリント → 午後1回で完了

Antigravity がフルスタックプロジェクトを並列ストリームに分割。Next.js フロントエンド担当・API 層担当・Google SSO 認証担当・RBAC 検証担当エージェントが同時進行し、通常2スプリントの作業を午後1回で完了。

Google 社内活用

Google 検索のカスタム UI をリアルタイム生成

Google が Antigravity の技術を Google Search に組み込み、ユーザーの検索クエリに対してリアルタイムでカスタム UI を生成する機能を実装。従来の静的 SERP から動的 UI への進化。

スタートアップ

MVP を週末2日で構築

スタートアップがアイデアから MVP（認証・DB・API・フロントエンド）を Antigravity を使って週末2日で構築。通常1ヶ月かかるボイラープレート実装をエージェントが自動生成。

エンタープライズ

Managed Agents で社内 AI アシスタントを即構築

中堅企業が Managed Agents API を使って社内ドキュメント検索・Slack 通知・カレンダー予約を統合した AI アシスタントをわずか2週間で本番リリース。従来は3ヶ月のプロジェクトだった。

テスト自動化

レガシーコードに Unit Test を自動追加

金融系スタートアップがテストカバレッジが20%以下のレガシーコードベースに Antigravity CLI を使って Unit Test を自動生成。2週間で coverage が20% → 75% に向上。

CI/CD

AI コードレビューを CI に統合

開発チームが Antigravity CLI を GitHub Actions に組み込み、PR がオープンされるたびに自動コードレビューコメントを生成。セキュリティ脆弱性・パフォーマンス問題の早期発見。

モバイル

Android Builder — 自然言語でアプリ生成

Google I/O 2026 でデモされた Android Builder 機能。Antigravity に「ユーザーの歩数を記録するシンプルな Android アプリを作って」と指示するだけで Jetpack Compose のフルアプリを生成。

マイグレーション

Python 2 → 3 の大規模移行を1日で

数万行の Python 2 コードベースを Antigravity が自動分析・移行・テスト。通常数週間かかる Python 3 移行を1日で完了し、既存テストが全て通過する状態で引き渡し。

ドキュメント

コードベース全体のドキュメントを自動生成

オープンソースプロジェクトが Antigravity CLI を使って全ファイルの docstring・README・API ドキュメントを自動生成。コントリビューターが「コードは書けるが文書が書けない」問題を解決。

音声操作

ハンズフリーコーディング

開発者が Desktop IDE の音声コマンドを使い、コードを手で書かずに「このコンポーネントをレスポンシブにして」「エラーハンドリングを追加して」と話しかけるだけでコーディング。RSI（反復性疲労障害）対策にも活用。

バックグラウンド実行

就寝中にリファクタリングが完了

シニアエンジニアが退勤前にスケジュールタスクで「全コードのリファクタリングとテスト実行」を設定。翌朝出勤するとリファクタリング済みの PR が作成されており、レビューのみで済んだ。

SDK活用

業界特化エージェントの構築・販売

AI スタートアップが Antigravity SDK で医療記録レビューエージェントを構築し SaaS として販売。Google の基盤を使うため AI 基盤開発コストゼロで、ドメイン特化のプロンプト・ツール設計に集中できた。
