現行モデル世代 SSOT — provider別モデルと提供面

このページはprovider・製品・API・weights・previewを分けた現行モデル参照表です。一次情報の確認日と不明点は2026-09-23公式差分に記録し、21 providerのcoverage gapはLLM Coverage Ledgerを参照します。過去のmodel releaseや個別ページの記述はcurrent factsとして無条件に引き継ぎません。

最終更新: 2026-09-23 ／ provider公式の発表・model catalog・API release notesを照合

このページの使い方

  • 参照する側: providerの有無・未確認gapはCoverage Ledger、ここに掲載したproviderの現行世代は本表を見る。矛盾する表記はバグ扱いで直す。
  • 更新する側: 新世代リリース・延期・繰り下げを観測したら、このページを先に直す。出典 URL を確認し、確証のある日付・数値だけを書く。
  • 個別ベンダーの詳細・実装メモは各深掘りページ、横断比較は intelligence-matrix、週次の動きは各 *-recent-updates トラッカーを参照。
この表は公開ハブ内の参照用SSOTです。噂・予定段階のものは「未確認／延期」と明示し、公式現行層へ昇格させません。組織canonやprovider採用判断ではありません。

やってはいけない表記（ドリフト防止）

以下の混同を避けてください。履歴記事は削除せず、更新日・確度・surfaceを明示してcurrent layerと分けます。

  • ❌ X / GrokPulse / daily newsで見たモデル名を、一次発表・model catalog確認前にcurrent layerへ昇格する。
  • ❌ API alias、ChatGPTなどのconsumer product、coding agent、open weightsを同じ提供surfaceとして記録する。
  • ❌ Preview / limited access / migration targetをGA・恒久提供と呼ぶ。
  • ❌ provider自身のbenchmarkや性能説明を独立評価として記載する。
  • ❌ 廃止予定日の経過だけを根拠に「停止済み」と書く。実際のshutdownを公式通知で確認する。
  • ❌ model repositoryのcode licenseからweight licenseやcommercial rightsを推測する。
  • ❌ current API model ID、地域、価格、契約条件を古い個別ページから転記する。
最重要: model名だけで「現行」を決めない。stable / preview、chat / API / coding agent / local weights、認証surfaceを必ず分ける。
